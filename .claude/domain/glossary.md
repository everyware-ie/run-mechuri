# 도메인 용어집

**문서마다 같은 말을 같은 뜻으로 쓰기 위한 것이다.** 새 용어를 만들거나 뜻을 바꾸면 여기부터 고친다.

> **2026-09-16에 용어가 바뀌었다.** 드로잉 → **경로 그림**, 각인 → **러닝 데이터** ([결정문](../../docs/decisions/2026-09-16-release-and-editor-scope.md)).
>
> **규칙 문서(FRD·PRD·구현 노트)의 치환은 끝났다.** 회의록·결정문·아이디에이션과 **사람이 실제로 한 말의 인용**에는 옛말이 그대로 남아 있다. 그때의 기록이라 고치지 않는다.

기획 문서(PRD·FRD·결정문)와 코드가 같은 이름을 쓴다.

## 데이터

| 용어 | 뜻 | 주의 |
|---|---|---|
| **트랙** | 시간순 좌표열 + 요약(거리·시간·페이스)로 정규화된 러닝 기록 | 데이터 출처(HealthKit / GPX)와 무관한 형태다. 렌더러는 트랙만 안다 |
| **기록** | 사용자가 고르는 단위의 러닝 한 건 | 트랙은 기록의 내부 표현이다 |
| **결과물** | 렌더링을 거쳐 나온 9:16 클립 | |

## 렌더링

| 용어 | 뜻 | 주의 |
|---|---|---|
| **프리셋** | 연출 스타일. MVP는 셋 (불빛 러너 / 구간 점등 / **기본 경로 그림**) | **"다듬기 세기"를 프리셋이라 부르지 않는다.** 08-18 회의록에서 두 뜻으로 쓰인 적이 있다 |
| **경로 그림** | **결과물에 그려지는 경로의 그림.** 편집에서 크기·위치·회전을 만지는 그 대상 | **2026-09-16에 "드로잉"에서 바뀌었다.** 프리셋 이름이 아니다. 셋 다 경로 그림을 그리는 방식이고, 그중 기본값의 이름이 **"기본 경로 그림"**이다 |
| **경로 탭** | 편집 화면에서 경로 그림을 만지는 단계 | **대상이 아니라 자리다.** 대상을 가리킬 때는 "경로 그림"을 쓴다 |
| **다듬기** | GPS 노이즈를 정리해 선을 매끄럽게 만드는 처리. 직선 축과 코너 축이 있다 | |
| **다듬기 세기** | 다듬기의 정도. 기본은 한 축, 고급에서 직선·코너로 나뉜다 | 프리셋이 아니다 |
| **이상점 제거** | 명백히 잘못 찍힌 좌표를 빼는 것. 다듬기와 별개로 항상 적용 | 스타일이 아니라 오류 처리다 |
| **왕복 분리** | 겹친 구간을 두 줄로 벌려 보여주는 처리. **MVP 제외** | 같은 구간을 여러 번 지나가는 애니메이션 자체는 기본 동작이며 이것과 다르다 |
| **프레이밍** | 경로를 화면에 앉히는 세 값: 회전·크기·위치 | 축척은 크기와 같은 말이다 |
| **러닝 데이터** | 결과물에 새기는 기록 값. 거리·시간·페이스·심박·날짜·장소 여섯 | **2026-09-16에 "각인"에서 바뀌었다** |
| **안전 영역** | 인스타 스토리 자체 UI에 가리는 화면 상하단 | |
| **연출 아이디어 풀** | 기본 프리셋 3개 위에 쌓아두는 후보들(폭죽, 줌 추적 등). 개수를 제한하지 않는다 | 확정된 프리셋이 아니다 |

## 화면

| 용어 | 뜻 |
|---|---|
| **코어 루프** | 기록 선택 → 배경 선택 → 프리셋 선택 → 미리보기·편집 → 공유 |
| **보관함** | 만든 결과물과 재료가 남는 곳. 두 번째 실행부터의 진입점 |
| **편집** | 사용자가 결과물의 값을 바꾸는 것 (프리셋 선택, 크기·위치·회전, 다듬기 세기, 러닝 데이터 항목) |

### 화면에 보이는 말과 문서에서 쓰는 말

**화면은 짧게, 문서는 헷갈리지 않게 쓴다.** 둘은 다른 말이 아니라 같은 것의 짧은 이름과 긴 이름이다.

| 화면 | 문서 | |
|---|---|---|
| **경로** | **경로 탭** | 편집의 단계를 가리킬 때 |
| **경로** | **경로 그림** | 그려지는 그림 자체를 가리킬 때 |
| **러닝 데이터** | 러닝 데이터 | |
| **항목** | 러닝 데이터 항목 | 무엇을 새길지 고르는 탭 |
| **MY RUNARY** | 결과물 목록 | 홈의 목록 제목 |

**문서에서 "경로"만 쓰면 GPS 경로와 섞인다.** 문서에서 137번 쓰이는 그 말이다. 그래서 문서에서는 "경로 탭"이나 "경로 그림"으로 무엇을 가리키는지 밝힌다.
