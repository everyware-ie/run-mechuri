# 결과물 생성 개선 1차: 편집 중 재료 준비

2026-09-28 · 측정 완료, 사전 준비 캐시 구현 중단

## 요청과 상태

사용자는 생성 속도 개선과 편집 중 사전 준비를 하나씩 적용하고 결과물을 보며 고도화하도록 요청했다. 이 문서는 첫 변경의 구체적인 범위다. 사용자가 근거 FRD와 범위를 확인하고 착수를 승인했다. 성과가 낮으면 중단하고 다른 방안을 검토하라는 조건을 함께 요청했다. [구현·측정 노트](../product/features/export-preparation.md)에 결과를 기록한다.

## 근거와 유지할 규칙

- [내보내기·공유 FRD](../specs/frd/export-and-share.md) §2-1 공유 화면에 들어갈 때 시작한다: 최종 mp4 생성은 공유 화면 진입 시 시작한다.
- 같은 문서 §2-2 인코딩이 끝나면 완성이다: 정상 파일 완성과 보관함 등록까지 완료해야 완성으로 처리한다.
- 같은 문서 §2-5 앱 전환·화면 잠금 중 인코딩: 시스템이 허용하는 백그라운드 실행과 취소·실패 동작을 유지한다.
- [경로 렌더링 FRD](../specs/frd/route-rendering.md) §9 출력 규격: 1080×1920·30fps·12초·H.264를 유지한다. 내부 렌더 배율·글로우·폰트도 첫 변경에서는 유지한다.

## 1차로 적용할 범위

편집 조작이 잠시 멈췄을 때 현재 배경 이미지의 디코딩·크롭 준비와 경로 투영·다듬기 결과를 네이티브에서 준비한다. 실제 작업 시간을 먼저 측정해 유효한 비용만 대상으로 한다. 사전 준비만으로 큰 폭 단축이 보장되는 것은 아니다.

- UI와 분리된 작업 큐에서 처리하고, 최신 요청 하나만 대기시킨다. 매 터치 이동마다 준비 요청을 보내지 않는다.
- 사진 식별 정보·수정 정보와 관련 편집값으로 일치 여부를 확인한다. 파일 경로만 같다고 같은 사진으로 간주하지 않는다.
- 경로와 배경의 의존값을 구분한다. 문구만 바꾸면 배경·경로 준비 결과는 재사용 가능하다.
- 완료를 누르면 정확히 일치하는 준비 결과만 재사용한다. 미준비·실패·메모리 해제 시 기존 생성 경로를 사용한다.
- 명시적인 영상 생성은 준비 작업보다 우선한다. 오래된 준비 작업을 기다리느라 완료 후 대기가 늘지 않도록 취소 지점을 둔다.
- 캐시는 메모리에서 한 편집 세션 분량으로 제한하고 메모리 경고·편집 종료에 해제한다. 영상 생성이 이어받은 자원의 수명은 별도로 보장한다.
- 배경·경로를 준비하는 동안에는 최종 mp4나 보관함 항목을 만들지 않고 시스템 인코딩 진행 배너도 띄우지 않는다.

## 비교와 채택 기준

동일한 합성 경로·배경·편집값으로 준비 기능을 켠 경우와 끈 경우를 비교한다. 최신 Release 구성에서 전경·다른 앱 사용·화면 잠금을 나누어 측정한다. 화면 잠금은 실제 버튼 조작 시 사용자 협조가 필요하다.

총 계산 시간과 완료 버튼 이후 대기 시간을 별도로 기록한다. 기존 로그의 raster/copy/wait뿐 아니라 배경 준비·경로 준비·캐시 적중·종료·보관함 저장 시간을 분리한다. 처음에는 대표 입력으로 타당성을 확인하고, 효과가 있으면 세 프리셋·사진·긴 경로 조합으로 넓힌다.

결과물 360프레임의 시각·규격·픽셀 일치를 비교한다. 편집 중 끊김이나 메모리 증가가 큰 경우 채택하지 않는다. 준비 도중 빠른 편집 변경, 즉시 완료, 뒤로 가기, 연속 요청, 캐시 실패를 검증한다. 속도 이득이 작으면 그 사실을 기록하고 중복 래스터화 제거·GPU 실험으로 넘어간다.

## 문서 반영 계획

효과를 측정하고 사전 준비를 채택하면 내보내기 FRD §2-1에 재료 사전 준비와 최종 인코딩의 구분, 일치 확인·실패 시 기존 경로·메모리 제한을 보완한다. PRD의 대기 개선 설명 및 구현 노트도 함께 갱신한다. 기존 FRD에 남은 '실측 없음'은 9/13 개발 빌드 측정과 최신 측정 미완료를 구분해 수정한다.

준비 단계별 측정 코드와 Release 빌드로 실기기에서 3회 측정했다. 전체 44.49~48.90초 중 준비 비용은 0.12~0.20초(0.25~0.44%)로 중단 기준에 해당했다. 사전 준비 캐시는 구현하지 않으며 반복 프레임 작업을 다음 대상으로 검토한다. 상세 조건과 한계는 구현·측정 노트에 남겼다. [전체 조사](2026-09-28-export-speed-research.md)의 GPU·내부 배율·영상 사전 생성은 이후 독립 단계로 남긴다.
