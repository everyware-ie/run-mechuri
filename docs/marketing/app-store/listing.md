# App Store 등록 정보

App Store Connect의 한국어 등록 정보에 그대로 넣을 문구다. 담당은 지민이다.

- 문체는 감성·가벼운 톤으로 간다. 국내 러닝 앱(런데이, 루나런클럽, 모두의 러너)의 스토어 문구를 참고했다
- **앱이 실제로 하는 것만 적는다.** 스토어 문구와 앱이 다르면 리젝 사유가 된다

오늘 뛴 길, 스토리로 자랑하기
```

## 홍보 문구 (170자 이내)

심사 없이 언제든 고칠 수 있다.

```
기록 캡처는 이제 그만 🏃 달린 길이 그대로 그려지는 영상, 버튼 몇 번이면 스토리에 바로 올라가요.
```

```

"러닝 앱 공유 화면은 다 비슷비슷해요"

Runary는 오늘 달린 길을 움직이는 영상으로 만들어 드려요.
지도 위에 찍힌 선이 아니라, 출발점부터 도착점까지
내가 뛴 길이 한 줄씩 그려지는 영상이에요 ✨

【 이렇게 만들어요 】
1. 건강 앱의 러닝 기록을 불러와 원하는 기록을 골라요
2. 기본 배경을 쓰거나, 갤러리 사진이나 방금 찍은 사진을 깔아요
3. 경로 모양과 크기, 위치, 문구를 내 맘대로 다듬어요
4. 저장하거나 인스타그램 스토리로 바로 올려요 📲

【 Runary가 좋은 이유 】
· 경로와 기록은 모두 내가 실제로 달린 데이터예요

※ 건강 앱에 GPS 경로가 있는 실외 러닝 기록이 필요해요.
  실내 러닝이나 직접 입력한 운동은 경로가 없어서 목록에 보이지 않아요.

## 키워드 (100바이트 이내)

쉼표로 구분하고 띄어쓰기를 넣지 않는다. 한글은 한 글자가 3바이트라 30자 남짓만 들어간다. 아래는 96바이트다.

```
러닝,달리기,마라톤,조깅,런닝,기록,경로,코스,크루,오운완,인증,영상,GPS
```

- 앱 이름과 부제에 있는 단어는 이미 검색에 잡히므로 다시 넣지 않는다
- 다른 앱이나 회사의 이름(스트라바, 나이키런, 인스타·릴스 등)은 넣지 않는다. 가이드라인 2.3.7 위반이다
- 합성어는 쪼개 넣는다. Apple 검색이 키워드끼리 조합하므로 `러닝`과 `기록`만 있어도 "러닝 기록"이 잡힌다
- 설명에서 인스타그램을 언급할 때는 줄임말 없이 "인스타그램"으로 쓴다
