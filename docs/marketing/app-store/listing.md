# App Store 등록 정보

1.0.1(47)의 App Store Connect 한국어 등록 정보 초안이다. 담당은 지민이다. 기존 1.0.0 문구는 [변경 전 사본](../../ops/public-docs-2026-11-03/listing-before.md)에 보관한다. 실제 Connect 등록 완료를 뜻하지 않는다.

- 문체는 감성·가벼운 톤으로 간다. 국내 러닝 앱(런데이, 루나런클럽, 모두의 러너)의 스토어 문구를 참고했다
- **앱이 실제로 하는 것만 적는다.** 스토어 문구와 앱이 다르면 리젝 사유가 된다

## 부제 (30자 이내)

```
러닝 기록을 나만의 스토리로
```

10/13 회의에서 이 문구로 확정했다. 처음 초안은 "오늘 뛴 길, 스토리로 자랑하기"였다 ([회의 종합](../../meetings/2026-10-13/synthesis.md)).

```

Runary는 오늘 달린 길을 움직이는 영상으로 만들어 드려요.
지도 위에 찍힌 선이 아니라, 출발점부터 도착점까지

【 이렇게 만들어요 】

4. 저장하거나 인스타그램 스토리로 바로 올려요 📲

【 달리는 순간부터 기록해요 】

건강 앱 자동 저장을 켜면 이후 새로 시작한 러닝부터 완료 시 건강 앱에도 저장해요.

【 Runary가 좋은 이유 】
· 직접 기록하거나 불러온 경로로 나만의 영상을 만들어요

  실내 러닝이나 좌표가 부족한 기록은 사용할 수 없어요. 하트 샘플은 가상 기록이에요.
  직접 측정에는 아이폰과 위치 권한이 필요하며 워치 단독 GPS 측정은 제공하지 않아요.
  워치 운동 연동과 건강 앱 저장은 선택 기능이에요. 워치 운동을 켜면 다른 워치 운동이 종료될 수 있어요.
```

## 키워드 (100바이트 이내)

쉼표로 구분하고 띄어쓰기를 넣지 않는다. 한글은 한 글자가 3바이트라 30자 남짓만 들어간다. 아래는 96바이트다.

```
러닝,달리기,마라톤,조깅,런닝,기록,경로,코스,크루,오운완,인증,영상,GPS
```

- 앱 이름과 부제에 있는 단어는 이미 검색에 잡히므로 다시 넣지 않는다
- 다른 앱이나 회사의 이름(스트라바, 나이키런, 인스타·릴스 등)은 넣지 않는다. 가이드라인 2.3.7 위반이다
- 합성어는 쪼개 넣는다. Apple 검색이 키워드끼리 조합하므로 `러닝`과 `기록`만 있어도 "러닝 기록"이 잡힌다
- 설명에서 인스타그램을 언급할 때는 줄임말 없이 "인스타그램"으로 쓴다

아래 [`screenshots/`](screenshots/)의 다섯 장은 기존 1.0.0용 소재다. 47번의 새 탭과 측정 화면을 확인한 최종 제출본으로 간주하지 않는다. 현재 자료의 크기는 6.9" 규격인 1290×2796이다.

10/13 회의에서 첫 이미지 문구를 "오늘의 러닝을 스토리로 남겨요"로 바꾸기로 했다. 실제 등록한 문구와 이미지는 App Store Connect에서 확인한다 `[확인 필요]`.

1.0.1(47)에서는 보관함·러닝 탭, 측정 준비와 진행 화면을 실제 빌드와 대조한다. 워치를 소개하는 자료에는 실제 워치 앱의 지표와 제어 화면을 사용하고 아이폰 단독 측정과 워치 연동을 구분한다. 기존 편집·저장 이미지는 현재 UI와 문구가 맞는지 확인한다. 제공하지 않는 칼로리, 활동 링 반영이나 워치 단독 GPS를 표현하지 않는다. **11/3 회의 당일 1.0.1(47)을 정식 제출할 때 스크린샷까지 모두 넣었다.** 스토어의 아이폰 스크린샷은 7장이다(11/9 조회). 레포에는 1.0.0용 5장만 있다.
