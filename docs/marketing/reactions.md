# 반응 모음

**결과물을 본 사람의 반응만 모은다.** 버그와 요청은 [QA 기록](../ops/qa-log.md)에 적는다. ([2026-09-29 결정](../decisions/2026-09-29-weekly-content-and-reactions.md))

**왜 모으나.** 이번 라운드가 확인하려는 것은 결과물을 본 사람이 해 보고 싶어 하는지다([PRD](../specs/prd/running-drawing-mvp.md) §5 MVP 범위). 카톡에 흘려보내면 회의 때 기억에 기대게 된다.

## 적는 법

**공개 저장소다.** 누구나 읽을 수 있다.

- 지인은 **성을 빼고 이름만** 적는다
- 스크린숏은 **다른 사람의 이름과 프로필 사진을 가리고** 올린다
- 한 말은 **원문 그대로** 옮긴다. 짐작한 것은 짐작이라고 적는다

한 줄에 이것만 있으면 된다.

| 칸 | 무엇을 |
|---|---|
| 날짜 | 반응이 온 날. 모르면 대략 |
| 누가 | 이름 |
| 무엇을 보고 | 누구의 어떤 결과물을, 어디서 |
| 반응 | 한 말은 원문 그대로. 한 일(물어봄, 설치, 직접 만들어 봄, 올림)도 |
| 적은 사람 | 우리 중 누가 받았나 |

**한 일이 중요하다.** 물어본 사람보다 설치한 사람이, 설치한 사람보다 직접 만들어 올린 사람이 이번 검증에 더 가깝다.
