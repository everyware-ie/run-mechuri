# TestFlight 37번 팀 공유 문구

Apple에서 내부 테스트 가능 상태를 확인한 뒤 작성했다. 실제 카톡 발송은 하지 않았다. 빌드와 검증 근거는 [배포 기록](build-and-dev-commands.md#2026-10-12-정식-심사-준비용-하트-샘플-testflight-빌드-37)에 있다.

```text
러너리 정식 심사 준비용 1.0.0(37)을 TestFlight에 등록했어요.
37번으로 업데이트해서 확인 부탁드려요.

이번 빌드에는 하트 샘플 체험과 개인정보 처리방침 링크 수정을 반영했습니다.
러닝 측정 기능과 워치 앱은 이번 심사 버전에서 제외했어요.

‘새로 만들기’에서 ‘샘플 기록으로 만들어 보기’를 선택해 편집하고 영상을 저장해 주세요.
개인정보 처리방침도 정상적으로 열리는지 함께 봐주세요.
문제가 있으면 화면과 재현 방법을 같이 알려주세요.

스토어 자료도 37번의 실제 화면을 기준으로 맞춰주시면 됩니다.
```
