# 10월 13일 제출용 일반 빌드

회의 중 사용자가 최종 리뷰 보완과 공개 Notion 도메인 변경을 반영한 새 빌드를 만들고, 검증 후 TestFlight에 바로 등록하도록 요청했다. [작성 중인 회의록](https://app.notion.com/p/3f840e8014f98005bce2ccb8fd60ac5e)의 2026-10-13 20:30 KST까지 작성된 내용을 참고한다. 작성 중 문서의 나머지 안건을 확정 결정으로 취급하지 않는다.

이번 일반 빌드는 앱 보관 영상의 백업 제외, 샘플과 실제 기록의 동시 선택 방지, 앱 내 개인정보 링크의 새 도메인을 포함한다. 측정·워치 기능을 제외한 `production` 프로필을 유지한다. 스토어 등록 자료는 회의에서 지민이 담당하고 있으며 이 작업에서 별도로 덮어쓰지 않는다.

## CI 실패 확인

PR #110의 최종 커밋 CI는 통과했지만, [머지 후 main 실행](https://github.com/everyware-ie/run-mechuri/actions/runs/38387187461)은 기록 상세 화면의 첫 테스트가 5초 제한을 넘겨 실패했다. 타입·린트와 나머지 321개 테스트는 통과했다. 화면 초기화 시간이 필요한 해당 테스트만 15초로 명시하고, 테스트마다 비동기 모의 함수의 구현과 대기열을 초기화한다. 대기 중 이전 기록을 보여주지 않는 검증은 유지한다. 검증 결과는 확인 후 아래에 추가한다.

## 공개 주소

- 개인정보 처리방침: https://runary.notion.site/privacy
- 안내 허브: https://runary.notion.site/runary

노션 페이지 ID는 바뀌지 않았다. 새 개인정보 주소에서 비로그인 전체 본문과 문의·변경 이력 링크를 확인했다. 최신 주소는 최종 바이너리에서도 확인한다. 37번 및 예전 문서 보관본은 당시 소스를 보존한다.

## 빌드 전 검증

`TZ=UTC`와 병렬 워커 2개로 CI와 같은 Jest 검사를 실행해 43개 묶음·322개가 통과했다. 타입 검사와 문서·diff 공백 검사가 통과했고 린트는 오류 0개·기존 경고 30개다. 앞선 최종 리뷰의 일반 iOS 빌드와 백업 제외 검증은 그대로이며, 이번 제품 변경은 공개 URL이다.

## 제출 기록

EAS 일반 빌드 `1.0.0(38)`을 소스 `2eda0635db3001bdb96a076b5aff2657dae24518`에서 시작했다. [진행 링크](https://expo.dev/accounts/team-mechuri/projects/mechuri/builds/3e8481ac-0e46-4dae-bc35-f9465cff45e9)는 `production` 프로필·채널과 STORE 배포다. 사용자 회의 안건과 개인 launch 파일은 빌드 소스에서 제외했다. 기존 인증서와 App Store 프로파일을 재사용했다.

공개 방침을 2026.10.13으로 갱신해 초안·결과물 정보와 38번부터의 보관 영상 백업 제외를 설명했다. FAQ·공지와 전체 보관본을 함께 반영했고 변경 이력·이전 문서 목록은 10/13 → 10/12 → 10/3 순서다. 사진 앱 및 외부 공유와 이전 백업은 별도 관리 대상으로 유지한다.

회의 중 20:38 KST 재조회에서 한국어 소개와 새 지원 URL의 등록을 확인했다. 당시 정식 버전은 아직 `1.0`이고 스크린샷·개인정보 URL·심사 메모와 연락처 일부가 등록 전이었다. 사용자가 지민이와 실시간으로 등록 중인 상태이므로 이 시점의 미등록 항목을 최종 결과로 단정하지 않는다.

소스 커밋·빌드 번호·바이너리 확인·Apple 처리 결과는 완료 후 [배포 기록](build-and-dev-commands.md)에 남긴다. TestFlight 업로드와 정식 심사 요청을 구분한다. App Privacy와 스토어 자료, 실기기·iPad 최종 확인은 수행한 범위만 완료로 기록한다.
