# Runary에서 달리고, 기록으로 영상을 만들어 보세요

측정 기능을 포함한 버전의 공개 공지 초안입니다. 적용일과 공개 버전을 확정한 뒤 게시합니다.

러닝 시작을 누르면 아이폰으로 시간과 거리, 경로를 기록할 수 있습니다. 완료한 기록은 기존 건강 기록이나 하트 샘플처럼 영상으로 만들 수 있습니다.

Apple Watch를 연결하면 같은 러닝의 심박과 현황, 일시정지·재개·종료를 함께 사용할 수 있습니다.\
워치 운동 연동은 선택 사항이며 다른 워치 운동이 종료될 수 있으므로 시작 전에 확인해 주세요.

건강 앱 자동 저장을 켜면 이후 새로 시작한 러닝부터 완료 시 건강 앱에 Runary 운동으로 저장합니다.\
권한을 허용하지 않거나 건강 저장에 실패해도 Runary 원본 기록은 기기에 남습니다.

측정과 워치 연결, 건강 저장에 맞춰 개인정보 처리방침과 FAQ도 함께 개정합니다. 실제 처리 항목과 삭제 방법은 개정 방침에서 확인할 수 있습니다. 이전 버전의 안내는 변경 이력에 보관합니다.

이 공지는 기능과 방침 변경을 알리는 안내입니다.\
OS 권한 요청이나 별도로 필요한 개인정보 처리 동의를 대신하지 않습니다.
