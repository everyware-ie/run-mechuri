# 샘플 경로 후보

2026-10-12 사용자가 샘플 체험 구현 전에 예쁘고 상징적인 경로를 비교해 선택하고 싶다고 요청했다. 미리보기와 정식 앱 포함 여부를 확인한 뒤 **하트를 선택**하고 로컬 미러링 확인을 요청했다. 샘플 PRD/FRD는 `approved`로 갱신했다. 다른 후보는 비교 기록으로 남기고 일반 앱에는 하트 한 건을 제공한다. 새 TestFlight 업로드는 사용자 로컬 확인 뒤 진행한다.

## 후보

| 이름 | 담으려는 의미 | Runary에서 보이는 특징 |
|---|---|---|
| 하트 | 달린 길을 좋아하는 마음 | 부드러운 곡선이며 완성된 모양을 바로 읽기 쉽다 |
| 무한 | 꾸준히 이어지는 러닝 | 가로로 넓고 중앙 교차가 불빛 러너의 진행을 보여 준다 |
| Runary R | 브랜드를 기억하게 하는 경로 | 세로 화면을 활용하고 Runary의 이름을 떠올리게 한다 |
| 별 | 오늘의 러닝을 작은 성취로 | 교차와 모서리가 또렷하고 완성 후 형태가 익숙하다 |

형태 선택을 돕기 위한 제안이다. 브랜드 상징성을 우선하면 R, 친근한 첫 체험을 우선하면 하트를 추천한다. 실제 도로를 따라 달릴 수 있는 코스로 제시하는 자료는 아니다.

## 데이터와 미리보기

[routes.json](routes.json)에 가상의 좌표·시각·기록 요약을 보관했다. 네 후보 모두 약 5km·30분·6분/km로 맞췄다. 실제 사용자의 건강 기록을 사용하지 않았으며, 합성 좌표의 기준점은 위도·경도 0이다. 실제 장소 이름으로 표시하지 않는다.

미리보기는 현재 앱의 `route-projection.ts`와 `route-smoothing.ts`를 직접 실행한 결과를 사용한다. 기본 다듬기 값인 `smooth: 0`, `corner: 0`을 적용한다. 화면은 1080×1920 기준이며, 기본 경로 그림과 불빛 러너를 비교한다. 재생은 앱과 같은 거리 진행률과 9초 그리기·3초 유지다.

선 두께·빛 색·잔광 길이는 현재 `route-preview.tsx`의 값을 옮겼지만 웹 Canvas로 그린 근사 미리보기다. 실제 React Native Skia 화면이나 최종 MP4를 캡처한 것은 아니다. 글자와 배경 편집을 제외하고 경로 모양만 비교하며, 선택 뒤 실제 앱과 생성 영상에서 확인한다.

## 확인 결과

- 네 경로의 거리 오차는 5km 기준 1m 이내이며 좌표 투영 결과가 캔버스 안에 있다.
- 브라우저에서 네 후보가 표시되고 표현 방식 변경·동시 재생·완성 화면 전환이 동작했다.
- 1024px와 360px 화면을 확인했고, 360px에서 가로 넘침과 자바스크립트 실행 오류가 없었다.
- 제품 코드 변경 전 타입 검사와 기록 저장·초안·권한 회귀 테스트 34개가 통과했다. 린트는 오류 0개·기존 경고 30개다. 샘플 구현의 검증 결과로 취급하지 않는다.
