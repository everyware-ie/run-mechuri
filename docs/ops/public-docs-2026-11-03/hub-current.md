뛴 기록을 그림으로 남기는 iOS 앱입니다.

건강 앱에 저장된 러닝 경로를 편집하고 사진이나 영상 배경 위에 표현해 세로 영상으로 저장하거나 Instagram에 공유합니다. 1.0.1(47)부터 측정 기능이 제공되는 버전에서는 아이폰으로 직접 기록한 러닝도 사용할 수 있습니다.<br />샘플 체험이 제공되는 버전에서는 실제 기록 없이 하트 경로로 먼저 만들어 볼 수 있습니다.

<b>팀 메추리</b>가 만들고 있습니다.

## 문서

개인정보 처리방침과 자주 묻는 질문, 공지사항을 확인할 수 있습니다.<br />처리방침의 이전 버전은 변경 이력에 보관합니다.

기존 1.0.0 일반 배포 앱은 건강 기록 편집과 영상 제작을 제공합니다.\
1.0.1(47)은 러닝 측정과 선택적 워치 운동 연동, 건강 앱 저장을 포함한 정식 심사 제출 예정 버전입니다. 해당 기능은 이 버전을 설치한 경우에 이용할 수 있으며 기존 앱에 소급해 추가되는 것은 아닙니다.
