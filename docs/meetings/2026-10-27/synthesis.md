## 1. 지난주 약속

| 약속 | 결과 |
|---|---|
| 지응: 기본 배경 + 하고 싶은 작업 | 배경 6장, 라벨에 색상 추가, 코너 프리셋 정리, 도구 버튼 접기. 측정 거리(2m 이하 누락) QA 제보 |
| 현수: 이어받아 필요한 작업 | Runary 기록의 건강 앱 저장, 워치 운동 연동 추가 |
| 지민: 스레드 글 2개 이상 | 이번 주 활동 없음 |
| 셋 다: 달리면 Runary로 재고 QA | 지응·현수 QA 진행 (아래 §4) |

10/20 QA 중 남아 있던 "위치 권한 창이 계속 뜨는지"는 안 떴던 것 같다는 의견. 문제 아닌 것으로 정리

## 2. 정식 심사

- 10/20 반려(연령 등급) 뒤 메타데이터를 고쳐 회신했지만 아직 응답 없음
- 10/27에 App Store Connect에서 심사 상태 업데이트 요청을 누름

## 3. 다음 주 정식 심사 (측정 포함)

### 정한 것

- **이번 주까지 작업한 기능을 모두 넣어 다음 주에 정식 심사 제출**
- 이번 주 할 일: 기능 안정성 높이기, 측정 기능 UI·UX 다듬기

### 남은 일 점검 결과

| 남은 일 | 회의에서 나온 것 |
|---|---|
| 짧은 이동이 거리에서 빠짐 | 일단 보류 (§4). 안건 펼침 메모에는 "수정 진행"으로 적혀 있음 `[확인 필요]` |
| 손목 들었을 때 측정 화면 복귀 | 회의 중 확인: 아이폰에서 측정을 시작했는데 워치에 바로 안 뜸 |
| 평균 심박이 화면마다 다름 | 감안하기로. 나이키 런 클럽도 마찬가지 |
| 건강 앱 저장 | 현수 기기에는 저장됨. 지민·지응 기기에서는 안 됨 |
| 공개 범위, 일반 빌드에 측정 넣기 | 이번 주까지 만든 기능 모두 공개 (위 결정) |
| 개인정보 처리방침, 스토어 자료 | 제출 전에 준비. 담당은 정하지 않음 |
