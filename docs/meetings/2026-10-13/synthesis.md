# 2026-10-13 회의 종합 - 정식 심사를 냈다, 다음은 측정과 팔로워

안건: [현수 안건](../../ideation/phs00/2026-10-13-meeting-agenda.md)

## 1. 정식 등재, 어디까지 왔나

회의 전에는 App Store Connect가 거의 비어 있었다. 회의하면서 지민이 등록을 진행했고, 끝날 무렵 심사를 제출했다.

| 항목 | 결과 |
|---|---|
| 제출 빌드 | 회의 중 현수가 새 빌드를 만들어 공유했다. 영상 백업 제외를 넣은 38번, 아이콘까지 바꾼 39번이다. 최종 제출은 39번이다 |
| 버전 표기 | App Store Connect도 `1.0.0`으로 맞췄다 |
| 언어 | 한국어를 추가했다 |
| 부제 | 러닝 기록을 나만의 스토리로 |
| 개인정보 URL | `https://runary.notion.site/privacy` |
| 아이콘 | 기존 R 마크를 조금 작게. [아이콘 결정](../../decisions/2026-09-22-app-icon.md)에 개정을 덧붙였다 |

부제 후보로 "나만의 러닝 기록이 영상이 되는 순간"도 있었다. 앱 이름에 없는 단어를 넣는 쪽으로 골랐다.

**공개 문서 주소가 바뀌었다.** 노션 도메인을 `phs00`에서 `runary`로 바꿨다. 앱과 레포 문서의 링크는 [PR #111](https://github.com/everyware-ie/run-mechuri/pull/111)에서 함께 고쳤다.

### 스토어 문구 수정 (지민)

| 안건에서 짚은 것 | 정한 것 |
|---|---|
| "어디에도 보내지 않아요" | "내 기록은 내 폰에만" 단락을 통째로 뺀다 |
| "모두 내가 실제로 달린 데이터" | 그대로 둔다 |
| 첫 이미지 "사진으로 남겨요" | "오늘의 러닝을 스토리로 남겨요"로 바꾼다 |

## 2. 러닝 측정

빌드 36으로 실제로 써 보고 나온 의견이다.

- **워치에서 권한을 또 허용해야 해서 번거롭다.** 허용은 처음 한 번만 하고 싶다
- **측정을 켜 둔 걸 잊는다.** 워치뿐 아니라 아이폰 잠금화면이나 알림에도 측정 중이라고 보이면 좋겠다

둘 다 [QA 기록](../../ops/qa-log.md)에 남겼다. 측정 기능은 현수가 맡아 다듬는다.

- 최소 20명, 온라인 설문
- 물어볼 것: 경로를 꾸밀 때 배경 고르기가 핵심인지, 사진을 직접 찍는 게 번거로운지, SNS에 공유하는 사람이라면 무엇을 바꿀 수 있으면 좋겠는지

할지는 정하지 않았다.
