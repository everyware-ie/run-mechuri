# 2026-11-20 회의 종합 - 크루는 보류하고 합동 그리기로, 로그인은 필수

안건: [현수 안건](../../ideation/phs00/2026-11-20-meeting-agenda.md), [지민 안건](../../ideation/jminkkk/2026-11-17-meeting-agenda.md), 노션 페이지 위쪽의 "간단하게 논의할 것들" · 수치: [App Store 분석](../../marketing/app-store/analytics/stats.md), [스레드 통계](../../marketing/threads/stats.md)

11/17 회의를 11/20(금)으로 미뤄서 진행

## 요약

- **크루 기능은 보류.** 대신 여러 사람이 한꺼번에 그리는 기능으로 바꿔 진행. 구체화는 지응
- 보류 전에 크루 시안에서 고른 것: 하단 네 번째 탭, 초대 링크와 회원 찾기, 바로 참여와 내보내기, 크루 홈은 한 줄 요약과 기록 목록
- **로그인은 필수.** 이메일은 받지 않고, 닉네임은 겹칠 수 없고 영문은 소문자만. 로그인 수단은 Apple과 카카오
- 경로 그림 프리셋: 경로 색은 파스텔 톤을 유지하고 retro web 스타일도 찾아보기로 함
- #143(로그인 구현)을 뺀 PR 머지. 회의 뒤 #136, #140, #141을 머지하고 1.0.2를 TestFlight에 올림
- 지민은 취업 준비로 2주 정도 일을 줄임

결정문: [크루 보류와 로그인 필수](../../decisions/2026-11-20-crew-hold-login-required.md)

## 2. 크루

### 시안에서 고른 것

크루를 보류하기 전에 [크루 시안](../../design/crew-screens.md)의 "고를 것"을 정함

| | 고른 것 |
|---|---|
| C1 크루 자리 | A 하단 네 번째 탭 |
| C2 참여 방식 | A 초대 링크, B 회원 찾아 초대까지. 찾는 조건은 닉네임이 될 듯(닉네임이 겹치지 않아서) |
| C3 승인 | A 바로 참여. 크루장의 내보내기는 둠 |
| C4 참여한 뒤 크루 화면 | A에서 B로 여는 안(현수 안) |
| C5 크루 홈 | D 한 줄 요약과 기록 목록 |

### 공유 항목 (F0 크루 만들기)

- 심박은 기본으로 끔. 페이스도 굳이 공유해야 하는지 의문이 나옴
- 지금 화면은 무엇이 켜져 있고 무엇이 꺼져 있는지 헷갈림
- 경로는 항상 공유(그리기의 조건), 나머지는 고르는 옵션으로

### 크루 기능은 보류

- 크루 대신 여러 사람이 한꺼번에 그리는 기능으로 바꿔 진행
  - 회의록 표현은 "셋로그 형태". 크루원을 초대해서 셋로그 형식으로 하는 방향인데, 회의록에도 물음표로 남아 있음 `[확인 필요]`
  - 담당은 지응. 먼저 구체화
- 지민 의견: 셋로그 방식이 더 좋을 것 같음. 현수처럼 잘 안 뛰는 사람에게 더 뛰게 만드는 동기 부여가 될 수 있음
- [MVP PRD](../../specs/prd/running-drawing-mvp.md) §10 로드맵의 그룹 드로잉("같은 날 함께 뛴 사람들의 기록을 하나의 경로 그림 파일에 모아")과 가까운 방향으로 보임(현수 정리)
- 노션 위쪽 의견 중 공유 기록 삭제, 공유 관리 목록 화면은 따로 다루지 않음. 크루 보류와 함께 미룸

## 3. 경로 그림 프리셋

[보고서와 시안](https://claude.ai/artifact/6b1nh6bde6rqaEPjsWCb36)을 보고 의견을 냄

- 경로 색은 좀 더 파스텔 톤을 유지
- retro web 스타일로 찾아보면 좋겠다는 의견

| 프리셋 | 의견 |
|---|---|
| 불빛 러너 | A안: 불빛 머리가 너무 큼, 밝기를 낮추면 좋겠다는 의견. B안과 C안: 괜찮음. 새 프리셋으로 넣어도 될 듯 |
| 구간 점등 | A안: 나쁘지 않음, 조금 더 다듬기. km 동그라미가 눈알 같아 별로라 바깥 테두리 없이 안쪽 동그라미와 글자만 남겨도 괜찮을 듯. B안: 불빛이 따라가는 게 경박해 보임(지응은 괜찮다고 봄). 메추리 캐릭터가 달리게 하는 건 어떤지, 메추리를 귀엽게 만들면 괜찮을 수도. C안: 구간을 나타낸다는 게 잘 안 보임 |
| 기본 경로 그림 | A안: 의견이 둘. 색은 A안으로 가고 선 모양은 지금처럼 두되 굵기만 더하기, 또는 A안으로 가되 출발점 동그라미만 없애기. B안과 C안: 별로. 기본은 기본으로 |

정한 것은 없음. 현수가 의견을 반영해 다듬음

## 4. 로그인 (지민 안건)

| 지민 안건 | 결과 |
|---|---|
| §1 크루원에게 보여 줄 기록의 범위 | 보류. 크루 기능을 안 하게 될 수 있어서 |
| §2 로그인 필수 여부 | **필수** |
| §3 이메일을 받지 않기로 함 | 받지 않음 |
| §4 Google 대신 카카오 | 카카오 |
| §5 닉네임 영문은 소문자만 | 닉네임은 겹칠 수 없고 영문은 소문자만 |

- 필수로 정해서 [로그인 PRD](../../specs/prd/account-login.md) §3 언제 로그인을 묻나와 [로그인 FRD](../../specs/frd/account-login.md) §2 로그인 입구를 고쳐야 함. 지금 문서는 선택(잠정) 기준
- 지민 안건에 적혀 있던 위험(계정이 핵심이 아닌 앱이 로그인을 강제하면 심사에서 반려될 수 있음, App Review Guidelines 5.1.1)은 회의에서 따로 다루지 않음
