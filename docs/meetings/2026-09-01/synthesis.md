# 2026-09-01 회의 종합 - 첫 빌드, FRD 우선, 기본 배경 확정

## 요약

**앱이 아이폰에서 돈다.** TestFlight로 빌드를 올려 셋이 각자 설치했다. 일주일 전에는 코드가 없었다.

가장 중요한 결정은 **디자인 시안과 FRD가 부딪치면 FRD를 따른다**는 것이다. 시안을 코드로 옮기다 충돌이 잦았고, 매번 사람이 판단하느라 진행이 막혔다.

**기본 배경 3장이 확정됐다.** 아침 · 점심 · 저녁 하나씩이다.

## 논의된 안건

### 1. 개발 현황과 막힌 곳

#### 시안과 FRD가 자주 부딪친다

**jminkkk의 디자인 시안(HTML)을 코드로 옮기는 과정에서 충돌 지점이 꽤 나왔다.** 시안이 말하는 것과 FRD가 말하는 것이 달라서, 충돌마다 사람이 확인하고 하나씩 판단해야 했다. 그만큼 느려진다.

**FRD를 따르기로 했다.** 다만 FRD대로 만들었더니 불편하거나 이상하면 **이슈로 올려 FRD를 고친 뒤 진행한다.** FRD를 지키자는 것이지 FRD가 항상 옳다는 것이 아니다.

#### 렌더링이 느리다

| | |
|---|---|
| 완성된 mp4 | 속도가 괜찮다 |
| **편집 과정** | **굉장히 느리다** |

**Swift로 그렸을 때 너무 느려서 미리보기를 JS로 바꿨다.** 원인은 "움직이는 것"으로 추측하고 있다.

**1차 MVP에서는 감수한다.** 타겟 사용자가 팀 셋이고, 지금은 부분을 빠르게 만드는 것보다 **끝까지 도는 완성본**을 만드는 것이 먼저다. (phs00 판단)

#### 아직 안 된 것

**인스타 공유가 미착수다.** 브릿지 셋 중 마지막이고 MVP 필수다. 기기에 저장하는 것은 된다.

### 2. 9/1 목표: 절반 달성

**빌드는 올렸고 베타 심사는 아직이다.**

| 9/1 목표 | 상태 |
|---|---|
| TestFlight 1차 빌드 | **달성.** 셋이 각자 설치해 쓰고 있다 |
| 베타 심사 통과 | **미착수** |

**TestFlight에는 두 가지가 있고 심사 여부가 다르다.**

| | 대상 | 심사 |
|---|---|---|
| 내부 테스트 | App Store Connect 팀 멤버 (최대 100명) | 없다 |
| **외부 테스트** | 팀 밖 사람 (최대 10,000명) | **베타 앱 심사가 필요하다** |

지금 하고 있는 것은 내부 테스트다. 셋 다 팀 멤버라 심사 없이 설치된다.

**그런데 9/22 출시 정의가 "TestFlight 공개 링크"다.** 공개 링크는 외부 테스트 기능이므로 **베타 심사를 반드시 통과해야 한다.** 아직 시작도 안 했다.

`[확인 필요]` **초반에 무언가 실패했는데 정체를 모른다.** 베타 심사인지, 빌드 업로드인지, 수출 규정 준수 미응답인지 확인이 필요하다. JiEung2가 확인한다. **답에 따라 9/22가 흔들릴 수 있다.**

`[확인 필요]` **베타 심사에 며칠 걸리는지 아무도 모른다.** 이걸 모르고 일정을 짜고 있다.

> **일정을 재조정하지 않았다.** 역산표의 9/8 기능 동결과 9/22 출시는 그대로다.

### 3. 제품명: "메추리런"으로 두고 계속 본다

**빌드에 "메추리런"으로 넣어 뒀다.** 대안으로 "런메추리"가 나왔다.

**확정은 아니다.** TestFlight 단계까지는 이름을 꽤 쉽게 바꿀 수 있어서, 그전까지는 계속 아이디에이션한다.

### 4. 기본 배경 3장 확정

10장 중 셋을 골랐다.

| | 파일 |
|---|---|
| 아침 | `아침-1-빛없음.png` |
| 점심 | `점심-3-맑은한낮.png` |
| 저녁 | `저녁-3-맑은노을.png` |

**세 시간대에서 하나씩이고, 셋 다 빛을 얹지 않은 가장 담백한 쪽이다.** [배경 선택 FRD](../../specs/frd/background-selection.md) §2-1이 정한 3장 규격을 그대로 채웠다.

**나머지 셋은 다루지 않았다.** 파일로 넣을지 코드로 그릴지, 배경마다 선 색을 바꿀지, 팀 문양을 다른 배경에도 얹을지다([구현 노트](../../product/features/background-images.md)).
