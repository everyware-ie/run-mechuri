# 2026-11-10 회의 종합 - 3차 스프린트는 크루와 다이어리, 로그인부터

안건: [현수 안건](../../ideation/phs00/2026-11-10-meeting-agenda.md) · 수치: [App Store 분석](../../marketing/app-store/analytics/stats.md), [스레드 통계](../../marketing/threads/stats.md)

## 요약

- 1.0.1 출시 첫 주 숫자 공유. 다운로드 9개(11/8까지)이고, 그중 7개가 App Store 검색에서 나옴
- **3차 스프린트를 오늘부터 4주(~12/8) 진행.** 투표로 크루 가입, 크루원 경로 보기, 다이어리를 만들기로 함
- 2차 스프린트 목표(다운로드 30, 팔로워 50)는 앞으로 2주(~11/24) 더 달성해 보기로 함
- 역할: 지민 로그인·회원가입, 현수 크루 화면 디자인과 디자인 보강, 지응 다이어리
- "러닝" 탭은 이름을 그대로 두고 아이콘을 바꿔 보기로 함. 아이콘은 지응이 준비
- QA: 거리가 길게 나온다는 의견이 다시 나옴. 앱을 지웠다 다시 깔아서 기록이 사라진 일도 있었음

결정문: [3차 스프린트](../../decisions/2026-11-10-third-sprint-crew-diary.md)

## 1. 지난주 약속과 QA

| 약속 | 결과 |
|---|---|
| TestFlight 47번으로 실제 러닝 QA | 지응이 달려 보고 의견 냄 (아래) |
| "러닝" 탭 이름 후보 | 후보 6개와 비교 시안 준비. §4에서 다룸 |
| 다음 스프린트 생각해 오기 | 셋 다 가져옴 (§5) |
| 출시 공지 | 회의록에 기록 없음 |

### 지응의 QA

- 거리가 조금 더 나오는 것 말고는 나쁘지 않았음. 5km 기준 400m 정도 더 나오는 것 같다는 의견. 무엇과 비교했는지는 기록 없음
- 업데이트 대신 앱을 지우고 다음 빌드를 까는 습관(회사에서 생긴 버릇) 때문에 이전 기록이 지워짐
- 러닝 준비 화면의 지도를 지금보다 더 확대해서 보여 주면 내 위치를 알아보기 쉽겠다는 의견

[QA 기록](../../ops/qa-log.md)에 남김

각자 달린 이야기도 나눔. 지응은 5km 평균 페이스 5:30의 벽을 깼고, 지민은 6:30. 날이 추워지니 오히려 뛰게 된다는 이야기도 나옴

## 2. App Store 첫 주 숫자

- 11/3 ~ 11/8: 노출 261, 페이지 조회 56, 최초 다운로드 9
- 다운로드 9개 중 7개가 App Store 검색에서 나옴. 링크로 들어온 29번은 페이지까지 다 봤지만 다운로드는 2개
- 2차 스프린트 목표 30개까지 21개 남음

### 정한 것

- 스레드와 인스타에 적극적으로 올리기
- 지응이 스레드 콘텐츠 1개 이상 올려 보기

2차 스프린트 목표는 앞으로 2주(~11/24) 더 달성해 보기로 함 (§6)

### 스크린샷 문구 오류

- "러닝 사진을 경로와 함께"에서 "께"가 빠진 스크린샷과 고친 이미지를 공유
- 1.0.1은 Connect에서 스크린샷이 잠겨 있어서 다음 버전(1.0.2)을 낼 때 교체
- 1.0.2를 언제 낼지는 다루지 않음

## 3. 스레드

- 팔로워 9명 그대로. 최근 7일 조회 559, 링크 클릭 45(처음 잡힘)
- 스레드만 따로 정한 것은 없음. 이번 주 글은 §2에서 정한 것을 따름

## 4. "러닝" 탭

- "러닝"이라는 이름도 나쁘지 않다는 의견. 이름 대신 아이콘을 바꿔 보는 방향으로 정함
- 아이콘은 지응이 준비. 메추리가 달리는 느낌
- 아이콘이 나오면 [하단 탭 FRD](../../specs/frd/home-running-tabs.md)를 고치고 앱에 반영

## 5. 다음 스프린트

### 각자 가져온 것

| 누가 | 아이디어 |
|---|---|
| 현수 | 앱을 지웠다 깔면 기록이 사라지는 문제(조사만 함), 보증금 챌린지와 포인트(BM 구상) |
| 지민 | 크루 합본(내 주간 합본 레이아웃에 크루원 기록을 넣어 주말에 각자 스토리에 올림), 땅따먹기, 마라톤 기록(참가한 마라톤을 예쁘게 보여 주기), 주간 기록을 SNS에 공유하고 싶게 만들기 |
| 지응 | 다이어리(내 기록을 다이어리로 보고, 뛴 날 스티커를 크루원과 같이 붙이기), 목표 달성 기능(나이키 런 클럽의 색깔별 레벨처럼), 디자인 보강(기본 배경, 불빛 런. 처음 기획에 비하면 투박해 보임) |

지응의 기록 삭제(§1)는 현수 조사의 "Apple로 로그인해서 서버에 보관" 방안과 이어짐. 회의에서 따로 정하지는 않음

### 묶어서 투표

아이디어를 다섯 묶음으로 정리하고 항목마다 투표함. 표 수는 회의록에 남은 투표 표시(v, 🥁, 지응)를 센 것

| 묶음 | 항목 | 표 |
|---|---|---:|
| 크루 기능 (가칭) | **크루에 가입한다 (같이 모인다)** | **2** |
| | 목표를 정할 수 있다 (나이키 런 클럽 챌린지처럼) | 1 |
| | **서로 뛴 경로를 공유(조회)할 수 있다** | **2** |
| | 서로 뛰고 Runary로 만든 경로를 하나로 합친다 | 1 |
| 개인 기록 꾸미기 (다이어리 요소 강화) | **다이어리 형태로 기록 보여 주기** | **2** |
| | 개인 주간 기록을 예쁘게 꾸며 공유 | 0 |
| 동기 부여 강화 (게이미피케이션, 성장 요소) | 목표 설정, 달성 현황, 러닝 등급과 성장 | 1 |
| 디자인 요소 강화 | 기본 배경, 불빛 런 등 시각적 완성도 | 0 |
| BM | 보증금 챌린지와 포인트 | 0 |

### 정한 것

- **3차 스프린트: 11/10 ~ 12/8 (4주)**
- 2표를 받은 세 가지를 만듦: 크루 가입, 크루원끼리 경로 보기, 다이어리

| 누가 | 무엇 |
|---|---|
| 지민 | 로그인과 회원가입 구현. Apple과 Google |
| 현수 | 크루 화면 디자인(모집, 경로 조회). 기본 배경, 불빛 런 같은 디자인 보강 |
| 지응 | 다이어리 구현(디자인 포함) |

- 카카오 대신 Google로 감. 다만 카카오에 사업자가 꼭 필요한지는 확실하지 않음. 지응은 없어도 된다고 했고, 사업자 없이 진행해 본 경험이 있다고 함. 지민이 진행하면서 판단
- 디자인 보강은 표를 받지 못했지만 현수 몫으로 들어감

### 다루지 않은 것

- 서버를 무엇으로 둘지
- 크루원에게 경로를 보여 줄 때 집·회사 위치를 어떻게 할지. 지민의 크루 합본 메모에 적혀 있던 문제
- 3차 스프린트의 목표 수치
