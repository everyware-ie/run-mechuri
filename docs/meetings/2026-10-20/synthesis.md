# 2026-10-20 회의 종합 - 심사 반려 대응, 스레드는 꾸준히, 측정은 Runary로 재기

안건: [현수 안건](../../ideation/phs00/2026-10-20-meeting-agenda.md) · 스레드 수치: [스레드 통계](../../marketing/threads/stats.md)

## 요약

- 정식 심사가 오늘 반려됐다. 연령 등급 설정 문제라 고쳐서 재심사를 요청했다
- 스레드는 조회가 잘 나오니, 올리고 싶은 글이 있으면 바로 올리고 꾸준히 발행한다
- 기본 배경 이미지를 지응이 예전에 만든 배경으로 고도화해 바꾼다
- 앞으로 달릴 때는 의식적으로 Runary로 재고, 각자 QA를 하나 이상 낸다

---

## 1. 정식 심사

- 10/13에 빌드 39로 낸 심사가 **10/20 반려**됐다. 앱이 아니라 App Store Connect의 **연령 등급 설정** 문제였다
- 앱에서 제공하지 않는 "유해 콘텐츠 차단(Parental Controls)"과 "나이 확인(Age Assurance)"을 모두 "아니요(None)"로 바꿨다. 같은 날 11:35 현수가 심사팀에 재심사를 요청했다
- 통과하면 카톡방에 알리고, 스레드에도 틈틈이 올린다

## 2. 스레드

스레드 수치를 레포에 쌓는 방법을 공유했다. 팀 구글 계정으로 만든 Meta 개발자 앱에 팀 스레드 계정을 테스터로 연결했다. 사용법은 [README](../../marketing/threads/README.md)에 있다.

10/20 기준 팔로워 9명, 최근 30일 계정 조회 59,331이다. 질문형 글이 조회와 답글을 거의 다 가져갔고, 조회가 팔로우로 이어지지 않았다.

### 나온 이야기

| 누가 | 내용 |
|---|---|
| 함께 | 조회가 잘 나오니 지난주처럼 올리고 싶은 글이 있으면 바로 올린다 |
| 지응 (리서치) | 논쟁을 일으키는 글을 올리고 거기에 슬쩍 자기 서비스를 끼워 넣는 계정들이 있다 |
| 지민 (추측) | 순수하게 궁금해서 묻는 글은 반응이 높고, 홍보 냄새가 조금이라도 나면 반응이 없는 것 같다 |
| 함께 | 다른 글에 반응을 잘하고, 스하리(서로 팔로우하고 하트와 리포스트를 주고받는 스레드 문화)에 참여한다. 글을 꾸준히 올리고, 유익한 글을 쓴다 |

### 링크 클릭이 0인 이유

회의에서 어떤 링크를 세는지 확인하기로 했다. 정리하면서 Meta 문서와 API로 확인했다.

- **우리 게시물에 넣은 링크를 누른 횟수다.** 문서 설명은 "The number of times people clicked on URLs you shared."이고, 2025-07-02 변경 이력도 "your Threads posts"의 링크 클릭이라고 한다
- **0인 이유는 글에 링크를 넣은 적이 없어서다.** 지금까지 올린 글 12개 모두 본문과 링크 첨부에 링크가 없다
- **프로필 링크는 따로다.** 스레드는 2025년 5월부터 프로필에 링크를 5개까지 걸고 앱 인사이트에서 클릭을 볼 수 있다. API 문서는 프로필 링크를 센다고 하지 않는다. 프로필에 앱 링크를 건 뒤 다음 수집에 잡히는지 보면 확인된다
- 수치에 스레드 공유 링크 하나가 클릭 0으로 잡혀 있는데, 우리 글에서는 찾지 못했다. 어디서 온 건지는 모른다

## 3. 러닝 측정

빌드 41의 잠금화면 제어, 바로 시작, 측정 기록으로 영상 만들기를 공유했다. 현수가 Runary로 잰 기록으로 만든 영상을 함께 봤다.

### 정한 것

- **앞으로 달릴 때는 의식적으로 Runary로 잰다.** 반강제로라도 쓰면서 QA를 모은다
- **기본 배경 이미지를 바꾼다.** 지금 기본 이미지가 별로라는 의견이 나왔다. 지응이 초창기에 만든 배경 이미지를 고도화해 기본 이미지로 쓴다. 바꾸기 전에 [배경 선택 FRD](../../specs/frd/background-selection.md)를 확인한다

### 나온 QA

[QA 기록](../../ops/qa-log.md)에 남겼다.

- 기록을 고를 때 Runary로 잰 기록과 애플 기록을 구분할 수 있게 하자. 예를 들면 색으로
- 위치 알림 설정에서 "허용 안 함", "항상 허용" 창이 계속 뜨는지 확인해야 한다
- 정지를 누르고 앱을 끈 뒤 잠금화면의 러닝 알림을 밀어서 없앴다. 다시 들어와 이어 달리기를 눌렀더니 잠금화면에 다시 뜨지 않았다
- 앱 안에서 일시정지를 누르면 "GPS 준비"가 나온다. 바로 이어서 재야 한다

### 친구 기능 (러프 논의, 참고)

결정한 것은 없다. 나온 아이디어만 적어 둔다.

- 단순히 친구를 맺고 공유하는 것보다 우리만의 색깔이 있으면 좋겠다 (지민). 당근의 지역 인증, 포켓몬처럼 가까운 사람끼리 상호작용하는 느낌
- 러닝 시그널, 특정 시간에 달린 사람만 들어가는 한정 커뮤니티
- 러닝 보물찾기: 뱃지, 아이콘이나 인스타 스티커 같은 보상, 예쁜 것을 모으거나 인증하기
- 고스트 러너: 적절한 강도를 위한 페이스 메이커
- 러닝 등급: 서비스 신뢰. 어느 정도 사용자가 모인 뒤에
- 러닝 명함: 누적 거리, 최고 기록, 페이스를 담은 이미지. 가까이 있는 사람끼리 교환
