# 구간 점등의 거리 구간 복원

- 근거: [경로 렌더링 FRD](../../specs/frd/route-rendering.md) §6-3 구간 점등 (`approved`), [MVP PRD](../../specs/prd/running-drawing-mvp.md) §7 결과물의 형태
- 확인: 2026-10-04 사용자가 구간 점등의 구간 표시가 보이지 않는다고 제보하고 목적에 맞게 수정을 요청했다. 승인된 거리별 단위를 안내하고 같은 범위에서 진행한다.
- 상태: 구현·핵심 실기기 검증 완료. 2026-10-04 TestFlight `1.0.0(29)` 내부 배포 완료 ([배포 기록](../../ops/build-and-dev-commands.md#2026-10-04-편집-2단계구간-점등-배포-10029)).

> 같은 날 후속 디자인 제보로 검정 테두리를 발광 표식으로 바꿨다. 아래는 최초 복원 당시의 구현·검증 기록이며 현재 디자인은 [발광 표식 다듬기](segment-lighting-glow.md)를 따른다.

## 원인과 수정

미리보기와 Swift 영상이 모두 다듬고 투영한 선의 픽셀 길이를 미터 단위 함수에 넣고 있었다. 화면 크기·다듬기·경로 확대에 따라 구간 수가 달라지며 기록 거리의 구간과 맞지 않는다. 완료한 경계 점은 반지름 4, 선은 두께 10이라 같은 색 선 안에 묻혔다.

기록의 총 거리로 구간 단위·개수·진행 비율을 정하고, 그 비율로 캔버스 경계 위치를 찾는다. 총 거리가 없으면 GPS 누적 거리로 대체하며 픽셀을 미터로 쓰지 않는다. 점등한 경계는 선보다 큰 점과 어두운 테두리로 남긴다. 마지막 잔여 구간도 완주 때 표시한다. 미리보기·생성 영상·보관함 썸네일에 같은 경계를 연결한다.

진행률은 기존처럼 화면 선 길이에 따라 부드럽게 흐른다. 다듬은 선 위 경계 위치는 기록 거리의 진행 비율로 대응하므로 원본 GPS 지점의 정밀 거리 표식이나 측정 도구는 아니다. 재생 시간·러닝 데이터 카운트업·선 색·두께 선택은 유지한다. 미리보기 애니메이션은 UI 스레드에서 처리하고, 구간마다 별도 컴포넌트로 훅을 사용해 기존 12개 상한 때문에 긴 기록의 마지막 구간이 빠지는 것도 막는다.

## 검증

거리별 구간 수와 끝 비율, 마지막 잔여 구간, 확대·회전·다듬기에 무관한 구간 수, 12개를 넘는 긴 기록을 검사한다. 실제 앱 화면·생성 영상은 별도로 확인하며 결과를 이 노트와 QA 기록에 모은다.

### 확인 결과 (2026-10-04)

- 거리별 단위·잔여 구간·14구간 긴 기록·확대/회전 시 경계 보간·GPS 대체 거리 검사를 포함해 전체 26개 묶음 222개 테스트 통과. 타입 검사 통과, 린트 오류 0개(기존 경고 32개), 문서 검사 통과.
- React 검사에서는 각 구간을 별도 컴포넌트로 둬 훅 호출 수가 바뀌지 않는지, 구간 계산이 진행률 샘플마다 반복되지 않는지 확인했다. 기존 UI 스레드 진행률과 Canvas memo 경계는 유지한다.
- iOS Debug 빌드 성공. iPhone 11 Pro에서 약 1.95km 기록의 경계가 500m마다 추가되는 것을 확인했다. 기본 따뜻한 흰색/두께 100%와 민트색/두께 약 200%(저장값 199%) 모두 경계가 선 밖에 보인다.
- 새 영상은 1080×1920·30fps·12초·360프레임이며 전체 디코딩 성공. 2.2초(500m 전)에는 점이 없고, 2.4초에는 1개, 4.7초에는 2개, 7초에는 3개, 9.1초와 11초에는 4개가 남는다. 미리보기·완성 카드·보관함의 경계 위치와 육안 비교했다.
- 기존 결과물 16건은 보존하고 검증 영상 1건을 추가했다. 사용자의 원래 초안은 QA 전 바이트와 동일하게 복원했다. GPS·영상·스크린샷은 로컬 검증용으로만 사용하고 커밋하지 않는다.

### 적용 범위와 남은 확인

이미 생성한 MP4는 다시 인코딩하지 않는다. 새 영상부터 수정한 구간이 들어가며, 기존 결과물의 앱 썸네일에는 새 표시를 사용한다. 다른 화면 크기·사진/영상 배경 조합은 이번 실기기 검증 범위에 포함하지 않았다. 구현 완료 당시 TestFlight는 배포하지 않았으며, 이후 빌드 29에 포함했다.

### 문서 정합성

FRD §6-3에 실제 미터 기준·경계 점·마지막 잔여 구간을 명시했다. PRD §7의 km 고정 표현도 FRD의 자동 단위와 맞췄다. 2026-08-18의 기본 프리셋 3개 결정은 유지하며 새 용어·저장 형식은 만들지 않았다. 실제 구현이 FRD와 어긋나던 픽셀 거리 계산을 복구한 수정이다.
