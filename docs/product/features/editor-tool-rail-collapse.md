## 무엇을 고치나

편집 화면 오른쪽에 도구 버튼 6개(배경·경로·러닝 데이터·문구·그리기·내 스타일)가 미리보기 위에 떠 있다. 코너 프리셋은 러닝 데이터를 오른쪽 모서리에 놓아서 버튼이 그 위를 가린다. 버튼 위에 접기 손잡이를 두고, 누르면 버튼이 접히고 다시 누르면 펼쳐지게 한다.

## 정한 것 (사용자 확인 2026-10-22)

| | |
|---|---|
| 손잡이 | 도구 버튼 위에 작은 원형 버튼. 펼침일 때와 접힘일 때 화살표 방향이 다르다 |
| 처음 상태 | 펼침. 도구의 존재를 알려야 한다 |
| 접은 상태의 수명 | 그 편집 화면을 보는 동안만. 저장하지 않는다 |
| 접힌 상태 | 손잡이만 남는다. 도구 버튼 6개는 사라진다 |
| 시트가 열려 있을 때 | 지금과 같다. 경로·러닝 데이터 도구를 열면 원래 버튼이 숨는 동작은 그대로 |

검토했지만 고르지 않은 것은 **자동으로 접히는 방식**(눈에 안 보이는 동작이라 헷갈린다)과 **아이콘만 남기는 방식**(FRD가 도구 버튼에 이름을 붙이라고 한 이유와 부딪친다. 9/16 지적)이다.

| 문서 | `docs/specs/frd/result-editing.md` §1 | 도구 버튼을 접을 수 있다는 규칙(이 PR에서 함께 고침) |

## 확인할 것

1. 코너 프리셋에서 접었을 때 러닝 데이터가 가려지지 않는지
2. 손잡이가 러닝 데이터와 겹치지 않는지. 다른 프리셋(스탯바, 레일, 스택 등)에서도 본다
3. 접은 채 도구를 쓰려면 한 번 더 눌러야 하는데 불편하지 않은지
4. 시트를 열고 닫을 때와 문구·그리기 진입 후 돌아왔을 때 접힘 상태가 어색하지 않은지

## 구현

- `edit.tsx`: `toolsFolded` 상태(저장 안 함). 도구 버튼 묶음 맨 위에 접기 손잡이(32pt 원, 아이콘 `chevron.up`/`chevron.down`)를 두고 접히면 도구 6개만 숨긴다
- 접근성: 손잡이는 "도구 접기"/"도구 펼치기" 라벨과 `expanded` 상태를 가진다
- 접은 상태에서 경로·러닝 데이터 도구를 열었다 닫는 동작은 바꾸지 않았다. 그 도구에서는 원래 도구 버튼 묶음 전체가 숨는다
