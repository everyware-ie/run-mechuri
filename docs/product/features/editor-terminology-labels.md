## 확인한 근거

[2026-09-16 결정](../../decisions/2026-09-16-release-and-editor-scope.md) §5 "화면에 쓰는 말을 바꾼다"와
[용어집](../../../.claude/domain/glossary.md) §번역 표를 확인하고 진행한다.

| 어디 | 전 | 후 |
|---|---|---|
| 단계 탭 | 드로잉 | 경로 |
| 단계 탭 | 각인 | 러닝 데이터 |
| 각인 안의 탭 | 넣을 것 | 항목 |
| 대시보드 | 내가 만든 것 | MY RUNARY |

approved FRD([결과물 편집](../../specs/frd/result-editing.md) §3 프리셋 선택)는 기본 프리셋 이름을 이미
"기본 경로 그림"으로 쓰고 있어(2026-09-16 이전부터), 코드의 "기본 드로잉" 라벨도 함께 맞춘다.

## 구현 노트

**범위: 화면에 실제로 보이는 문자열만.** 회의 결정문 §5는 "문서 155곳, 구현 노트까지 300곳"의
전체 치환은 별도 작업으로 분리한다고 명시했다 — 코드 주석과 변수명(`isStamp`, `stampConfig`,
`drawingHint` 등 식별자)은 그 별도 작업 대상이라 이번 커밋에서 건드리지 않는다.

- `frontend/src/app/edit.tsx`: 단계 탭 라벨(드로잉/각인 → 경로/러닝 데이터), 러닝 데이터 안의
  "넣을 것" → "항목" 탭 라벨, 프리셋 "기본 드로잉" → "기본 경로 그림", 그리고 같은 화면의 나머지
  화면 문구(제스처 안내, 초기화·이전·다음 버튼 접근성 라벨, 문구 입력 안내)도 같은 규칙으로 맞춰
  화면 안에서 신·구 용어가 섞이지 않게 했다.
- `frontend/src/app/index.tsx`: 대시보드 섹션 라벨 "내가 만든 것" → "MY RUNARY".
- 스토리 안전 영역 버튼 제거, 간결 프리셋 삭제, 장소 각인 프리셋 확대 등 **기능 변경은 이번
  범위가 아니다** — 같은 결정문의 다른 절(§4)이며 별도로 진행한다.
