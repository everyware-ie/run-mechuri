## 확인한 범위 (2026-09-10)

사용자가 재생 버튼 옆 안내 문구에 이어 앱 UI 전반을 Pretendard로 바꾸도록 요청했다.
홈, 연결, 기록·배경 선택, 편집, 공유, 결과 상세 화면과 공통 버튼·헤더·안내 시트의 텍스트 및 입력창이 대상이다.
UI의 숫자와 영문도 함께 적용한다. 재생·새로고침 등 아이콘으로 쓰이는 기호는 기존 표시를 유지한다.
문구 내용, 크기, 자간, 색상, 배치와 재생 동작은 기존 값을 유지한다.
각인 프리셋의 서체 차이는 각 프리셋의 특징을 반영한 것이라는 사용자 설명에 따라, 각인 미리보기와 저장 영상의 서체는 변경하지 않는다.

## 구현

Pretendard 1.3.9 공식 배포본의 Medium(500), Bold(700) 정적 OTF와 라이선스를 `frontend/assets/fonts/`에 포함한다.
기존 `_layout.tsx`의 `useFonts`에서 로드하고 `theme.ts`의 `Fonts.sans`와 `Fonts.sansBold`를 통해 사용한다.
기존 500/700 굵기 구분을 유지한다. 각인에서 사용하는 Space Grotesk, JetBrains Mono, Noto Sans KR은 계속 로드한다.

## 검증

- UI 전반 적용 후 TypeScript, 문서 정합성 검사와 `git diff --check` 통과.
- `src` 전체 린트 오류 26건은 변경 전과 동일하며 새 오류는 없다.
- Metro 전체 새로고침 후 iOS 번들 생성 성공. 각인 미리보기와 영상 렌더러의 소스 변경이 없음을 확인했다.
- 자동 승인 검토의 모델 용량 문제로 Xcode 화면 확인이 차단되어 이번 변경의 실기기 육안 검증은 수행하지 못했다.
- 사용자가 실기기에서 UI 전반에 글꼴이 잘 반영되었음을 확인했다(2026-09-10).
