## 구현 노트

`frontend/src/app/index.tsx`를 홈 화면으로 구현. §1-1 화면 구성 순서(이어서 만들기 → 새로 만들기 → 결과물 목록 → 쇼케이스) 그대로.

- **새로 만들기**(항상): `record-selection`으로 이동
- **결과물 목록**: `frontend/src/lib/results-store.ts`(AsyncStorage)에서 읽음. §2-1 정렬(러닝한 날 최신순), 썸네일(`route-thumbnail.tsx`, 완성 순간 정지 이미지) 반영. 2열 그리드
- **결과물에서 할 수 있는 것**(§2-2): `frontend/src/app/result/[id].tsx` — 다시 편집·같은 기록으로 새로 만들기·삭제. "보기"는 v0에서 정지 이미지로 대신함(영상 재생 라이브러리 미도입)
- **이어서 만들기**(§3): `frontend/src/lib/draft-store.ts` — 단일 슬롯(§3-1 "맨 위에 하나"). edit.tsx 진입·프리셋·변형값 변경마다 저장, share.tsx 완성 시 삭제
- **쇼케이스**(§4): FRD가 명시적으로 "여유 시"(§4-3)라 계속 미착수

**§2-3 저장 데이터**: `SavedResult`에 트랙 좌표·프리셋·변형값·배경 참조를 전부 담음 — 원본 HealthKit 기록이 지워져도 다시 편집·재생성이 되게 하는 게 목적.

**아직 안 한 것**: 복귀 위치(§5, 30분 기준 포그라운드 복귀 분기 — 별도 상태 추적 필요), "보기"의 실제 영상 재생.

### 홈 목록에서는 각인을 안 그린다 (2026-09-02)

`RouteThumbnail`(route-thumbnail.tsx)은 `run`/`stampConfig`를 넘기면 사용자가 고른 각인 프리셋을 원래 크기·자리 그대로 그린다. 홈 화면의 `heroCard`(이어서 만들기 아래 큰 카드)·`gridThumb`(내가 만든 것 그리드 칸)는 각각 `heroOverlay`(거리+날짜)·`gridLabel`(거리만) — 이 화면 전용으로 항상 같은 자리·같은 스타일로 보여주는 고정 표시를 이미 갖고 있는데, 여기에 `run`/`stampConfig`까지 넘기니 **두 표시가 겹쳐 보였다**(실기기 피드백: "위에껀 km+날짜인데 밑에껀 작은 글씨로 km만 남아있다" — 실은 고정 표시 위에 프리셋별로 다르게 배치되는 각인이 겹쳐 그려진 것). 홈 목록의 두 `RouteThumbnail` 호출 모두 `run`/`stampConfig`를 안 넘기도록 고쳤다 — 경로 선만 그려지고, 거리·날짜는 이 화면 전용 고정 표시로만 보인다. `share.tsx`(완성! 화면)·`result/[id].tsx`(보관함 상세)는 거리·날짜 텍스트가 카드 밖 별도 자리에 있어(겹치지 않음) 그대로 둠 — 각인을 실제로 보여줘야 하는 화면이기도 하고. 각인 텍스트 자체의 효과(외곽선·그림자)는 `docs/product/features/result-editing.md` "각인 텍스트 효과를 프리셋군별로 분리" 참고.

### "다시 편집"이 배경 파일을 못 찾을 때 미리 안내 (2026-09-03)

배경 이미지 경로가 더는 유효하지 않은 옛 결과물(원인은 `docs/product/features/background-selection.md` "다시 편집이 결과물을 못 만들던 문제" 참고)을 "다시 편집"하면, `result/[id].tsx`가 진입 전에 배경 파일 존재 여부를 먼저 확인한다. 없으면 편집을 다 끝낸 뒤(공유 화면)에야 실패로 알게 되는 대신, 시작 전에 안내하고 배경만 다시 고르게 한다 — 프리셋·변형·다듬기·각인 등 나머지 편집값은 그대로 유지한 채 `background-selection`으로 보낸다.

**"이어서 만들기"(§3)도 같은 문제가 있었다** — TestFlight로 실기기 재확인: "업데이트한 뒤 이어서 만들기가 안 되는 것 같다." `draft-store.ts`의 초안도 `SavedResult`와 똑같이 `backgroundImagePath`를 절대경로 문자열로 저장해 둔 채라, 앱 업데이트(테스트플라이트·앱스토어는 데이터를 지우지 않고 덮어써서 설치된다 — 지우고 재설치하는 것과 다르다) 사이에 초안을 남겨 놨으면 똑같이 깨질 수 있었다. `index.tsx`의 `handleResumeDraft`에도 같은 사전 확인·안내를 추가했다.
