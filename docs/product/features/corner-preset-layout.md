# 코너 프리셋 항목 재배치

- FRD: [경로 렌더링](../../specs/frd/route-rendering.md) §7-5 배치("코너 프리셋은 켜진 항목에 맞춰 자리를 다시 잡는다")
- 근거 QA: 사용자 요청(2026-10-22), [QA 기록](../../ops/qa-log.md) "코너 프리셋에서 날짜 위치가 애매하다"(2026-09-23)
- 구현 상태: **구현했다**(2026-10-22, 사용자가 FRD 개정안을 확인). 실기기 확인 대기

## 무엇을 고치나

코너 프리셋에서 날짜가 오른쪽 위에 혼자 떨어져 보인다. 그리고 러닝 데이터 항목을 끄고 켜도 남은 항목의 자리가 맞춰지지 않는다.

**원인.** 날짜는 안전 영역 바로 아래에 놓이고 통계는 날짜에서 `72 * M`만큼 떨어져 시작한다. 원래 시안에는 그 사이에 왼쪽 위 문구가 있었다. 2026-10-04에 문구를 프리셋에서 떼면서 날짜만 위에 남았다. 또 거리를 끄면 시간이 큰 숫자가 되는데 통계에도 시간이 다시 나온다. 글래스는 큰 숫자를 통계에서 빼는데 코너는 빼지 않기 때문이다.

## 정한 것 (사용자 확인 2026-10-22)

FRD §7-5의 표를 따른다. 요약하면 이렇다.

- 날짜는 통계가 있으면 그 묶음의 첫 줄로 붙는다. 통계가 없고 큰 숫자가 있으면 큰 숫자 바로 위로 간다
- 큰 숫자로 쓴 항목은 통계에서 뺀다
- 항목이 하나도 없는 쪽은 자리를 비운다

## 고칠 곳

편집 화면과 저장 영상이 같은 규칙으로 그려져야 한다.

| | 파일 | 무엇 |
|---|---|---|
| 편집 화면·썸네일 | `frontend/src/components/route-preview.tsx` | `layout === 'corner'` 분기 |
| 저장한 영상 | `frontend/modules/route-renderer/ios/RouteRendererModule.swift` | `stamp.stampLayout == "corner"` 분기 |

## 확인할 것

1. 모든 항목을 켰을 때 날짜와 통계가 한 묶음으로 보이는지
2. 거리를 끄면 시간이 큰 숫자가 되고 통계에서 시간이 빠지는지
3. 통계를 모두 끄면 날짜가 큰 숫자 위로 가는지
4. 큰 숫자까지 끄면 통계만 남아도 어색하지 않은지
5. 편집 화면과 저장한 영상이 같은 자리에 그리는지

## 구현

- 통계 목록에서 큰 숫자로 쓴 항목을 뺀다(글래스가 하던 것과 같다)
- 날짜는 통계가 있으면 통계 묶음의 첫 줄(날짜 바로 아래에서 통계 시작), 통계가 없고 큰 숫자가 있으면 큰 숫자 위, 둘 다 없으면 오른쪽 위
- 통계 묶음의 시작 위치: 예전에는 날짜에서 `72 * M` 아래였다. 지금은 날짜가 있으면 `12 * u` 아래, 없으면 날짜 자리(맨 위)다
- 큰 숫자의 위치 계산을 날짜 계산보다 앞으로 옮겼다. 값은 그대로다
- TS(편집 화면·썸네일)와 Swift(저장 영상)에 같은 규칙을 넣었다. 간격 상수(`12 * u`, `0.78`, `8 * u`)가 같다
