# 편집 도구의 상단 선택 영역

- 근거: [결과물 편집 FRD](../../specs/frd/result-editing.md) §1 화면 구조·§3 프리셋 선택·§5 다듬기 세기 (`approved`).
- 착수 확인: 2026-10-04 사용자가 경로 프리셋 상단 배치와 ROUTE B 아이콘 교체 제안을 승인하고 구현을 요청했다. 앞서 확인한 편집 FRD의 배치 개정이며, 기능과 편집값 유지 규칙은 같다.
- 이슈: [#101](https://github.com/everyware-ie/run-mechuri/issues/101)
- 상태: 구현·핵심 실기기 QA 완료. 손그림 획 편집과 [PR #100](https://github.com/everyware-ie/run-mechuri/pull/100)에 묶는다.

손그림에서 확인한 상단 선택·하단 세부 조절 구성을 경로 도구에 적용한다. 경로 도구를 열었을 때만 상단에 되돌리기·기본/불빛/구간·완료를 보여 준다. 아래 시트에는 다듬기/선 스타일 탭과 초기화를 둔다. 다른 도구를 열거나 시트를 닫으면 평소 도구가 돌아온다. 이후 사용자가 러닝 데이터에도 상단 분리를 승인해 아래 후속 작업으로 확장한다. 문구의 상단 배치는 아직 적용하지 않는다.

경로 도구 아이콘은 `point.bottomleft.forward.to.point.topright.scurvepath`로 바꾼다. 프리셋의 짧은 화면 이름과 전체 접근성 이름을 구분하고, 선택 상태를 표시한다. 위치·크기·회전·색·두께와 저장·되돌리기는 기존 처리 함수를 그대로 사용한다. 새 네이티브 의존성을 추가하지 않는다.

## 검증

타입 검사, 전체 테스트 31개 묶음·246개, 린트 오류 0개(기존 경고 32개)를 확인했다. iPhone 11 Pro 개발 앱에서 ROUTE B 아이콘, 상단 프리셋 세 개, 선택 강조, 아래 다듬기/선 스타일 탭과 색·두께를 확인했다. 선 스타일 탭에서 프리셋을 바꿔도 탭·민트색·두께 117%·경로 선택 영역이 유지됐고, 상단 되돌리기로 프리셋이 복구됐다. 상단 완료로 시트를 닫으면 평소 도구가 돌아왔다. QA에서 바꾼 프리셋은 되돌리기로 원래 값에 복원했다.

문서 검사와 diff 공백 검사도 통과했다. 네이티브 변경이 없어 재빌드하지 않고 실행 중인 개발 앱에서 확인했다. 다른 기기 크기·큰 글자 설정은 실기기 미검증이며, 새 영상 생성과 TestFlight 배포는 이번 범위가 아니다.

## 어긋남 기록

기존 FRD가 경로 프리셋을 아래 시트에 두도록 정한 부분은 사용자 승인으로 상단 배치로 개정한다. PRD의 기능 범위는 같고, 결정문에는 배치 개정을 덧붙인다. 새 용어는 없다.

## 후속 QA: 그리기 진입 시 화면 흔들림

2026-10-04 사용자가 그리기를 누르면 편집 화면이 새로고침되는 듯 위아래로 흔들린다고 제보했다. 기존 손그림 화면은 하단 완료 영역이 없는 별도 미리보기를 새로 만들어 캔버스 크기·중심이 바뀌고, 부모의 재생 플래그도 전환해 진입·복귀 때 재생을 초기화했다. 기존 편집 캔버스와 배경을 유지하고, 그 위에 그리기 입력·붓·팔레트만 올리도록 수정했다. 부모가 측정한 캔버스 크기로 손그림 좌표를 계산하고, 진행 중인 획은 SharedValue 경로로 같은 미리보기에 연결한다. 재생 플래그를 바꾸지 않고 조작 중 일시 정지를 사용해 현재 시점에서 멈추고 완료 후 이어 간다. 새 획 저장·세션 되돌리기 규칙은 유지한다.

실제 편집 컴포넌트의 회귀 검사에서 진입·복귀 전후 미리보기 인스턴스가 하나로 유지되고, 크기·재생 플래그가 같으며, 그리는 동안 기존 편집 제스처가 막히고 완료 후 복귀함을 확인했다. iPhone 11 Pro에서도 캔버스 상하 위치 유지, 숫자·경로 재생 정지와 완료 후 이어짐, 한 점 입력·네온 붓 전환·되돌리기를 확인했다. 확인용 획은 되돌려 원래 초안을 유지했다. 최종 전체 테스트 31개 묶음·247개, 타입·린트 오류 0개(기존 경고 32개)·문서·diff 검사 통과. 사진 배경에서 확인했으며 영상 배경과 다른 화면 크기는 이번 실기기 미검증이다.

## 후속 작업: 러닝 데이터 프리셋 상단 배치

2026-10-04 사용자가 상단의 가로 스크롤 프리셋과 아래 항목/글자 스타일 구성을 승인했다. 근거는 [편집 FRD](../../specs/frd/result-editing.md) §7 러닝 데이터와 문구다. 코너·글래스·레일·스택·스탯바·원라인의 기존 순서를 유지하고, 작은 배치 미리보기와 이름으로 표시한다. 상단은 되돌리기·프리셋·완료, 아래는 항목·폰트·글자 색과 초기화다. 선택 변경·되돌리기·시트 재진입 시 현재 프리셋이 보이도록 스크롤을 맞춘다. 기존 위치·크기·문구·표시 항목은 유지한다.

되돌리기 아이콘은 사용자에게 별도로 제안하며 이번 배치 작업에서 교체하지 않는다.

타입·전체 테스트 31개 묶음 247개·린트 오류 0개(기존 경고 32개)·문서·diff 검사 통과. iPhone 11 Pro에서 원라인·스택·레일 전환, 선택한 프리셋의 자동 노출, 글자 스타일 탭·기본 폰트·검정색 유지, 되돌리기, 완료 후 평소 도구 복귀와 재진입 시 원라인 노출을 확인했다. 확인용 프리셋 변경은 되돌려 원래 초안을 보존했다. 좌우 스와이프는 미러링 자동 조작으로 재현하지 못해 직접 확인이 남는다. 다른 화면 너비·큰 글자 설정은 실기기 미검증이며 영상 생성과 TestFlight 배포는 하지 않는다.
