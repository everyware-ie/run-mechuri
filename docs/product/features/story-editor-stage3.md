## 불빛 러너

현재 다른 색은 밝은 선과 주변 빛에 같은 파스텔색을 사용한다. 선택색은 유지하면서 주변 빛을 더 진한 같은 계열의 색으로 나누고 최근 잔광·완성 선에 가는 밝은 중심을 더한다. 움직이는 머리도 밝은 중심으로 바꾼다. 기본 따뜻한 흰색은 기존 표현을 유지한다. 미리보기·썸네일·Swift 영상에 함께 연결하며 프레임마다 React 상태를 갱신하지 않는다. 기존 블러 층의 수는 유지한다.

## 그리기와 내 스타일

그리기는 시안의 붓 버튼·왼쪽 굵기·아래 색 선택을 따른다. 손그림은 처음부터 경로 위·글자 아래에 보이며 다시 그리기에서 고친다. 내 스타일에는 기본 배경·스타일·다듬기 값만 담고 기기 안에 이름을 붙여 최대 20개 저장한다. 내 사진/영상인 스타일은 적용 대상의 배경을 유지한다. 기존 초안·결과물과 영상·썸네일 연결을 포함한 3단계 단위로 검증·정리한다.

## 검증

타입·문서 검사·iOS Debug 빌드 통과. 전체 29개 테스트 묶음의 237개 검사 통과, 린트 오류 0개·기존 경고 32개다. 저장·삭제 동시 실행, 20개 한도, 저장 실패 후 재시도, 개인 배경·문구·위치 보존, 옛 결과물 호환, 손그림 세션의 한 단계 되돌리기와 썸네일 범위를 검사했다.

실기기는 iPhone 11 Pro(iOS 26.6.2)의 개발용 앱에서 확인했다. 펜·형광·네온, 손그림만 지우는 지우개와 획 복원, 한 점 입력, 전체 편집 되돌리기(4획→3획), 앱 재실행 후 초안·스타일 보존, 이름 입력·저장, 민트→주황 변경 후 스타일 재적용을 확인했다. 손그림 3획이 결과물 다시 편집에도 그대로 열렸다. 저장 파일에서 다듬기 값 18/0을 확인했고 스타일에 트랙·장소·문구·손그림·위치가 없는 것도 확인했다.

미리보기에서 민트·주황 선의 밝은 중심과 주변 빛을 확인했다. 실제 생성한 민트 영상은 AVFoundation으로 1080×1920·30fps·12초와 전체 360프레임 디코딩 성공을 확인했다. 첫 장면과 완주 장면에서 펜·형광·네온 손그림이 처음부터 같은 위치에 남으며, 글자가 위에 합성되고 완주한 불빛 러너에 밝은 중심이 나타난다. 보관함과 결과물 상세 썸네일도 손그림 전체를 담는다.

다른 기기 크기·실제 사진/영상 배경 조합·나머지 색과 극단 굵기의 실기기 조합은 이번에 확인하지 않았다. 손그림이 없는 기존 영상과 이번 생성 영상의 속도를 같은 조건으로 비교하지 않았으므로 성능 향상이나 추가 비용의 실측값은 주장하지 않는다. 새 표현은 새로 생성한 영상부터 적용하며 이미 만든 MP4를 바꾸지 않는다. TestFlight 배포는 별도 요청에 따른다.

## 구현에서 정한 제한과 저장

손그림은 최대 100획·총 10,000점으로 제한하고 한계에 도달하면 안내한다. 1080×1920 좌표와 붓·색·굵기를 저장하며, 화면 밖 좌표와 비정상 저장값은 읽을 때 정리한다. 같은 획 안에서 가까운 점은 합쳐 터치 입력과 보관 비용을 줄인다. 지우개는 선분의 교차까지 검사해 빠르게 가로질러도 획을 놓치지 않게 한다. 붓 굵기는 캔버스 기준 4~48px이다.

영상의 손그림은 투명 이미지로 한 번 그려 모든 프레임에서 재사용한다. 손그림이 없는 기록은 추가 이미지를 만들지 않는다. 투명 캔버스 메모리 약 8MB가 손그림 결과물 생성 동안 추가될 수 있고, 기존 최종 프레임 재사용·영상 규격은 유지한다. 초안·결과물에는 손그림을 보관하고 내 스타일에는 그림과 사용자 사진 경로를 보관하지 않는다.


## 사용자 자료 보존

실기기 QA 직전의 사용자 초안을 백업하고 QA 후 같은 내용으로 복원했다. 기존 보관함 결과물 18건을 보존하고 손그림 3획이 들어간 확인용 영상 1건을 추가로 남겼다. 검사용으로 만든 스타일 2개는 제거했다. 개인 사진·좌표·영상·화면 캡처는 레포에 넣지 않았다.
