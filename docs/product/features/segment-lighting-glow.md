## 디자인 방향

큰 검정 테두리는 구간을 쉽게 찾게 하지만 경로 그림보다 먼저 눈에 들어오고 지도 핀처럼 보인다. 경계 표시는 남기되 선에 맺힌 작은 빛으로 표현한다. 테두리 없이 경로와 같은 색의 작은 점, 밝은 중심, 가장자리로 사라지는 빛을 겹친다. 거리 경계에 도달하면 빛이 짧게 밝아졌다가 차분해진다. 완주 끝점은 마지막 정지 장면에서 살짝 더 밝게 남겨 마무리를 알린다. 마지막 프레임을 재사용하는 인코딩 방식도 유지한다. 선 두께를 두 배로 키워도 점은 두 배까지 커지지 않도록 비례를 완만하게 한다.

실제 거리 기준·마지막 잔여 구간·경계 위치·재생 시간은 앞선 수정과 같다. 미리보기와 썸네일은 표식 컴포넌트를 공유하고 Swift 영상에 같은 크기·빛 분포를 적용한다. 빛은 반경 안의 그라데이션으로 그려 추가 블러 비용을 피한다. 애니메이션은 기존 UI 스레드에서 계산한다.

## 문서 정합성

사용자의 디자인 수정 요청에 따라 FRD §6-3의 어두운 테두리 요구를 발광 표식으로 개정한다. PRD의 자동 거리 구간·완료 경계 유지와 기본 프리셋 3개 결정은 유지한다. 새 용어와 저장 항목은 만들지 않는다.

## 검증

자동 검사와 iOS 빌드 후 기본·굵은 선의 미리보기와 새 영상을 확인한다. 검증 범위와 남은 확인은 완료 후 이 노트와 QA 기록에 모은다.

설치된 Skia의 `RadialGradientProps` 타입을 확인했다. 관련 문서: [React Native Skia 공식 문서](https://shopify.github.io/react-native-skia/docs/shaders/gradients/).

### 확인 결과 (2026-10-04)

전체 테스트 222개/26개 묶음·타입·문서 검사 통과, 린트 오류 0개(기존 경고 32개), iOS Debug 빌드 성공. React 검토에서 표식 컴포넌트는 미리보기·썸네일이 공유하며 시간 변화는 SharedValue로만 처리한다. 진행률 샘플에 따른 새 React 렌더는 추가하지 않았다.

iPhone 11 Pro에서 따뜻한 흰색/두께 100%와 민트색/두께 약 200%(저장값 199%)를 확인했다. 테두리 없이 작은 밝은 중심과 경로색의 빛이 남으며, 완성 카드·보관함도 같은 표식을 사용한다. 같은 약 1.95km 기록의 민트색 새 영상은 1080×1920·30fps·12초·360프레임 전체 디코딩 성공. 500m 도달 직후와 1.5km 이후, 마지막 정지 장면에서 표식·빛을 육안 확인했다. 이전 검정 테두리 영상과도 비교했다.

기존 결과물 17건을 모두 보존하고 검증 영상 1건을 추가했다. 원래 초안은 QA 전 바이트와 동일하게 복원했다. 생성된 영상·스크린샷·GPS는 로컬 QA용이며 커밋하지 않는다.

다른 화면 크기, 실제 사진·영상 배경, 팔레트의 나머지 색은 이번 실기기 검증에서 확인하지 않았다. 인코딩 속도를 새로 측정하지 않았으며 기존 최종 프레임 재사용·출력 품질 설정은 유지한다. 기존 MP4는 바뀌지 않고 새 영상부터 적용된다. 구현 완료 당시 TestFlight 배포는 보류했으며, 이후 사용자 요청으로 빌드 29에 포함했다.
