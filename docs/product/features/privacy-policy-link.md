# 앱 안 개인정보 처리방침 링크

근거: [홈과 보관함 FRD](../../specs/frd/home-and-library.md) §1-2 개인정보 처리방침, [러닝 기록 선택 FRD](../../specs/frd/run-record-selection.md) §3 권한, [출시 범위 결정](../../decisions/2026-09-16-release-and-editor-scope.md) §7 확인만 하고 넘어간 것.

## 착수 확인 (2026-09-20)

사용자가 오늘 QA는 확인 완료로 알렸고, 배포 전에 앱 안 처리방침 링크를 먼저 추가하도록 요청했다. 이후 앱 표시 이름을 Runary·러너리로 정리한다.

2026-10-12 사용자 제보에 따라 기존 승인 범위의 열기 실패를 수정했다. 규약·문서/Git 컨벤션·용어집과 홈 FRD를 다시 확인했다.

## 구현

첫 실행 안내의 시작 버튼 아래와 홈 목록 하단에 작은 텍스트 링크를 둔다. 기록이 없어도 접근할 수 있고 터치 높이는 44pt 이상이다. 기존 공개 주소 https://phs00.notion.site/privacy 를 앱 내 시스템 브라우저로 연다. 열기 요청 실패 시 안내와 다시 시도 버튼을 제공한다. 동의 체크나 건강 권한 요청은 추가하지 않는다.

### 2026-10-12 열기 실패 보완

사용자 제보를 미러링에서 재현했으며 `Linking.openURL`의 외부 열기가 실패해 오류 안내가 표시됐다. Expo의 기존 `expo-web-browser`로 시스템 브라우저를 앱 안에서 열도록 변경했다. 중복 탭을 막고 닫기·실패 뒤에는 다시 열 수 있다. 기존 의존성을 사용해 네이티브 패키지를 추가하지 않았다. [Expo의 개인정보 페이지 열기 안내](https://docs.expo.dev/versions/latest/sdk/webbrowser/)

후속 미러링에서 공개 처리방침의 제목·본문이 로그인 없이 표시되는 것을 확인했다. 상세 OS 거절 원인은 확인하지 않았으므로 외부 열기 실패와 앱 내 열기 성공을 구분해 기록한다. 약관 초안은 비공개로 작성했으며, 이용약관의 공개·앱 연결은 필수 여부와 운영 정보 검토 단계에 남긴다.

타입·문서 검사와 브라우저 열기·닫은 뒤 재열기·중복 탭·실패 재시도 회귀 3개가 통과했다. 린트는 오류 0개·기존 경고 30개다. 미러링에서 닫기 후 원래 홈 위치로 복귀한 뒤 재열기도 확인했다. 개인정보 처리방침의 베타 적용 범위 문구는 남아 있으며 정식 제출 전 별도로 검토한다.

## 어긋남 기록

팀 결정은 있었으나 FRD에 노출 위치와 실패 동작이 없었다. 홈·기록 선택 FRD와 PRD에 함께 보완한다.

## 검증

2026-09-20 공개 브라우저에서 로그인 요구 없이 처리방침 제목·본문을 확인했다. 타입·문서 검사와 변경 화면·링크 컴포넌트 린트가 통과했다. 전체 린트는 기존 오류 16개·경고 5개와 동일하다. 링크 컴포넌트는 두 화면에서 공용으로 사용하며 개발 앱에 반영했다. 실제 아이폰에서 링크를 눌러 브라우저로 이동하는 동작은 사용자 QA로 확인한다.

2026-09-20 PR #63을 머지해 TestFlight `1.0.0(23)` 내부 배포를 완료했다. [배포 기록](../../ops/build-and-dev-commands.md)에 검증과 제출 결과를 남겼다.
