# 드로잉·각인 단계 안내와 자유 전환

- 상태: 로컬 구현 완료, 실제 화면 확인은 사용자 진행
- 근거: [결과물 편집 FRD §1 화면 구조·§4 조작](../../specs/frd/result-editing.md), [2026-09-08 퍼널 논의 및 09-11 보완](../../decisions/2026-09-08-scope-and-roles.md)
- 확인: 2026-09-11 사용자는 이전·다음으로 자연스럽게 단계를 배우면서 탭으로도 이동하는 구성을 요청했다. 각인부터 작업한 사용자가 드로잉을 조정한 뒤 다시 각인을 거치게 되는 불편함을 함께 고려했다.

## 구현

- 편집 진입은 드로잉이다. 다음은 각인으로, 각인의 이전은 드로잉으로, 완료는 공유로 이동한다. 드로잉 단계의 보조 버튼은 배경 바꾸기다.
- 상단 완료는 어느 단계에서도 공유로 이동한다. 편집 순서는 안내이며 필수 통과 절차가 아니다.
- 같은 `edit.tsx`에서 단계만 전환하므로 드로잉·각인의 위치·크기·프리셋·문구는 유지된다. 전환 시 대기 중인 다듬기·각인 업데이트를 반영하고 완료 전에 최신 값을 저장한다.
- 탭은 사용자 후속 요청에 따라 숫자 없이 `드로잉 / 각인`으로 표시하고, 도구를 접어도 남긴다. 탭을 누르면 해당 도구를 펼친다.
- 전체 미리보기는 어느 단계에서든 배경·드로잉·각인을 함께 보여준다. 각인 프리셋 변경으로 드로잉을 자동 재배치하지 않는다.
- 드래그·핀치는 현재 선택한 단계의 대상에 적용한다. 다른 대상을 단순 탭하면 단계와 도구를 함께 전환하고, 같은 대상의 단순 탭은 도구를 접는다. 작은 손떨림과 실제 이동을 구분한다.
- 일반 패널은 실제 내용 높이에 맞춰 252~320 범위에서 조정하고 키보드 표시 중에는 176을 유지한다. 이전·다음은 패널 안에 고정하고 도구 내용만 스크롤한다. 키보드가 뜨면 하단 이동 버튼을 숨겨 입력 영역을 확보하며 상단 완료·단계 탭은 유지한다.
- React 구성·접근성 검토: 기존 편집 상태를 재사용하고 단계 전환 시 컴포넌트 전체를 재마운트하지 않는다. 탭은 선택 상태를, 이동 버튼은 목적지를 접근성 라벨로 제공한다.

## 검증

- 실제 `edit.tsx`를 변환한 경량 React/RN 모의 실행에서 이전·다음, 자유 탭 전환, 프리셋·문구·위치 보존, 선택한 대상의 드래그, 다른 대상 직접 탭, 드로잉에서 바로 완료를 확인했다. 네이티브 제스처나 화면의 육안 검증을 대체하지 않는다.
- TypeScript 검사 통과. 편집 화면의 기존 Reanimated/ref 관련 ESLint 오류 16건은 그대로이며 추가 오류는 없다.
- 문서 정합성과 `git diff --check` 통과.
