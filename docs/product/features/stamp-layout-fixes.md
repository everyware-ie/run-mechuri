# 각인 단위와 통계 배치 수정

- 근거: [경로 렌더링 FRD §7 각인](../../specs/frd/route-rendering.md) (`approved`)
- 확인: 2026-09-11 사용자 요청. BPM 중복, 간결·스탯바의 인접 통계 겹침, 글래스의 기본 위치 잘림을 수정한다.

## 구현

- BPM 라벨이 있는 프리셋은 값에 단위를 붙이지 않는다.
- `stamp-columns.ts`에서 한글·넓은 영문을 고려한 통계 폭을 계산하고, 최소 간격을 확보한 뒤 필요할 때 글자를 함께 축소한다. 완성 값 기준으로 공간을 확보해 카운트업 중 배치가 움직이지 않는다.
- 간결·스택·스탯바·글래스에 적용한다. 글래스 패널 자체는 캔버스 좌우 여백 안에 유지한다.
- `route-preview.tsx`와 Swift `RouteRendererModule.swift`에 같은 계산을 적용한다. 썸네일용 보수적 각인 경계 계산도 제공한다.
- 기존 완성 영상은 그대로이며 새로 생성하는 영상부터 적용된다.

## 검증

- 216개 통계 배치 조합에서 추정 글자 경계의 간격·가용 폭·카운트업 위치 유지 확인.
- TypeScript, 문서 정합성, iOS 개발 빌드 통과. 연결된 아이폰에 설치했다.
- 기존 Reanimated 관련 ESLint 오류 2건은 별도다. 실제 서체의 육안 확인은 사용자 진행.
