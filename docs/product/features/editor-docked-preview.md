# 편집 도구와 전체 미리보기

- FRD: [결과물 편집](../../specs/frd/result-editing.md) (`approved`, §2 미리보기·§4 조작·§5 다듬기·§7 각인)
- 구현 상태: 구현 완료 (로컬)

## 확인한 범위 (2026-09-10)

사용자가 낮은 도구 패널 위에 9:16 전체 미리보기를 배치하고, 패널을 접으면 미리보기를 키우는 추천안을 적용하기로 했다.
배경·경로·각인의 상대 배치는 유지한다. 저장되는 변형값이나 각인별 서체, 영상 렌더러는 바꾸지 않는다.
대시보드는 기존 정사각형 중앙 크롭을 유지한다. 경로 중심으로 썸네일을 맞추는 안은 후속 검토이며 이번 구현 대상이 아니다.

## 구현

- 미리보기와 도구 패널을 위아래로 배치해 서로 겹치지 않게 한다.
- 남은 영역에 9:16 캔버스 전체가 들어가도록 맞추고, 같은 크기와 contain 좌표계를 배경·경로·각인·터치 판정에 사용한다.
- 2026-09-11: 상단 미리보기 도구 줄을 제거하고 재생·스토리 영역·접기 버튼을 기존 하단 단계 탭 행에 합쳤다. 별도 행을 추가하지 않아 기존 상단 도구 줄의 공간을 미리보기에 돌려준다. 접은 상태에서도 같은 버튼을 유지하며 터치 영역은 최소 44로 둔다.
- 제스처 안내는 드로잉/각인 도구의 스크롤 내용으로 옮긴다. 문구 탭에서는 입력 안내만 보여준다.
- 드로잉 패널에서 프리셋과 직선·코너 슬라이더를 함께 보여준다. 슬라이더를 고급 설정 안에 숨기지 않는다. 2026-09-11부터 하단 이전·다음 버튼 공간을 확보하기 위해 도구 내용은 패널 안에서 스크롤한다.
- 각인 도구는 프리셋·넣을 것·문구 탭으로 나누며, 긴 항목 목록만 패널 내부에서 스크롤한다.
- 패널 접기 버튼·손잡이 아래로 끌기·현재 대상의 미리보기 탭으로 도구를 접는다. 다른 대상의 탭은 단계 선택으로 처리한다. 접은 상태에서도 단계 탭과 도구 열기를 그림 바깥에 유지한다(2026-09-11 [단계 안내](editor-tool-modes.md)).
- 일반 도구 패널 높이는 실제 도구 내용에 맞춰 252~320 범위에서 조정하며, 키보드가 뜨면 176으로 줄여 미리보기 공간을 확보한다. 패널과 미리보기 전체를 `KeyboardAvoidingView` 안에 둔다.

## 도구 스크롤 최소화 (2026-09-11)

- 드로잉 초기화는 제스처 안내 줄 오른쪽에 회전 화살표와 `초기화` 문구를 함께 표시한다. 프리셋과 구별되도록 옅은 테두리의 작은 칩으로 표현하며, 시각적 높이는 최소 28·터치 영역은 최소 44로 둔다. 아이콘만으로 의미를 알기 어렵다는 사용자 피드백을 반영했다.
- 도구 내용의 세로 간격은 4이며, 초기화가 있는 안내 줄도 실제 내용 높이 측정에 포함한다. 재생·접기 버튼의 터치 영역은 44를 유지한다.
- 각인 프리셋 7개는 4열·2행으로 배치한다. 패널 높이는 `onContentSizeChange`로 측정한 내용과 고정 조작 영역을 합산하며, 도구별 측정값을 보관한다.
- 일반 패널은 252~320 안에서 필요한 만큼만 높아진다. 접으면 56, 키보드가 뜨면 176이다. 긴 장소나 큰 글자로 최대 높이를 넘으면 내부 스크롤을 유지한다.
- `ScrollView`의 바운스를 꺼서 내용이 다 들어갈 때 불필요하게 위아래로 움직이지 않게 한다.

## 검증

- TypeScript, 문서 정합성과 `git diff --check` 통과.
- 편집 화면 린트는 기존 ref/immutability 규칙 오류 21건에서 16건으로 줄었다. 완전한 린트 통과 상태는 아니다. 새 레이아웃 함수는 린트 통과.
- 작은 화면·일반 화면·도구를 접은 화면·키보드로 가용 높이가 줄어든 화면을 포함한 7가지 크기에서 전체 캔버스 경계, 터치 좌표 왕복, 드래그 배율과 접기 시 확대를 검증했다.
- iOS 번들 생성 성공. 실기기 미러링에서 도구와 미리보기 분리, 접기·다시 열기, 각인 3개 탭, 입력 포커스, 미리보기 탭으로 접기를 확인했다. 각인 터치의 캔버스 좌표가 각인 영역 내부임도 확인했다.
- 실제 아이폰 소프트 키보드가 뜬 배치도 사용자가 확인 완료했다 (2026-09-11).
