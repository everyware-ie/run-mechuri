# 앱 재개와 기존 기록 호환성

## 착수 근거

2026-10-25 사용자가 [잠금화면 FRD](../../specs/frd/run-live-activity.md) 링크와 앱 즉시 재개·명시적 재개 때 현황 복구 제안을 확인하고 “네 순차적으로 진행해 주세요”라고 승인했다. [측정 FRD](../../specs/frd/internal-run-tracking.md)의 관련 조건을 먼저 개정했다.

첫 작업은 앱에서 GPS 준비 없이 같은 기록을 재개하고, 재개 저장 성공 뒤 지운 현황 생성을 다시 허용하는 것이다. 워치의 준비 조건과 공개 빌드 범위는 유지한다. 반복 위치 권한 안내는 코드 점검과 실기기 재현을 구분한다.

[배경 선택 FRD §2 기본 이미지](../../specs/frd/background-selection.md#2-기본-이미지)와 [홈과 보관함 FRD §2 결과물](../../specs/frd/home-and-library.md#2-결과물)의 원래 배경 유지 기준으로 기존 결과물·내 스타일의 배경 호환성과 저장 영상 표시를 확인한다. 이전 배경의 ID와 에셋을 별도 복원 목록으로 유지하고 새 배경 선택은 6장으로 유지한다. 기록 출처 구분은 시안을 먼저 준비한다.

## 검증

- TypeScript와 문서 정합성 검사 통과. 전체 ESLint는 오류 0개, 기존 경고 30개다.
- 전체 Jest 50개 묶음 371개와 이후 추가한 재개 화면 검사 4개 통과. 화면 진입으로 자동 재개하지 않는 것, 즉시 재개 호출, 이전 네이티브 앱 호환과 권한 오류 표시를 확인했다.
- 순수 Swift 측정·저장 133개와 잠금화면 36개 통과. 이전 카드의 삭제 이벤트가 새 카드의 복구를 막지 않는 회귀 검사를 추가했다.
- 미리보기 동작 및 일반·내부 빌드 설정 검사 통과.
- iOS 시뮬레이터 Debug 전체 앱·잠금화면 확장 빌드 성공(arm64, x86_64). 실기기 서명·설치 성공과 구분한다.
- 새 앱으로 GPS 준비 없이 시작 → 일시정지 → 즉시 재개 → 종료·저장을 확인했다. 시뮬레이터 저장 기록은 30.56초·0km이며, 약 73초의 일시정지 시간은 제외되고 재개 시 새 구간이 생겼다.
- 하트 샘플로 편집 → 영상 생성 → 보관함 재생 → 다시 편집까지 확인했다. 저장한 1080×1920·12초 영상의 마지막 프레임에서 새벽 강변 배경과 하트, 왼쪽 아래 거리, 오른쪽 위 날짜·시간·페이스 배치를 확인했다. 시뮬레이터 결과이며 실기기의 기존 데이터 확인과 구분한다.
- 기록 출처 비교 시안은 브라우저에서 두 구성과 카드 선택 동작을 확인했다. 제품 화면에 적용하지 않았다.

### 10/25 실기기 확인

`ce89946`의 아이폰·워치·잠금화면 확장 iphoneos Debug 빌드와 깊은 서명 검증을 통과했다. 기존 인증서·프로파일을 재사용해 iPhone 11 Pro의 TestFlight 42번 위에 개발 앱 `1.0.0(1)`을 설치했고 실제 설치 버전과 LAN 번들 실행을 확인했다. 사용자는 여러 작업을 묶어 배포하기로 했으므로 TestFlight에는 제출하지 않는다.

5.06초에서 일시정지한 QA 러닝의 잠금화면 현황을 사용자가 직접 지웠다. 앱을 다시 여는 것만으로는 재생성되지 않았고, 같은 러닝 ID의 삭제 상태가 저장되어 있었다. `이어서 달리기`를 누르면 GPS 준비 없이 재개되며 현황 생성 성공과 삭제 상태 해제를 확인했다. 다시 일시정지했을 때 측정 시간은 21.15초, 구간은 2개였다. 중간 일시정지 약 288초는 측정 시간에서 제외됐다. 사용자가 잠금화면의 실제 재표시도 확인했다. QA 러닝은 종료해 완료 상태로 저장했다.

사용자가 재확인한 문구는 “Runary의 실시간 현황을 계속 허용하시겠습니까?”이며 선택지는 “허용 안 함 / 항상 허용”이었다. 위치 권한이 아니라 iOS의 실시간 현황 허용 안내다. 앞선 위치 권한 추정은 이 확인으로 정정한다. [ActivityAuthorizationInfo](https://developer.apple.com/documentation/activitykit/activityauthorizationinfo)는 사용자가 허용한 상태를 읽고 관찰하는 API다. 앱이 ‘항상 허용’을 대신 선택하는 기능은 제공하지 않는다. 이번 안내를 없애기 위해 위치 권한이나 백그라운드 GPS 정책을 바꾸지 않는다. ‘항상 허용’ 선택 이후에도 반복되는지는 아직 확인하지 않았다.

업데이트 후 보관함 26개와 기존 편집 초안이 유지됐다. 초안을 다시 열어 예전 그라디언트 배경을 확인했고, 내 스타일 `111`의 배경 이름도 `점심`으로 표시됐다. 스타일 적용·추가·삭제는 하지 않았다. 사라진 배경 파일의 복원 분기는 자동 회귀 검사로 확인했으며, 실기기의 사용자 파일을 일부러 지워 검증하지 않았다.

## 남은 확인과 한계

실기기에서 앱 즉시 재개와 삭제한 현황 복구는 확인했다. 이번 버전의 앱 강제 종료 후 중단 복구, 야외 GPS 수신 후 구간 연결, 내 스타일 적용 후 저장은 추가 확인하지 않았다. 기존 장거리 측정·워치 검증과 자동 회귀 검사 결과는 유지한다. 실시간 현황의 ‘항상 허용’ 선택 이후 안내가 반복되는지도 아직 확인하지 않았다.

이전 배경 ID가 저장소에 남아 있는 결과물·내 스타일을 보존한다. 42번에서 다른 스타일을 저장·삭제하며 이미 배경 ID가 null로 덮인 내 스타일은 원래 배경을 추측해 복원하지 않는다. 사용자의 사진이나 영상을 임의의 기본 배경으로 바꾸지 않는다.
