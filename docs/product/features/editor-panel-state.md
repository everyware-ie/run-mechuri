# 편집 대상 전환 시 전체 미리보기 유지

근거: [결과물 편집 FRD](../../specs/frd/result-editing.md) §1 화면 구조, §4-1 대상 선택.

## 착수 확인 (2026-09-20)

사용자가 도구를 접고 전체 미리보기를 보는 중에 경로와 러닝 데이터를 번갈아 선택하면 도구가 매번 열리는 문제를 제보했다. 선택한 탭만 바뀌고 전체 미리보기를 유지하는 방향으로 요청했다.

## 수정

대상 선택 함수가 도구를 강제로 펼치지 않도록 한다. 미리보기에서 대상을 탭하거나 하단 단계 탭을 눌러도 접힘·펼침 상태를 유지한다. 펼친 상태에서 이전·다음으로 단계를 바꾸면 그대로 펼쳐져 있다. 문구 입력 키보드는 단계 전환 시 닫는다.

도구를 여는 동작은 기존 화살표 버튼으로 제공한다. 선택된 대상을 다시 탭했을 때 펼친 도구를 접는 기존 동작도 유지한다. 편집값 저장과 대상 선택 점선은 그대로다.

## 어긋남 기록

기존에는 단계 선택이 도구 펼치기까지 수행했다. 대상 선택과 도구 표시 상태를 분리해 사용자가 확보한 미리보기 크기를 유지한다.

## 검증

타입·문서 검사를 통과했다. 전체 린트는 기존 오류 16개·경고 5개와 같으며 새 오류는 없다. 단계 선택 함수의 공통 호출 경로에서 펼침 상태를 변경하지 않는지 확인했고 개발 앱을 새로고침했다. 실제 아이폰의 접힌 상태에서 양방향 대상 전환은 사용자 QA로 확인한다.
