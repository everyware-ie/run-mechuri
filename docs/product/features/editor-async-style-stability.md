# 내 스타일 적용 중 화면 전환 안정성

- 근거: [결과물 편집 FRD](../../specs/frd/result-editing.md) §1 화면 구조와 §12 내 스타일 (`approved`), [PRD](../../specs/prd/running-drawing-mvp.md) §7 결과물의 형태.
- 착수 확인: 사용자가 후속 안정성 검증·수정을 계속 진행하도록 요청한 범위에서 점검한다. 새 정책과 기능을 추가하지 않는다.

스타일을 적용하려면 기본 배경 파일 준비를 기다려야 할 수 있다. 화면에 적용 중 상태가 반영되기 직전에 완료를 누르면, 이벤트 콜백은 아직 적용 전의 상태를 읽어 내보내기로 이동했다. 실제 편집 화면 회귀 검사에서 같은 갱신 안에 스타일 적용과 완료를 호출해 재현했다.

적용 시작·종료 상태를 ref에도 즉시 기록한다. 화면 버튼의 대기 표시와 별개로 완료와 그리기 진입이 같은 상태를 확인한다. 빠른 중복 적용은 하나만 진행하고, 나가기·되돌리기·화면 이탈은 작업 번호를 바꾸어 이전 작업의 늦은 완료를 무시한다. 취소한 작업의 종료가 새로운 적용의 대기를 풀지 않아야 한다.

수정 전에는 적용 중에도 `/share`로 이동해 검사가 실패했다. 수정 후 적용 대기·성공·실패 후 재시도·도구 전환 취소·중복 요청·취소한 작업과 새 작업의 완료 순서를 실제 편집 컴포넌트 검사에서 확인했다. 전체 테스트 33개 묶음 266개, 타입 검사와 린트 오류 0개(기존 경고 30개)를 확인했다. 실제 손으로 같은 순간에 누르는 실기기 재현은 수행하지 않았으며, 이벤트 순서를 제어한 회귀 검사로 검증했다. 최종 결과는 QA 기록에도 남긴다. 개인 배경·문구·손그림·위치·크기 제외와 스타일 적용 한 단계 되돌리기 정책은 유지한다.
