# 러닝 데이터 라벨 가독성

- FRD: [경로 렌더링](../../specs/frd/route-rendering.md) §7-4-1 읽히는 것이 먼저다
- 근거 QA: [QA 기록](../../ops/qa-log.md) "러닝 데이터의 라벨 글씨가 흐리다"(2026-09-29), "라벨 글씨 가독성은 아직이다"(2026-10-06)
- 구현 상태: **FRD 확인 전.** 아직 코드를 고치지 않았다

## 무엇을 고치나

러닝 데이터에서 값(시간, 페이스 등)은 읽히는데 값 위의 라벨(TIME, PACE, 날짜)이 흐려서 밝은 배경에서 잘 안 보인다. 2026-09-30 확인에서 원인은 라벨만 투명도 50%인 크림색이라는 것이다. 값은 불투명하다.

[FRD §7-4-1](../../specs/frd/route-rendering.md)이 이미 "바탕이 무엇이든 읽혀야 한다"를 기준으로 두고 있다. 그래서 FRD를 고치는 일이 아니라 구현을 FRD에 맞추는 일이다. 구체적인 색과 두께는 FRD가 "실기기에서 보며 정한다"고 했으므로 이 노트에 정한 값과 확인 결과를 남긴다.

## 고칠 곳

편집 화면과 저장되는 영상이 같은 모양으로 그려져야 한다. 둘을 함께 고친다.

| | 파일 | 무엇 |
|---|---|---|
| 편집 화면 | `frontend/src/components/route-preview.tsx` | `muted`인 글씨의 투명도(`fillOpacity .5`) |
| 저장한 영상 | `frontend/modules/route-renderer/ios/RouteRendererModule.swift` | `mutedColor`(투명도 0.5)와 글씨에 거는 그림자 |

## 확인할 것

1. 흰 사진 한 장에서 편집 화면과 저장한 영상의 라벨을 나란히 본다. 영상의 라벨이 편집 화면보다 더 흐린지(QA 기록의 `[확인 필요]`)
2. 새 기본 배경 6장(특히 하늘이 밝은 `bg-3-track`, `bg-2-coast-road`)에서 라벨이 읽히는지
3. 글자 색을 흰색과 검정으로 바꿔도 읽히는지(FRD §7-4-1이 어느 색이든 또렷함 기준이 그대로라고 한다)
