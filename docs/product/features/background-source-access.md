# 배경 선택의 갤러리·촬영 진입

## 착수 근거

2026-10-25 사용자가 기본 이미지 증가로 갤러리·촬영 버튼이 스크롤 뒤에 가려지는 문제를 제보했다. 시안을 다듬은 뒤 기본 이미지 제목 오른쪽에 아이콘 두 개를 놓는 배치를 승인하고 구현을 요청했다.

[배경 선택 FRD §3-2 그 자리에서 찍기](../../specs/frd/background-selection.md#3-2-그-자리에서-찍기)의 소재 선택 배치를 반영한다. 상류 [PRD §6 배경 선택](../../specs/prd/running-drawing-mvp.md#배경-선택)의 기본 이미지·사용자 소재 범위와 권한 정책은 바뀌지 않는다.

## 구현

갤러리와 사진 촬영은 제목 오른쪽의 고정 아이콘으로 제공한다. 각각 44pt 터치 영역과 접근성 이름을 가지며 기존 선택 함수를 호출한다. 가로 스크롤에는 기본 이미지 6장만 둔다. 썸네일 폭을 54pt로 줄이고 중복 안내 문구를 없애 9:16 미리보기 공간을 확보한다. 사진 조정과 취소, 처리 중 비활성화는 기존 흐름을 유지한다.

## 검증

타입 검사와 전체 린트 통과(오류 0개, 기존 경고 30개). 기존 배경 저장·비동기 적용 테스트 16개와 문서 정합성 검사를 통과했다. 배치만 바꿨으므로 이를 그대로 복제하는 테스트는 추가하지 않았다.

iPhone 11 Pro의 개발 앱에서 제목 오른쪽의 두 아이콘과 확대된 9:16 미리보기를 확인했다. 갤러리 아이콘으로 시스템 사진·영상 선택기가 열렸고, 취소하면 기존 배경 선택으로 돌아왔다. 사진 촬영 함수와 권한 처리는 변경하지 않았으며 실제 촬영은 이번 확인에 포함하지 않았다. TestFlight 배포는 보류한다.
