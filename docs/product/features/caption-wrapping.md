# 문구 자동 줄바꿈과 입력 제한

- 근거: [경로 렌더링 FRD §7-6 한 줄 문구](../../specs/frd/route-rendering.md), [결과물 편집 FRD §7 각인과 문구](../../specs/frd/result-editing.md) (`approved`)
- 확인: 2026-09-11 사용자가 자동 줄바꿈과 제한 누락을 제보했다. FRD의 줄 기준 정책에 맞추는 오류 수정이다.
- 상태: 로컬 구현 완료, 실제 입력·영상의 육안 확인은 사용자 진행

## 구현 범위

- 임의의 40자 제한과 단일 행 입력을 제거한다. 결과물의 문구 폭·크기 기준으로 최대 3줄까지 입력하게 하고 줄 수와 제한 안내를 표시한다.
- 공통 드로잉 여백 8%를 기준으로 문구 폭을 잡고, 글래스의 내부 여백이나 날짜 영역은 추가로 확보한다.
- 어절 우선 자동 줄바꿈, 한 줄보다 긴 어절은 글자 단위 분할, 사용자가 넣은 줄바꿈은 원문에 보존한다. 자동 줄바꿈은 원문에 저장하지 않아 크기 변경 시 다시 흐른다.
- 3줄을 초과한 입력·붙여넣기는 들어갈 수 있는 부분까지만 반영한다. 삭제는 허용하고, 입력 후 크기·프리셋을 바꿔 4줄 이상이 된 기존 문구는 잘라내지 않는다.
- 모든 각인 프리셋의 문구를 여러 텍스트 행으로 배치한다. 위에 붙은 문구는 위쪽으로 늘리고, 글래스 머리글·레일 등은 문구 높이를 포함해 카드·통계 영역을 계산한다.
- 같은 줄바꿈 결과를 Swift에 전달해 미리보기와 새로 생성하는 영상의 행 구성을 맞춘다. 저장되는 편집값은 사용자가 입력한 원문 그대로다.
- 기존 각인 프리셋의 서체를 유지한다. 이번 수정은 줄바꿈·입력 제한을 대상으로 한다.

## 검증

- 한글 어절, 긴 어절, 직접 개행·빈 줄, 40자 초과 입력, 3줄 붙여넣기 제한, 전체 선택 후 더 짧은 여러 줄 붙여넣기, 크기 변경 후 삭제, 자동 줄 합치기, 기존 뒷부분 보존을 확인했다.
- 7개 각인 프리셋 × 4개 배율의 28개 조합에서 실제 미리보기 행과 공통 줄바꿈 결과 일치, 좌우 여백, 행간, 글래스 문구·큰 통계의 간격을 검사했다.
- TypeScript와 새 순수 함수·공유 화면의 ESLint 통과. 기존 편집 화면 16건·미리보기 2건의 Reanimated/ref 관련 ESLint 오류는 별도이며 증가하지 않았다.
- Swift 변경을 포함한 iOS 개발 빌드 통과. 기존 저장 영상은 자동 재생성하지 않는다.
