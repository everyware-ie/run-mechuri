# 기록 선택 출처 배지

2026-10-25 사용자가 작은 배지 시안과 날짜순 정렬 유지 범위를 확인하고 “네 구현 진행해 주세요”라고 승인했다. [자체 기록 편집 FRD §2 목록과 선택](../../specs/frd/runary-record-editing.md#2-목록과-선택)과 [기록 선택 FRD §2-3 목록 항목](../../specs/frd/run-record-selection.md#2-3-목록-항목)을 먼저 동기화했다.

`record-selection.tsx`의 기존 행에서 날짜 위에 출처 배지를 표시한다. 지표 줄의 출처 문구를 옮기는 변경이며, 조회·정렬·선택 처리와 샘플 진입은 유지한다. 배지는 별도 버튼으로 만들지 않아 행 전체를 누르는 기존 동작과 접근성 읽기 순서를 유지한다.

타입 검사와 문서 정합성 검사를 통과했다. 전체 린트는 오류 0개·기존 경고 30개이며, 기록 권한·자체 기록 회귀 검사 19개도 통과했다. 표시만 옮기는 변경이므로 같은 내용을 반복하는 새 테스트는 추가하지 않았다.

iPhone 11 Pro 미러링에서 Runary 5.41km와 Apple 건강 5.34km 기록에 각 배지가 표시되는 것을 확인했다. 날짜 위의 배지, 지표 줄의 중복 제거, 날짜순 혼합 목록과 샘플의 별도 진입을 확인했다. 기존 개발 앱과 Metro로 반영했으며 새 네이티브 빌드는 필요하지 않았다. TestFlight는 다른 작업과 묶어 배포하며 이번 변경만으로 제출하지 않는다.
