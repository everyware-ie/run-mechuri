# 인스타그램 공유 실패·화면 전환 검증

- FRD: [내보내기·공유](../../specs/frd/export-and-share.md) §3 인스타그램 스토리로 공유 / [공통 규칙](../../specs/frd/common-rules.md) §3 실패 (`approved`)
- PRD: [러닝 경로 그림 MVP](../../specs/prd/running-drawing-mvp.md) §6 인스타로 넘기는 마지막 한 걸음
- 착수 확인: 2026-10-04 사용자가 안정성 점검을 계속하도록 요청했다. TestFlight 배포는 보류한다.

## 범위

공유 화면과 보관함 상세에서 영상 확인·인스타 설치 확인·공유 요청의 오류를 사용자에게 안내한다. 진행 중 연속 탭은 한 요청으로 처리하고, 화면을 떠난 뒤 이전 요청의 완료·실패가 안내나 홈 이동을 실행하지 않도록 한다. 인스타 미설치 시 사진 앱 저장으로 안내하는 기존 흐름과 인코딩 품질은 유지한다.

## 구현과 검증

`frontend/src/hooks/use-instagram-share.ts`를 공유 화면과 보관함 상세에서 사용한다. 영상 존재 확인, 인스타그램 설치 확인, 네이티브 공유 요청을 하나의 예외 처리 안에 둔다. 실패하면 보관함의 결과물을 유지하고 다시 공유하거나 기기에 저장하도록 안내한다. 영상 자체가 사라진 경우에는 다시 편집·같은 기록으로 새로 만들기로 안내한다. 공유 화면에도 영상 존재 확인을 추가했다.

진행 중인 요청은 ref로 즉시 잠근다. React가 버튼을 갱신하기 전 연속 탭에도 파일 확인과 공유를 한 번만 실행한다. 공유 버튼은 비활성화되며 접근성의 작업 중·사용 불가 상태를 제공한다. 요청이 끝나면 다시 누를 수 있다.

앱 안에서 화면을 떠나면 요청 세대를 무효화한다. 각 비동기 단계가 끝났을 때 확인해 이전 요청이 새로 인스타그램을 열거나 미설치·실패 안내, 홈 이동을 실행하지 않게 한다. 떠났다가 같은 화면으로 돌아와도 이전 요청은 무효다. 이미 실행된 인스타그램 앱을 닫거나 공유를 취소하는 변경은 아니다. 앱 내부의 화면 포커스를 사용하며 앱 전경·배경 상태와 구분한다.

- 네이티브 경계를 대역으로 둔 React 검사 15개 통과: 영상 없음·숨은 화면, 연속 탭, 파일 누락, 미설치, 파일 확인·설치 확인·공유 오류 후 재시도, 단계별 화면 이탈, 떠났다가 복귀, 언마운트 후 성공·실패.
- 전체 테스트 181개(19개 묶음), 타입 검사 통과. 린트 오류 0개, 기존 경고 32개.
- 실제 iOS 공유 오류를 재현했다는 뜻은 아니다. 코드에서 확인한 예외 경계와 요청 수명 문제를 대역 검사로 검증했다. 네이티브 공유 API·패키지·인코딩 설정은 바꾸지 않았다.

## 남은 실기기 확인

공유 화면과 보관함 상세에서 빠르게 여러 번 누를 때 인스타그램이 한 번 열리는지, 실행 후 돌아오는 흐름과 미설치 시 사진 앱 저장 안내가 이어지는지 확인한다. 실제 인스타그램 실행·복귀, VoiceOver, 영상 결과물 품질 비교는 이번에 수행하지 않았다. TestFlight 배포도 보류한다.

## 어긋남 기록

기존 실패 처리와 공유 정책에 맞추는 안정성 수정이며 제품 정책 변경은 없다.
