# 러닝 데이터 터치 영역을 항목별로 나누기

근거: [결과물 편집 FRD](../../specs/frd/result-editing.md) §4-1 대상 선택.

## 착수 확인 (2026-09-20)

사용자가 코너 프리셋의 터치 영역이 거리와 오른쪽 통계를 큰 사각형으로 감싸는 문제를 제보했다. 날짜처럼 나누고 다른 프리셋도 확인해 달라고 요청했다.

## 수정

가까운 사각형을 연쇄적으로 합치는 방식 대신 항목 이름과 값을 묶는다. 거리 강조값, 날짜, 문구는 각각 독립된 영역으로 둔다. 코너·스탯바·레일의 항목 사이 빈 공간을 큰 사각형에 포함하지 않는다. 스택과 기존 간결도 텍스트 덩어리별로 나누며 원라인은 한 줄 전체가 하나의 영역이다. 구분선과 레일 선은 자체 영역만 갖고 다른 항목을 연결하지 않는다.

글래스는 실제로 보이는 카드 배경 전체를 선택 영역으로 유지한다. 카드 밖으로 나간 내용은 별도 영역을 가진다. 여러 영역 중 어디를 선택해도 러닝 데이터 전체가 함께 이동·확대된다. 선택 점선과 터치 판정은 같은 사각형을 쓴다. 한글 장소명은 영문과 같은 좁은 글자 폭으로 계산하지 않아 글자 왼쪽도 선택할 수 있게 한다. 썸네일 크롭과 출력 배치는 바꾸지 않는다.

## 어긋남 기록

기존의 거리 기준 묶음은 작은 간격을 연쇄적으로 연결해 큰 빈 공간을 포함했다. FRD의 실제 내용에 가까운 선택 원칙을 항목 단위로 구체화한다.

## 검증

타입·변경 파일 린트·기존 미리보기 회귀 검사가 통과했다. 7개 프리셋에서 50%·100%·300% 크기와 이동, 텍스트 선택, 코너의 빈 공간, 카드 배경, 한글 장소명, 꺼진 항목을 확인했다. JS 변경으로 로컬 서버에서 반영하며 네이티브 재설치는 필요 없다. 실제 아이폰의 선택감은 사용자 QA로 확인한다.
