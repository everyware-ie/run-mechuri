# 기록 선택의 출처 표시 시안

2026-10-25 사용자가 작업 순서를 승인했다. 기록 출처 구분은 시안을 먼저 확인한 뒤 구현한다. [10/20 회의](../meetings/2026-10-20/synthesis.md)와 [자체 측정 기록 편집 FRD](../specs/frd/runary-record-editing.md)를 참고한다.

## 두 가지 제안

작은 배지 안은 날짜 위에 `Runary` 또는 `Apple 건강`을 표시한다. Runary에만 옅은 주황색을 쓰고 건강 기록은 중립색으로 둔다. 출처가 지표 문장에 섞이지 않아 훑어보기 쉽다.

별도 줄 안은 날짜와 지표 아래에 `Runary에서 측정` 또는 `Apple 건강에서 가져옴`을 둔다. 출처의 의미는 더 분명하지만 카드 높이가 늘어난다.

두 안 모두 날짜순을 유지하며 출처별 탭이나 목록 분할은 추가하지 않는다. 색을 구분하지 못해도 출처 문구를 읽을 수 있어야 한다. 샘플은 실제 기록과 구분한다. 시안의 기록 값은 레이아웃 확인용 예시다.

## 결정 상태

2026-10-25 사용자가 작은 배지 안을 선택하고 구현을 승인했다. [자체 기록 편집 FRD §2 목록과 선택](../specs/frd/runary-record-editing.md#2-목록과-선택)에 최종 구성을 반영했다. 별도 줄 안은 비교용 제안으로 남긴다.
