# 러닝 잠금화면 디자인

2026-10-19 대화에서 사용자가 선택한 거리 중심안이다. 기능 동작의 정본은 [잠금화면 FRD](../specs/frd/run-live-activity.md)이며, 이 문서는 시각 구성을 보관한다.

## 구성

상단에는 작은 주황 점과 `RUNARY`, 오른쪽에는 측정 상태를 둔다. 가운데 왼쪽에는 거리를 가장 크게 쓰고 km는 작게 붙인다. 오른쪽에는 `일시정지` 또는 `재개` 버튼을 둔다.

아래에는 얇은 구분선과 함께 시간·평균 페이스·심박을 한 줄로 나눈다. 각 항목은 제목 위, 표시값 아래의 구조다. **세 항목 모두 왼쪽 정렬한다.** 심박 제목도 아이콘과 값 묶음의 왼쪽 시작선에 맞춘다. 심박 아이콘은 유지한다.

## 시안 기준값

색·크기 값은 확정한 시안을 네이티브 화면으로 옮길 때의 출발점이다. 시스템 글꼴과 접근성 크기, 실제 위젯 여백에 맞춰 조정하되 정보의 순서와 정렬은 유지한다.

| 요소 | 기준 |
|---|---|
| 바탕 | `#11161B` |
| 강조 | Runary 주황 `#FF572B` |
| 주요 숫자 | 밝은 전경, 시스템 숫자 글꼴. HTML 시안 54pt·좁은 너비 38pt. 네이티브 시작값 50pt이며 긴 숫자는 단위를 남기고 축소. 측정·일시정지에 같은 크기 적용 |
| 제목·단위 | 보조 전경 `#AAB2BB`, 제목 11pt |
| 보조 지표 | 기본 19pt, 좁은 시안 17pt. 값과 단위의 크기 구분 |
| 심박 | 심장 윤곽 아이콘 14pt, 숫자, 작은 bpm 순서 |
| 제어 | 같은 크기의 44pt 원형 버튼 두 개. 측정 중 일시정지는 어두운 바탕, 재개는 주황 바탕. 종료는 네모 아이콘이며 항상 같은 모습 유지 |
| 외곽 | 시안 높이 160pt, 내부 가로 여백 14~16pt. 실제 시스템 크기와 큰 글자에서는 잘림 없이 재배치 |

미수신은 자연스러운 하이픈 `-`로 쓴다. 심박값이 빠져도 제목과 아이콘의 정렬이 바뀌지 않아야 한다. 거리 자릿수와 시간 길이가 늘어날 때 버튼이나 다른 지표를 침범하지 않도록 확인한다.

## 후속 제안: 상태가 바뀌어도 배치를 유지한다

작은 정사각형 제어와 일시정지 후 하단에 버튼을 추가하는 안 모두 사용자가 어색하다고 지적했다. 특히 일시정지 때문에 거리 크기·지표 위치·버튼 생김새가 함께 바뀐 것이 문제였다. 두 안을 구현 기준으로 쓰지 않는다.

새 검토안은 측정 중과 일시정지에서 거리 크기·지표 위치·버튼 영역을 고정한다. 거리 오른쪽에 같은 위치와 크기의 기본 제어와 `종료`를 항상 둔다. 사용자는 이 배치가 훨씬 자연스럽다고 확인한 뒤, 버튼에서도 현재 상태를 알아보기 쉽게 다듬어 달라고 요청했다.

사용자가 후속으로 문구 없이 일시정지·재개·종료 아이콘만 표시하는 방식을 제안했다. 이에 기본 제어는 측정 중 회색 바탕의 일시정지 아이콘, 멈췄을 때 주황 바탕의 재생 아이콘으로 표시한다. 종료는 네모 아이콘으로 바꾼다. 두 버튼은 같은 크기의 44pt 원형이며, 측정·일시정지 전후 위치와 크기를 유지한다. 종료 버튼은 상태에 따라 변하지 않는다. 화면의 버튼 문구는 빼되 VoiceOver에는 각각 `러닝 일시정지`, `러닝 재개`, `러닝 종료`를 제공한다.

일시정지 후 버튼이 새로 생기거나 아래로 이동하지 않는다. 종료도 일시정지를 먼저 누르는 조건 없이 같은 자리에서 선택한다. 하단 지표의 열 너비는 심박 수신 여부와 관계없이 고정해 `142`가 `-`로 바뀌어도 제목이 움직이지 않게 한다. 작은 너비 대응은 두 상태에 똑같이 적용한다.

종료를 누르면 카드 안에 확인 문구와 거리·시간, `돌아가기`·`종료·저장`을 보여준다. 돌아가기는 직전의 측정 또는 일시정지 상태로 복귀한다. 저장 성공 뒤 카드가 사라진다. 사용자가 아이콘 제어 시안을 확인하고 후속 구현을 요청했다. 이 구성을 네이티브 구현의 기준으로 삼는다.

## 확인한 것과 남은 것

대화 시안에서 거리 중심 선택, 심박 아이콘 유지, 하단 항목 왼쪽 정렬을 사용자가 확인했다. 브라우저 시안의 일시정지·재개와 좁은 너비를 확인했다. 실제 SwiftUI 카드 컴포넌트를 별도 시뮬레이터 시안 앱에서 렌더링했다. 320·360·430pt의 기본 높이 160pt, 측정·일시정지·종료 확인과 심박 미수신 배치를 확인했다. 320pt에서 큰 글자와 긴 거리·시간을 함께 사용해 km·bpm이 잘리는 문제를 고쳤다.

이 검증은 실제 ActivityKit 잠금화면 실행을 대신하지 않는다. 잠금 인증·실기기 큰 글자·Dynamic Island 배치는 별도 확인한다.
