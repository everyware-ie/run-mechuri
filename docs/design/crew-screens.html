예시 데이터
크루 "새벽 한강 러닝", 멤버 4명(서연, 도윤, 하늘, 준호), 최근 7일(11/10～11/16) 공유 기록 8건
보는 사람은 하늘
거리, 시간, 경로 모양, 지도는 비교용으로 만든 값이며 실측 기록이 아님
지도는 실제 지도가 아니라 도로를 흉내 낸 그림
정한 것
경로 모양은 빼거나 자르지 않고 항상 처음부터 끝까지 보여 줌 (11/16)
지도로 보여 줄지는 공유하는 사람이 고르고, 지도로 보여 줄 때는 가게와 건물 이름을 숨길 수 있음 (11/17)
출발점과 도착점 주변 가리기와 가릴 장소 지정은 번거롭고 어색해서 뺌 (11/17)
장소 이름을 숨겨도 길은 보여서 지도를 공유하면 달린 곳을 알 수 있음. 위치를 알리고 싶지 않으면 지도를 끄고 경로 모양만 공유함
고를 것여러 안 중에서 고르는 곳 (C1～C5)A, B처럼 글자를 붙인 후보 카드를 나란히 놓음절 제목 옆에 "하나 고르기"나 "여러 개 고르기"를 표시함
흐름순서대로 따라가며 디테일을 다듬는 곳 (F1～F3)화면을 쓰는 순서대로 화살표로 이음문구, 요소, 빠진 단계를 봄. 1부의 현수 안으로 이어 그림

흐름에 쓴 안: 크루 자리 C1-A(네 번째 탭), 가입 방식 C2-A(초대 링크), 크루 화면 C4 A에서 [>]로 B, 크루 홈 C5-D(한 줄 요약과 목록)
모두 현수 안(11/16)이며 회의 결과에 따라 흐름 화면도 바뀜

여러 안 중에서 고르기

안끼리 같은 예시 데이터로 그렸음
파란 테두리와 "현수 안" 띠가 붙은 카드가 현수가 고른 안이며 회의에서 확인함. 나머지 후보는 흐리게 보임 (마우스를 올리면 또렷해짐)
"흐름에 쓴 안" 초록 표시는 2부 흐름을 그릴 때 쓴 안

C1

크루를 어디에 둘까

A, B 중 하나 고르기현수 안: A

다이어리가 들어오면서 하단 탭이 보관함, 러닝, 다이어리 세 개가 됨
두 안을 가입한 크루 보기, 초대하기, 크루가 없을 때 세 장면으로 나란히 비교함
현수 제안: A. 크루가 여러 개가 되어도 크루 홈 제목에서 바꾸면 되어 늘리기 쉬움 (11/16, 회의에서 확인)

고르는 기준

  • 탭이 네 개일 때 이름이 줄바꿈 없이 읽히는가
  • 크루를 자주 열 이유가 탭 하나를 차지할 만큼 큰가
  • 초대와 설정을 찾기 쉬운가

고르면 바뀌는 것

  • B를 고르면 승인된 다이어리 FRD를 고쳐야 함
  • A를 고르면 크루 탭이 곧 크루 화면이라 C4와 C5를 합쳐 봄
C2

첫 버전에 넣을 가입 방식

A～D 중 여러 개 고르기현수 안: A, B, D

기획서의 가입 방식 후보 네 가지
어느 길로 와도 같은 크루 소개로 모이게 함
현수 안(11/16): A, B, D를 첫 버전에 넣음. 빠듯하면 A를 먼저 넣고 B, D로 넓힘. C는 보류

고르는 기준

  • 받은 사람이 누가 어디로 초대했는지 알 수 있는가
  • 회원 검색에서 동명이인을 구분할 수 있는가
  • 찾기 목록에서 원하는 크루를 구분할 수 있는가

고르면 바뀌는 것

  • C를 고르려면 친구 추가 기능부터 도입해야 함 확인 필요
  • D를 고르면 C3 승인제를 함께 정해야 함
  • 로그인 뒤 같은 초대로 돌아오는 흐름은 지민의 로그인 작업과 이어짐
C3

가입에 승인을 둘까

C2-D를 넣을 때 정함현수 안: 크루장이 고름

크루 찾기(C2-D)로 처음 보는 사람이 들어올 때 필요한 질문
현수 안(11/16): 크루장이 크루마다 바로 가입과 승인 후 가입 중에서 고름. 크루 정보의 소개 탭에서 크루장에게만 보임

고르는 기준

  • 가입 전과 승인 대기 중이 한눈에 구분되는가
  • 크루마다 승인 여부를 고르게 할지
C4

가입한 뒤 크루 화면의 구성

A, B 중 하나 고르기현수 안: A에서 [>]로 B

크루 소개 아래에 기록을 어떻게 둘지
C1-A를 고르면 이 화면이 크루 홈이 되므로 C5와 함께 봄
현수 안(11/16): A를 크루 홈으로 두고, 소개 오른쪽 [>]를 누르면 B의 탭 화면이 열림
크루 정보의 탭은 기록과 소개 둘. 멤버 탭은 11/17에 빼고 소개 탭의 멤버 줄로 멤버 목록을 엶

고르는 기준

  • 최신 러닝까지 한 번에 가는 것과 소개를 다시 찾기 쉬운 것 중 무엇이 중요한가
C5

크루 홈 구성

A～F 중 하나 고르기 (섞어도 됨)현수 안: D

같은 기록 8건을 여섯 가지로 배치함
현수 안(11/16): D. 오늘 몇 명이 달렸는지 요약이 먼저 보이는 점이 좋음
크루 홈에서는 C4 현수 안의 소개 아래에 둠
다른 안과 섞어 더 다듬을 여지는 회의에서 봄

고르는 기준

  • 최근 누가 뛰었는지, 경로 모양이 어떤지 가장 빨리 파악되는가
  • 자주 뛰는 한 사람(서연 3회)이 홈을 채우지 않는가
  • 기록이 적은 날에도 크루 분위기가 전달되는가

고르면 바뀌는 것

  • F는 기획서에 사진 공유가 없어 범위부터 정해야 함
2부: 흐름

순서대로 따라가며 디테일 다듬기

화살표 위의 말은 다음 화면으로 넘어가는 행동
흐름마다 "다듬을 점"을 보고, 문구와 요소와 빠진 단계를 확인함

F1초대받아 가입하기

크루원이 링크를 보내고, 받은 사람이 가입해서 공유를 고르기까지

다듬을 점

  • 초대 시트의 선택지는 C2 결과에 따라 바뀜
  • 링크로 연 소개에서 누가 어디로 초대했는지 읽히는가
  • 자동으로 공유되고 고르는 것은 항목뿐이라는 점이 읽히는가
  • 지도 안내("달린 곳을 지도 위에 보여 줘요")가 이해되는가
  • 빈 크루 홈이 어색하지 않은가

이 흐름에서 정할 것

  • 가입 전 안내(F1-2)와 항목 고르기(F1-3)로 자동 공유 동의가 충분한지 확인 필요
  • 평균 심박을 켠 채로 안내해도 되는지. 현수 안(11/17): 켜 둠. 출시 전 법률 확인에서 문제가 되면 끔 확인 필요

크루원이 공유한 러닝이 있으면 F1-4 대신 기록이 쌓인 크루 홈(F2-1)이 열림

F1-3에서 지도를 켰을 때

F2크루원 기록 보기

크루 홈에서 서연의 러닝을 열고 지도로 바꿔 보기까지
경로는 어느 보기에서나 처음부터 끝까지 그림

다듬을 점

  • 경로 모양과 지도 사이 전환이 자연스러운가
  • 장소 이름을 숨긴 지도가 어색하지 않게 읽히는가
  • 거리와 시간이 전체 러닝 기준이라는 점이 읽히는가

이 흐름에서 정할 것

  • 장소 이름 숨기기의 기본값 확인 필요 (시안은 켬)
  • 건강 앱 심박을 크루에 공유하는 정책 확인 필요
  • 여러 크루 가입을 허용할지 (크루 홈 제목의 ▾) 확인 필요

이 화면에서 정할 것

  • F2-4 경로가 없는 러닝을 거리와 시간만 공유할지 확인 필요

F3내 공유 관리

본인만 보는 화면. 크루 홈 오른쪽 위 설정에서 들어감
경로 모양은 항상 공유되며 지도로 보여 줄지와 장소 이름 숨기기는 공유하는 사람이 고름

다듬을 점

  • 설정만 보고 크루원에게 무엇이 보이는지 설명할 수 있는가
  • 지난 러닝을 한 건씩 바꾸는 자리가 찾기 쉬운가
  • 시트에서 이 러닝에만 적용된다는 점이 읽히는가
  • 공유를 취소한 뒤 다시 공유하는 자리가 찾기 쉬운가

이 흐름에서 정할 것

  • 여러 크루에 공유한 러닝이면 크루마다 따로 바꿀지 확인 필요

회의에서 정할 것

고를 것

  1. C1 크루의 자리: 네 번째 탭 또는 다이어리 안. 현수 제안은 A(11/16) (시안에서 새로 나온 질문)
  2. C2 첫 버전 가입 방식. 현수 안은 A, B, D이고 빠듯하면 A부터(11/16). 친구 목록(C)과 친구 추가 기능은 보류 (기획서 확인 필요)
  3. C3 승인제. 현수 안은 크루장이 고름(11/16). 크루장을 누가 맡는지는 크루 만들기와 함께 정함 (레퍼런스)
  4. C4 가입한 뒤 크루 화면의 구성. 현수 안은 A를 크루 홈으로 두고 소개 오른쪽 [>]를 누르면 B의 탭 화면이 열리는 안(11/16) (레퍼런스)
  5. C5 크루 홈 구성. 현수 안은 D(11/16). 사진 기록을 범위에 넣을지 (레퍼런스)

흐름에서 정할 디테일

  1. F1 자동 공유 동의를 받는 자리. 현수 안은 가입하면 자동 공유가 켜지고 끄지 않으며 가입 직후 보여 줄 항목만 고름(11/16) (기획서 확인 필요)
  2. F2 장소 이름 숨기기의 기본값. 시안은 켬 (기획서 확인 필요)
  3. F2 건강 앱 심박을 크루에 공유하는 정책. 현수 안은 처음에 켜 둔 채로 안내하고 끌 수 있게 하는 것(11/17). 출시 전 법률 확인에서 민감정보이거나 미리 켠 동의가 문제가 되면 끔 (기획서 확인 필요)
  4. F2 여러 크루 가입을 허용할지. 허용하면 크루 전환이 필요하고 크루마다 가입 직후 항목 고르기가 열림 (기획서 확인 필요)
  5. F2-4 경로가 없는 러닝의 공유 (기획서 확인 필요)
  6. F3 지난 러닝을 한 건씩 바꾸거나 빼는 방법. 현수 안은 내 기록 상세의 공유 줄을 눌러 이 러닝의 공유 항목을 바꾸거나 공유를 취소하는 것(11/17) (기획서 확인 필요)
