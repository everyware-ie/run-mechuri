크루 화면 시안

크루 기획서 초안과 UI 레퍼런스의 후보를 화면으로 옮김
가입 방식, 크루 홈, 크루원에게 보이는 범위를 같은 예시 데이터로 비교함

근거: 크루 기획서 (draft) UI 레퍼런스 시각 기준: 디자인 시스템 PR #137 하단 탭: 다이어리 PR #136 기준
예시 데이터
크루 "새벽 한강 러닝", 멤버 4명(서연, 도윤, 하늘, 준호), 이번 주(11/10～11/16) 공유 기록 8건
보는 사람은 하늘
거리, 시간, 경로 모양, 지도는 비교용으로 만든 값이며 실측 기록이 아님
지도는 실제 지도가 아니라 도로를 흉내 낸 그림
11/16 정한 것
경로 모양은 빼거나 자르지 않고 항상 처음부터 끝까지 보여 줌
지도 보기에서 출발·도착 주변의 상세 위치(지도 배경, 주소, 장소 이름)는 기본으로 가림
집이나 회사 같은 장소는 사용자가 더해서 가림
지도 보기도 첫 버전에 넣으며 공유하는 사람이 켬
가린 영역 안의 경로 끝점과 주변 도로로 위치를 짐작할 수 있다는 점은 정확한 경로를 우선해 받아들임

0크루를 어디에 둘까

다이어리가 들어오면서 하단 탭이 보관함, 러닝, 다이어리 세 개가 됨
크루가 들어갈 자리가 기획서에 아직 없어 두 안을 그림

비교할 점

  • 탭이 네 개일 때 이름이 줄바꿈 없이 읽히는가
  • 크루를 자주 열 이유가 탭 하나를 차지할 만큼 큰가

정할 것

  • 크루의 자리 기획서에 없는 질문

1크루에 들어오는 길

기획서의 가입 방식 후보 네 가지
어느 길로 와도 같은 크루 소개 화면으로 모이게 함

초대 링크회원 검색 초대친구 목록 초대 (도입 시)앱에서 크루 찾기
모두크루 소개 (2A)가입공유 미리보기 (3A)켜기 또는 나중에크루 홈 (4)

비교할 점

  • 링크를 쉽게 보낼 수 있는가. 받은 사람이 누가 어디로 초대했는지 알 수 있는가
  • 회원 검색에서 동명이인을 구분할 수 있는가
  • 찾기 목록에서 원하는 크루를 구분할 수 있는가. 바로 가입인지 승인이 필요한지 보이는가

정할 것

  • 첫 버전에 넣을 가입 방식 확인 필요
  • 친구 추가 기능을 도입할지 확인 필요
  • 크루를 누가 어떻게 만드는지 기획서에 없는 질문

2크루 상세: 가입 상태에 따라

같은 크루 화면에서 버튼 자리와 아래 내용만 바뀜
가입 전에는 크루가 공개한 소개까지만 보임

비교할 점

  • 가입 전, 승인 대기 중, 가입 완료가 한눈에 구분되는가
  • 가입 후 최근 러닝이 바로 보이는 구성(2C)과 기록·소개를 탭으로 나눈 구성(2D)

정할 것

  • 승인제를 둘지, 둔다면 크루마다 고르게 할지
  • 가입 후 상세 구성

3가입 직후: 공유를 고른다

가입을 마치면 크루원에게 보일 모습을 먼저 보여 주고 자동 공유를 켤지 고르게 함
경로 모양은 항상 공유됨
지도와 평균 심박은 따로 켬

비교할 점

  • 공유 대상과 항목을 화면만 보고 설명할 수 있는가
  • "나중에"를 골랐을 때 빈 크루 홈이 어색하지 않은가

정할 것

  • 자동 공유 동의를 어디에서 받을지 확인 필요

4크루 홈 후보

같은 기록 8건을 여섯 가지로 배치함
레퍼런스의 다섯 후보에 더해 기록순 피드를 넓은 카드와 작은 썸네일로 나눔

비교할 점

  • 최근 누가 뛰었는지, 경로 모양이 어떤지 어느 화면에서 가장 빨리 파악되는가
  • 자주 뛰는 한 사람(서연 3회)이 홈을 채우지 않는가
  • 기록이 적은 날에도 크루 분위기가 전달되는가

정할 것

  • 크루 홈 구성 (섞어도 됨. 예: 4D의 요약 줄 + 4B 목록)
  • 사진 기록(4F)은 기획서 범위 밖이라 넣을지부터 정하기

5기록 상세: 크루원에게 보이는 것

서연이 공유한 같은 러닝을 하늘이 열었을 때
경로는 어느 보기에서나 처음부터 끝까지 그림
지도 보기는 서연이 지도 공유를 켰을 때만 열림

비교할 점

  • 가린 곳과 보이는 곳을 화면만 보고 설명할 수 있는가
  • 지도에서 가린 영역이 어색하지 않게 읽히는가

정할 것

  • 출발·도착 주변을 얼마만큼 가릴지 확인 필요 (시안은 200 m 예시, 가리기는 기본으로 켬)
  • 경로가 없는 러닝을 거리와 시간만 공유할지 확인 필요
  • 건강 앱 심박을 크루에 공유할 때의 정책과 동의 범위 확인 필요

6내 공유 설정

본인만 보는 화면
경로 모양은 항상 공유되며 가리기는 지도 보기에만 적용됨
점선 원 안은 크루원에게 상세 위치가 가려지는 영역

비교할 점

  • 설정만 보고 크루원에게 무엇이 가려지는지 설명할 수 있는가
  • 공유한 러닝을 한 건씩 거두는 자리가 찾기 쉬운가

정할 것

  • 공유하지 않을 러닝을 한 건씩 어떻게 뺄지 확인 필요
  • 공유한 러닝에 가릴 장소를 더하는 흐름 확인 필요

회의에서 정할 것

  1. 크루의 자리: 네 번째 탭(0A) 또는 다이어리 안(0B) (시안에서 새로 나온 질문)
  2. 첫 버전 가입 방식: 초대 링크, 회원 검색, 친구 목록, 앱에서 찾기 중 무엇을 넣을지 (기획서 확인 필요)
  3. 친구 추가 기능을 도입할지 (기획서 확인 필요)
  4. 크루를 누가 어떻게 만드는지 (기획서에 없음)
  5. 승인제를 둘지, 가입 후 상세를 기록 바로(2C)로 할지 탭(2D)으로 할지 (레퍼런스)
  6. 크루 홈 구성: 4A~4F 중 하나 또는 조합 (레퍼런스)
  7. 자동 공유 동의를 받는 자리와 한 건씩 빼는 방법 (기획서 확인 필요)
  8. 경로가 없는 러닝의 공유 (기획서 확인 필요)
  9. 출발·도착 주변을 얼마만큼 가릴지. 가리기를 기본으로 켜는 것은 11/16에 정함 (기획서 확인 필요)
  10. 건강 앱 심박을 크루에 공유하는 정책 (기획서 확인 필요)
  11. 여러 크루 가입을 허용할지. 허용하면 크루 홈 제목의 전환(▾)과 공유할 크루 선택이 필요 (기획서 확인 필요)

휴대폰 화면 안의 문구는 디자인 시스템의 문구 규칙(해요체, 수치 형식 5.41 km · 32:18 · 평균 5'58")을 따름
설명 글은 슴체 개조식으로 씀
