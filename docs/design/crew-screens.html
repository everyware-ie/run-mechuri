크루 화면 시안

크루 기획서 초안과 UI 레퍼런스의 후보를 화면으로 옮김
가입 방식, 크루 홈, 크루원에게 보이는 범위를 같은 예시 데이터로 비교함

근거: 크루 기획서 (draft) UI 레퍼런스 시각 기준: 디자인 시스템 PR #137 하단 탭: 다이어리 PR #136 기준
예시 데이터
크루 "새벽 한강 러닝", 멤버 4명(서연, 도윤, 하늘, 준호), 최근 7일(11/10～11/16) 공유 기록 8건
보는 사람은 하늘
거리, 시간, 경로 모양, 지도는 비교용으로 만든 값이며 실측 기록이 아님
지도는 실제 지도가 아니라 도로를 흉내 낸 그림
11/16 정한 것
경로 모양은 빼거나 자르지 않고 항상 처음부터 끝까지 보여 줌
지도 보기에서 출발점과 도착점 주변의 상세 위치(지도 배경, 주소, 장소 이름)는 기본으로 가림
집이나 회사 같은 장소는 사용자가 더해서 가림
지도 보기도 첫 버전에 넣으며 공유하는 사람이 켬
가린 영역 안의 경로 끝점과 주변 도로로 위치를 짐작할 수 있다는 점은 정확한 경로를 우선해 받아들임
고를 것여러 안 중에서 고르는 곳 (C1～C5)A, B처럼 글자를 붙인 후보 카드를 나란히 놓음절 제목 옆에 "하나 고르기"나 "여러 개 고르기"를 표시함
흐름순서대로 따라가며 디테일을 다듬는 곳 (F1～F3)화면을 쓰는 순서대로 화살표로 이음문구, 요소, 빠진 단계를 봄. 고를 것이 정해지기 전이라 기준안으로 그림

흐름의 기준안: 크루 자리 C1-A(네 번째 탭), 가입 방식 C2-A(초대 링크), 크루 홈 C5-D(한 줄 요약과 목록)
정한 안이 아니라 흐름을 이어 그리려고 고른 안이며, 고를 것의 결과에 따라 흐름 화면도 바뀜

1부: 고를 것

여러 안 중에서 고르기

안끼리 같은 예시 데이터로 그렸음
"흐름에 쓴 안" 표시는 2부 흐름을 그릴 때 쓴 안이며 정한 안이 아님

C1

크루를 어디에 둘까

A, B 중 하나 고르기

다이어리가 들어오면서 하단 탭이 보관함, 러닝, 다이어리 세 개가 됨
두 안을 가입한 크루 보기, 초대하기, 크루가 없을 때 세 장면으로 나란히 비교함

고르는 기준

  • 탭이 네 개일 때 이름이 줄바꿈 없이 읽히는가
  • 크루를 자주 열 이유가 탭 하나를 차지할 만큼 큰가
  • 초대와 설정을 찾기 쉬운가

고르면 바뀌는 것

  • B를 고르면 승인된 다이어리 FRD를 고쳐야 함
  • A를 고르면 크루 탭이 곧 크루 화면이라 C4와 C5를 합쳐 봄
C2

첫 버전에 넣을 가입 방식

A～D 중 여러 개 고르기

기획서의 가입 방식 후보 네 가지
어느 길로 와도 같은 크루 소개로 모이게 함

고르는 기준

  • 받은 사람이 누가 어디로 초대했는지 알 수 있는가
  • 회원 검색에서 동명이인을 구분할 수 있는가
  • 찾기 목록에서 원하는 크루를 구분할 수 있는가

고르면 바뀌는 것

  • C를 고르려면 친구 추가 기능부터 도입해야 함 확인 필요
  • D를 고르면 C3 승인제를 함께 정해야 함
  • 로그인 뒤 같은 초대로 돌아오는 흐름은 지민의 로그인 작업과 이어짐
C3

가입에 승인을 둘까

A, B 중 하나 고르기 (C2-D를 고를 때만)

크루 찾기(C2-D)로 처음 보는 사람이 들어올 때 필요한 질문
초대 링크나 회원 검색만 쓰면 정하지 않아도 됨

고르는 기준

  • 가입 전과 승인 대기 중이 한눈에 구분되는가
  • 크루마다 승인 여부를 고르게 할지
C4

가입한 뒤 크루 화면의 구성

A, B 중 하나 고르기

크루 소개 아래에 기록을 어떻게 둘지
C1-A를 고르면 이 화면이 크루 홈이 되므로 C5와 함께 봄

고르는 기준

  • 최신 러닝까지 한 번에 가는 것과 소개를 다시 찾기 쉬운 것 중 무엇이 중요한가
C5

크루 홈 구성

A～F 중 하나 고르기 (섞어도 됨)

같은 기록 8건을 여섯 가지로 배치함
섞는 예: D의 요약 줄 아래에 B의 목록

고르는 기준

  • 최근 누가 뛰었는지, 경로 모양이 어떤지 가장 빨리 파악되는가
  • 자주 뛰는 한 사람(서연 3회)이 홈을 채우지 않는가
  • 기록이 적은 날에도 크루 분위기가 전달되는가

고르면 바뀌는 것

  • F는 기획서에 사진 공유가 없어 범위부터 정해야 함
2부: 흐름

순서대로 따라가며 디테일 다듬기

화살표 위의 말은 다음 화면으로 넘어가는 행동
흐름마다 "다듬을 점"을 보고, 문구와 요소와 빠진 단계를 확인함

F1초대받아 가입하기

크루원이 링크를 보내고, 받은 사람이 가입해서 공유를 고르기까지

다듬을 점

  • 초대 시트의 선택지는 C2 결과에 따라 바뀜
  • 링크로 연 소개에서 누가 어디로 초대했는지 읽히는가
  • 공유 미리보기의 안내("상세 위치는 가려지고 경로는 그대로 보여요")가 이해되는가
  • "나중에"를 고른 뒤의 빈 홈이 어색하지 않은가

이 흐름에서 정할 것

  • 자동 공유 동의를 어디에서 받을지 확인 필요

F1-3에서 자동 공유를 켜면 기록이 쌓인 크루 홈(F2-1)으로 감

F2크루원 기록 보기

크루 홈에서 서연의 러닝을 열고 지도로 바꿔 보기까지
경로는 어느 보기에서나 처음부터 끝까지 그림

다듬을 점

  • 경로 모양과 지도 사이 전환이 자연스러운가
  • 지도에서 가린 영역이 어색하지 않게 읽히는가
  • 거리와 시간이 전체 러닝 기준이라는 점이 읽히는가

이 흐름에서 정할 것

  • 출발점과 도착점 주변을 얼마만큼 가릴지 확인 필요 (시안은 200 m 예시, 가리기는 기본으로 켬)
  • 건강 앱 심박을 크루에 공유하는 정책 확인 필요
  • 여러 크루 가입을 허용할지 (크루 홈 제목의 ▾) 확인 필요

예외 화면

이 화면에서 정할 것

  • 경로가 없는 러닝을 거리와 시간만 공유할지 확인 필요

F3내 공유 관리

본인만 보는 화면. 크루 홈 오른쪽 위 설정에서 들어감
경로 모양은 항상 공유되며 가리기는 지도 보기에만 적용됨

다듬을 점

  • 설정만 보고 크루원에게 무엇이 가려지는지 설명할 수 있는가
  • 공유한 러닝을 한 건씩 거두는 자리가 찾기 쉬운가

이 흐름에서 정할 것

  • 공유하지 않을 러닝을 한 건씩 어떻게 뺄지 확인 필요
  • 공유한 러닝에 가릴 장소를 더하는 흐름 확인 필요

고를 것

  1. C1 크루의 자리: 네 번째 탭 또는 다이어리 안 (시안에서 새로 나온 질문)
  2. C2 첫 버전 가입 방식 (여러 개 가능), 친구 추가 기능을 도입할지 (기획서 확인 필요)
  3. C3 승인제를 둘지 (레퍼런스)
  4. C4 가입한 뒤 크루 화면의 구성 (레퍼런스)
  5. C5 크루 홈 구성, 사진 기록을 범위에 넣을지 (레퍼런스)

흐름에서 정할 디테일

  1. F1 자동 공유 동의를 받는 자리 (기획서 확인 필요)
  2. F2 출발점과 도착점 주변을 얼마만큼 가릴지. 가리기를 기본으로 켜는 것은 11/16에 정함 (기획서 확인 필요)
  3. F2 건강 앱 심박을 크루에 공유하는 정책 (기획서 확인 필요)
  4. F2 여러 크루 가입을 허용할지. 허용하면 크루 전환과 공유할 크루 선택이 필요 (기획서 확인 필요)
  5. F2-4 경로가 없는 러닝의 공유 (기획서 확인 필요)
  6. F3 공유하지 않을 러닝을 한 건씩 빼는 방법, 공유한 러닝에 가릴 장소를 더하는 흐름 (기획서 확인 필요)
