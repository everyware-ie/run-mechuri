크루를 어디에 둘까

A, B 중 하나 고르기현수 안: A

다이어리가 들어오면서 하단 탭이 보관함, 러닝, 다이어리 세 개가 됨
두 안을 가입한 크루 보기, 초대하기, 크루가 없을 때 세 장면으로 나란히 비교함
현수 제안: A. 크루가 여러 개가 되어도 크루 홈 제목에서 바꾸면 되어 늘리기 쉬움 (11/16, 회의에서 확인)

  • 탭이 네 개일 때 이름이 줄바꿈 없이 읽히는가

고르면 바뀌는 것

  • B를 고르면 승인된 다이어리 FRD를 고쳐야 함

고르면 바뀌는 것

F0크루 만들기

만든 사람이 크루장이 되고, 만들자마자 초대로 이어지기까지
누구나 만들 수 있음. 공개 범위 단계(F0-4)는 크루 찾기를 넣을 때만 있음

다듬을 점

  • 이름과 소개의 글자 수 표시가 거슬리지 않는가
  • 고른 표지가 크루 홈에서 어떻게 보일지 짐작되는가
  • 비공개와 공개의 차이가 설명만 보고 이해되는가
  • 만들자마자 초대 시트가 뜨는 게 자연스러운가

이 흐름에서 정할 것

  • 크루 찾기를 첫 버전에 넣을지. 현수 안(11/18)은 뺌. 그러면 F0-4 단계와 크루 찾기 버튼이 빠짐 확인 필요
  • 집계 한 줄을 크루 수가 적을 때 숨길지 확인 필요
  • 크루 인원 상한과 한 사람이 만들 수 있는 크루 수 (기능정의서)

크루가 이미 있을 때

F1초대받아 가입하기

크루원이 링크를 보내고, 받은 사람이 가입해서 공유를 고르기까지

다듬을 점

  • 링크로 연 소개에서 누가 어디로 초대했는지 읽히는가
  • 자동으로 공유되고 고르는 것은 항목뿐이라는 점이 읽히는가
  • 지도 안내("달린 곳을 지도 위에 보여 줘요")가 이해되는가
  • 빈 크루 홈이 어색하지 않은가

이 흐름에서 정할 것

  • 가입 전 안내(F1-2)와 항목 고르기(F1-3)로 자동 공유 동의가 충분한지 확인 필요
  • 평균 심박을 켠 채로 안내해도 되는지. 현수 안(11/17): 켜 둠. 출시 전 법률 확인에서 문제가 되면 끔 확인 필요

크루원이 공유한 러닝이 있으면 F1-4 대신 기록이 쌓인 크루 홈(F2-1)이 열림

F2크루원 기록 보기

크루 홈에서 서연의 러닝을 열고 지도로 바꿔 보기까지
경로는 어느 보기에서나 처음부터 끝까지 그림

다듬을 점

  • 경로 모양과 지도 사이 전환이 자연스러운가
  • 장소 이름을 숨긴 지도가 어색하지 않게 읽히는가
  • 거리와 시간이 전체 러닝 기준이라는 점이 읽히는가

이 흐름에서 정할 것

  • 장소 이름 숨기기의 기본값 확인 필요 (시안은 켬)
  • 건강 앱 심박을 크루에 공유하는 정책 확인 필요
  • 여러 크루 가입을 허용할지 (크루 홈 제목의 ▾) 확인 필요

F3내 공유 관리

본인만 보는 화면. 크루 홈 오른쪽 위 설정에서 들어감
경로 모양은 항상 공유되며 지도로 보여 줄지와 장소 이름 숨기기는 공유하는 사람이 고름

  • 지난 러닝을 한 건씩 바꾸는 자리가 찾기 쉬운가
  • 시트에서 이 러닝에만 적용된다는 점이 읽히는가
  • 공유를 취소한 뒤 다시 공유하는 자리가 찾기 쉬운가

이 흐름에서 정할 것

F4크루장이 멤버 내보내기

크루장이 멤버 명단에서 멤버를 내보내기까지와 내보내진 사람이 보는 화면
크루 찾기를 빼도 초대 링크는 다른 사람에게 전달될 수 있어 첫 버전에 넣음(11/18)

다듬을 점

  • ⋯가 크루장에게만 보인다는 점이 자연스러운가
  • 확인 창만 보고 내보낸 뒤 무엇이 바뀌는지 알 수 있는가
  • 내보내진 사람에게 알리는 문구가 날카롭지 않은가

이 흐름에서 정할 것

  • 내보낸 멤버의 공유 러닝 처리. 시안은 크루에서 내림 확인 필요
  • 다시 들어오는 것을 막는 범위. 시안은 예전 초대 링크로 못 들어오고 크루장이 새로 초대하면 들어옴 확인 필요
  • 내보내진 사람에게 알릴지 확인 필요

내보내진 사람이 볼 때

F5크루장 넘기기와 크루 나가기

크루장이 나가려면 새 크루장에게 넘겨야 하고, 혼자 남았으면 크루를 삭제하고 나감
크루 나가기는 소개 탭 맨 아래에 있음(11/18)

다듬을 점

  • 넘기고 나가기 버튼만 보고 누구에게 넘기는지 알 수 있는가
  • 넘긴 뒤 내가 멤버가 됐다는 점이 읽히는가
  • 삭제하고 나가기가 너무 쉽게 눌리지 않는가

이 흐름에서 정할 것

  • 넘겨받는 사람의 동의를 받을지. 시안은 바로 넘기고 한 번 알림 확인 필요
  • 나간 멤버가 다시 들어오는 조건. 시안은 새 초대가 필요함 확인 필요

넘기기만 할 때 (F4-2의 크루장 넘기기)

혼자 남았을 때와 멤버가 나갈 때

회의에서 정할 것

App Store 가이드라인 1.2란
애플이 앱스토어에 올릴 앱을 심사할 때 쓰는 기준(App Store Review Guidelines) 가운데 "사용자가 만든 콘텐츠" 항목
사용자가 만들어 다른 사용자가 보는 글, 사진, 프로필이 있는 앱은 네 가지를 갖춰야 함
1) 부적절한 내용을 거르는 장치 2) 불쾌한 내용을 신고하고 제때 처리받는 수단 3) 괴롭히는 사용자를 막는 차단 4) 사용자가 연락할 수 있는 공개 연락처
갖추지 않으면 심사에서 반려될 수 있음. Runary에서는 크루 이름과 소개, 닉네임, 공유한 러닝, 사진이 들어간 결과물이 여기에 해당할 수 있음
크루 찾기(C2-D)와 사진 기록, 결과물 공유(C5-F)는 이 네 가지를 첫 버전부터 갖춰야 하게 만들어서 빼려고 함(11/18 현수 안)

  4. F2 여러 크루 가입을 허용할지. 허용하면 크루 전환이 필요하고 크루마다 가입 직후 항목 고르기가 열림 (기획서 확인 필요)

  6. F3 지난 러닝을 한 건씩 바꾸거나 빼는 방법. 현수 안은 내 기록 상세의 공유 줄을 눌러 이 러닝의 공유 항목을 바꾸거나 공유를 취소하는 것(11/17) (기획서 확인 필요)
  7. F0 집계 한 줄을 크루 수가 적을 때 숨길지. 크루 탭이 비었을 때와 크루 찾기 위에 둠(11/17) (현수 안)
