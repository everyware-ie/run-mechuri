투박해 보이는 이유 (관찰)

  • 선이 가늘고 밝은 한 겹이라 낮 사진이나 나뭇잎처럼 복잡한 배경에서 묻힘
  • 빛의 밝은 중심과 넓은 주변 빛이 잘 나뉘지 않아 네온 느낌이 약함. FRD §6-2는 불빛 러너를 "진한 주변 빛과 밝고 가는 중심"으로 나누라고 정해 둠
  • 세 프리셋의 차이가 움직이는 동안에만 보이고, 마지막 3초 정지 화면에서는 비슷한 흰 선으로 남음. 정지 화면은 보는 사람이 모양을 알아보고 캡처하는 자리(FRD §5-1)이고, 11/19 지인의 정지 이미지 요청과도 이어짐
  • 세 프리셋의 정체성 색이 아직 정해지지 않음(FRD의 기본 색이 셋 다 확인 필요)
  • 11/10 회의에서 지응이 "처음 기획에 비하면 투박해 보임"이라고 함. 8/4 목업은 주황 빛 번짐이 더 진했음

희미한 경로 위로 구간이 하나씩 켜지는 프리셋. 운동 기록의 랩 표시, 선을 계단식으로 칠하는 지도 기법, 지하철 노선도의 역 표현을 참고함

7현수가 정할 것

  1. 불빛 러너의 주변 빛과 머리를 지금, 1번, 2번, 1+2번 중 무엇으로 할지(1절 비교)
  2. 경로 색: 주변 빛을 고른 파스텔 색 그대로 쓸지(이 보고서), 지금 앱처럼 채도를 올릴지. 이 보고서대로 가면 앱의 runnerLightColors 계산을 바꿔야 함
  3. 세 프리셋의 정체성 색. FRD의 기본 색이 셋 다 확인 필요로 남아 있음. 지금 앱은 셋 다 따뜻한 흰색이 기본
  4. 불빛 러너 B안(불꽃 입자), C안(발자국 잔광)과 retro web 시안(반짝이 커서, 픽셀 선) 중 무엇을 새 프리셋으로 넣을지. 넣으면 PRD §7 결과물의 형태와 경로 그림 FRD §6 프리셋에 프리셋을 더해야 함
  5. 구간 점등 B안을 불빛 버전과 메추리 버전 중 무엇으로 볼지. 메추리로 가면 캐릭터를 더 다듬을지
  6. 구간 점등을 "흐르다가 켜짐"으로 바꾸면 경로 그림 FRD §6-3 구간 점등의 진행 표현("구간이 하나씩 켜진다")을 고쳐야 함
  7. 기본 경로 그림을 A-1(지금 선 모양에 굵기만)과 A-2(A안에서 출발점 동그라미만 뺌) 중 무엇으로 할지
  8. 마지막 정지 화면을 프리셋마다 다르게 보이게 할지. 캡처되는 자리이고 정지 이미지 저장 요청(QA 기록 11/19 지인 피드백)과 이어짐
  9. 줌 추적(카메라)을 이번 디자인 보강 범위에 넣을지. PRD는 1순위로 봤지만 아직 시도하지 않음
  10. 개발과 확인할 것: 빛 겹이나 입자를 늘리면 영상을 만드는 시간이 늘 수 있음. 내보내기 FRD에 따르면 9/13 측정에서 이미 약 40초～224초가 걸림 확인 필요

예시의 기법은 브라우저 캔버스로 흉내 낸 것이라, 실제 앱의 렌더러(미리보기와 영상)에서 같은 모양이 나오는지는 구현하며 확인해야 함
