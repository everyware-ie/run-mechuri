경로 그림 프리셋 레퍼런스

불빛 러너, 구간 점등, 기본 경로 그림을 다듬기 위해 찾은 레퍼런스와, 그 기법을 예시 경로에 적용해 본 움직이는 비교

2026-11-20 현수 검토용3차 스프린트 디자인 보강 1순위, 마감 12/8근거: 경로 그림 FRD §6 프리셋

예시는 6초 그리기와 2.5초 정지로 줄였음(실제는 9초와 3초). 경로와 배경, 수치는 비교용 예시이고 실제 기록이 아님. 위쪽에서 배경(밤 사진, 낮 사진)과 선 색을 바꿔 볼 수 있음

0지금 상태

프리셋시작 상태진행 표현마무리기본 색
기본 경로 그림빈 화면경로가 처음부터 선으로 그려져 나감별도 연출 없이 완성된 선이 남음확인 필요
불빛 러너빈 화면빛이 경로를 달리고 지나온 길에 잔광이 남음끝점에 닿으면 경로 전체가 밝아짐확인 필요
구간 점등경로 전체가 희미하게 깔림구간이 하나씩 켜지고 켜진 구간은 남음. 5～8회 켜지게 구간 단위를 고르고 경계 점을 남김마지막 구간이 켜지면 전체가 켜진 상태확인 필요

투박해 보이는 이유 (관찰)

  • 선이 가늘고 밝은 한 겹이라 낮 사진이나 나뭇잎처럼 복잡한 배경에서 묻힘
  • 빛의 밝은 중심과 넓은 주변 빛이 잘 나뉘지 않아 네온 느낌이 약함. FRD §6-2는 불빛 러너를 "진한 주변 빛과 밝고 가는 중심"으로 나누라고 정해 둠
  • 세 프리셋의 차이가 움직이는 동안에만 보이고, 마지막 3초 정지 화면에서는 비슷한 흰 선으로 남음. 정지 화면은 보는 사람이 모양을 알아보고 캡처하는 자리(FRD §5-1)이고, 11/19 지인의 정지 이미지 요청과도 이어짐
  • 세 프리셋의 정체성 색이 아직 정해지지 않음(FRD의 기본 색이 셋 다 확인 필요)
  • 11/10 회의에서 지응이 "처음 기획에 비하면 투박해 보임"이라고 함. 8/4 목업은 주황 빛 번짐이 더 진했음

1불빛 러너

빛이 경로를 달리고 잔광이 남는 프리셋. 빛 그림 사진의 궤적, 움직이는 지도의 잔상 꼬리, 모션 그래픽의 혜성, 네온의 겹 빛을 참고함

지금에 가깝게앱 화면을 보고 흉내 냄
레퍼런스 적용혜성 꼬리, 겹 빛, 거꾸로 훑는 마무리
빛 그림 사진 (장노출 빛 궤적)
볼 점
장노출 동안 움직인 사람은 지워지고 들고 있던 빛만 궤적으로 남음. 셔터 시간이 궤적 길이를 정함
가져올 것
러너는 보이지 않고 빛의 궤적만 남는 그림. 잔광을 셔터처럼 일정한 길이로 다룸
Adobe 빛 궤적 사진 안내, Amateur Photographer 빛 그림 입문
deck.gl TripsLayer 잔상 꼬리
볼 점
움직이는 머리 뒤로 정해진 길이만큼 꼬리가 남고 점점 흐려짐(trailLength, 흐려짐 켜기)
가져올 것
꼬리 길이를 경로 길이의 일정 비율로 고정해 5km든 20km든 같은 리듬으로 보이게 함
deck.gl TripsLayer 문서. 꼬리 길이 단위는 바인딩마다 설명이 달라 확인 필요
After Effects 트림 패스 혜성
볼 점
선의 머리와 꼬리 값을 묶어 함께 움직이고, 꼬리 쪽을 가늘게 하고 빛 효과를 더함
가져올 것
꼬리 끝으로 갈수록 가늘고 흐려지게 해서 속도감을 줌
Noble Desktop 트림 패스, Photofocus 머리와 꼬리 묶기
네온 겹 빛 (겹친 흐림)
볼 점
같은 선을 여러 번 흐리게 겹쳐 밝은 중심과 넓은 주변 빛을 만듦. 노선도 가이드는 흐림을 3～4 정도로 두라고 하고, 더 세면 가까운 선끼리 뭉친다고 함
가져올 것
FRD §6-2의 중심과 주변 빛을 두세 겹으로 실제로 나눔
9elements SVG 네온, 노선도 빛 가이드
예시에 적용한 것
  • 머리는 흰 중심과 주황 빛, 꼬리는 경로 길이의 16%만큼 가늘어지며 흐려짐
  • 지나온 길은 낮은 잔광으로 남김
  • 끝점에 닿으면 빛이 경로를 거꾸로 훑으며 전체가 밝아지고 끝점에서 빛 고리가 한 번 퍼짐

더 해 본 시안 (11/20 추가)

B안불꽃 입자

머리에서 불티가 튀고 금방 식음. 끝점에 닿으면 불티가 한 번 크게 터지고 지나온 길 전체가 달아오름

레퍼런스
불꽃막대를 들고 장노출로 찍은 빛 그림 사진. 움직인 길은 빛 선으로 남고 불티는 짧은 줄로 흩어짐
가져올 것
빛 선 위에 불티를 더해 손으로 그은 느낌을 줌. A안의 혜성 꼬리와 섞을 수 있음
구현 메모
불티 수만큼 그릴 것이 늘어 영상 만드는 시간에 영향이 있음. 예시는 한 화면에 불티 40개 안팎 확인 필요
Instructables 불꽃막대 사진, Digital Camera World 불꽃막대 빛 그림
C안발자국 잔광

선 대신 발자국이 찍힘. 밟는 순간 번쩍였다가 은은하게 남고, 끝점에 닿으면 처음부터 끝까지 물결처럼 한 번 더 빛남

레퍼런스
해변의 발광 플랑크톤. 건드리면 그 자리만 빛나서 걸어간 발자국이 빛으로 남음
가져올 것
"내가 달린 흔적"이라는 뜻이 바로 읽힘. 왼발과 오른발을 번갈아 찍음
구현 메모
발자국 수는 거리와 상관없이 일정하게 둠(예시 약 48개). 점으로 이어져서 짧은 기록은 경로 모양이 덜 읽힐 수 있음
My Modern Met 웨일스 해변의 발광 플랑크톤, JellyWatch 발광 조류

2구간 점등

희미한 경로 위로 구간이 하나씩 켜지는 프리셋. 운동 기록의 랩 표시, 선을 계단식으로 칠하는 지도 기법, 지하철 노선도의 역 표현을 참고함

지금에 가깝게앱 화면과 FRD를 보고 흉내 냄
레퍼런스 적용흐르는 선, 켜질 때 번짐, 역 같은 경계 점
Garmin Connect 랩 표시
볼 점
자동 랩으로 km마다 지도에 표시를 남김. 랩이 많으면 아이콘 수를 줄여 지도가 어지럽지 않게 함
가져올 것
FRD가 점등을 5～8회로 맞추는 것과 같은 생각. 경계 점에 km 숫자를 잠깐 띄워 무엇이 켜졌는지 읽히게 함
Garmin 포럼. 아이콘을 줄이는 기준(10개)은 포럼 답변이라 확인 필요
Mapbox line-gradient와 line-progress
볼 점
선 하나의 진행률에 계단식(step) 식을 걸어 앞부분만 보이게 하거나 구간마다 다르게 칠함
가져올 것
구간을 따로 그리지 않고 하나의 선 안에서 끊어 켬. "프리셋은 전부 하나의 렌더러"라는 원칙과 맞음
Mapbox 그라데이션 선 예제
노선도의 빛나는 선과 역
볼 점
노선을 빛나게 그리고 역은 고리와 밝은 중심으로 표시함
가져올 것
경계 점을 지하철역처럼 고리로. 켜지는 순간 고리가 한 번 퍼짐
노선도 빛 가이드
Apple 피트니스 페이스 색 경로
볼 점
같은 경로를 빠른 곳은 초록, 느린 곳은 빨강으로 칠하고 운동마다 그 운동의 평균을 기준으로 삼음
가져올 것
구간마다 밝기나 색에 페이스를 얹는 확장 아이디어. 페이스 색상 프리셋은 MVP에서 빠졌으므로 지금 범위 밖
Apple 지원 문서. 평균 기준이라는 설명은 사용자 커뮤니티 답변
예시에 적용한 것
  • 선은 불빛 러너와 기본 경로 그림처럼 끊기지 않고 흐름. km 경계를 지나면 지나온 구간이 그 자리에서 켜짐(11/20 현수 의견)
  • 구간이 켜지는 순간 잠깐 더 밝게 번졌다가 가라앉음
  • 경계 점은 고리로, 켜질 때 고리가 퍼지고 km 숫자가 잠깐 떴다가 작게 남음
  • 마지막 구간이 켜지면 전체가 한 번 맥박치고 끝점을 조금 크게 둠

B안활주로 불빛

경로 위에 꺼진 등이 줄지어 있고, 머리가 지나가면 차례로 켜짐. km를 넘으면 지나온 구간 위로 빛이 한 번 달리고, 끝나면 처음부터 끝까지 한 번 더 달림

레퍼런스
공항 진입등의 연속 섬광등. 빛이 활주로 쪽으로 1초에 두 번 미끄러지듯 달려서 "토끼(rabbit)"라고 부름
가져올 것
켜진 등은 계속 켜 두고, 달리는 빛은 "한 구간을 끝냈다"는 신호로만 짧게 씀
구현 메모
등 간격을 경로 길이의 비율로 두면 거리와 상관없이 등 수가 같음(예시 약 58개)
AVweb 진입등 해설, 위키백과 진입등 체계
C안네온 간판 켜기

꺼진 네온관을 따라 가는 선이 흐르고, km를 넘으면 그 구간이 한 번 깜빡이며 켜짐. 마지막 구간이 켜지면 간판 전체가 잠깐 더 밝아짐

레퍼런스
네온 간판이 켜질 때의 깜빡임과, 색 관 안에 흰 심이 보이는 네온 빛
가져올 것
디자인 컨셉(1a 야간 네온)과 가장 가까움. 켜진 구간은 색 관과 흰 심으로 그림
구현 메모
깜빡임은 구간마다 한 번만 넣음. 접근성 기준은 1초에 3번 넘게 번쩍이지 않게 하라고 함. 동작 줄이기를 켠 사용자에게 깜빡임을 뺄지 확인 필요
Adobe 네온 빛 튜토리얼, W3C 세 번 번쩍임 기준

Nike 도움말

B안붓펜 선

굵기가 달린 속도를 따라 변함. 빨리 달린 곳은 가늘고 천천히 달린 곳은 굵음. 끝나면 마침표처럼 점을 찍음

레퍼런스
손글씨 그리기 라이브러리 perfect-freehand. 펜 압력이 없으면 속도로 압력을 흉내 내 굵기를 바꿈. 굵기가 변하는 손글씨를 그려 나가는 Apple "hello" 애니메이션
가져올 것
굵기에 페이스를 실어 내 달리기가 선 모양에 드러남. 색은 하나만 써서 기본 경로 그림의 담백함을 지킴
구현 메모
경로 좌표마다 시각이 있어야 함. 지금 브릿지가 좌표의 시각을 넘기는지 확인 필요. 예시의 굵기는 지어낸 페이스

레퍼런스
리소그래프 인쇄. 색마다 따로 찍어서 조금씩 어긋나고, 이 어긋남을 일부러 살리기도 함. 마라톤 코스를 기념 포스터로 만든 인쇄물
가져올 것
결과물을 기념 포스터처럼 보이게 함. 두 번째 색은 고른 색에서 계산한 주변 빛 색을 씀

선을 한 번 더 그리는 정도라 렌더러 부담이 적음

4색상별로 보기

앱의 기본 팔레트 여섯 가지로 그린 레퍼런스 적용판의 마지막 정지 장면. 캡처되는 순간을 색마다 비교함

불빛 러너의 주변 빛과 중심 색은 앱 코드(runnerLightColors)와 같은 계산을 씀. 고른 색에서 채도를 높인 주변 빛과 흰색에 가깝게 밝힌 중심을 나눔. 따뜻한 흰색만 주변 빛을 강조색(주황)으로 둠. 그래서 불빛 러너에서는 따뜻한 흰색과 오렌지가 거의 같아 보임. 구간 점등과 기본 경로 그림에 같은 계산을 쓴 것은 이 보고서의 제안. 위쪽 선 색을 바꾸면 움직이는 예시도 같은 색으로 바뀜. 자유 색상도 같은 계산으로 마감됨

6현수가 정할 것

  1. 세 프리셋의 정체성 색. FRD의 기본 색이 셋 다 확인 필요로 남아 있음. 지금 앱은 셋 다 따뜻한 흰색이 기본이고, 예시도 따뜻한 흰색에 주변 빛을 강조색(주황)으로 둠
  2. 고른 색에서 주변 빛과 중심을 나누는 불빛 러너의 계산을 구간 점등과 기본 경로 그림에도 쓸지
  3. 마지막 정지 화면을 프리셋마다 다르게 보이게 할지. 캡처되는 자리이고 정지 이미지 저장 요청(QA 기록 11/19)과 이어짐
  4. 프리셋마다 A안(레퍼런스 적용), B안, C안 중 무엇으로 갈지. 섞어도 됨. 예를 들어 구간 점등은 A안의 흐름에 C안의 네온 켜짐을 얹을 수 있음
  5. 구간 점등을 "흐르다가 켜짐"으로 바꾸면 경로 그림 FRD §6-3 구간 점등의 진행 표현("구간이 하나씩 켜진다")을 고쳐야 함
  6. 프리셋마다 먼저 시도할 레퍼런스 하나씩. 예시처럼 여러 개를 한꺼번에 넣을지, 하나씩 넣고 볼지
  7. 줌 추적(카메라)을 이번 디자인 보강 범위에 넣을지. PRD는 1순위로 봤지만 아직 시도하지 않음
  8. 개발과 확인할 것: 빛 겹을 늘리면 영상을 만드는 시간이 늘 수 있음. 내보내기 FRD에 따르면 9/13 측정에서 이미 약 40초～224초가 걸림 확인 필요

예시의 기법은 브라우저 캔버스로 흉내 낸 것이라, 실제 앱의 렌더러(미리보기와 영상)에서 같은 모양이 나오는지는 구현하며 확인해야 함
