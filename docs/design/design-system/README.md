Runary(작업명 Pretty Running Path)의 러닝 측정 화면을 위한 디자인 시스템입니다. 아이폰과 애플워치에서 러닝 경로와 건강 지표를 측정하는 화면이 대상입니다.\
화면 동작의 정본은 FRD([내부 측정](https://github.com/everyware-ie/run-mechuri/blob/main/docs/specs/frd/internal-run-tracking.md), [워치 운동 연동](https://github.com/everyware-ie/run-mechuri/blob/main/docs/specs/frd/watch-workout-integration.md))이고, 이 문서는 시각 기준입니다. 둘이 부딪치면 FRD를 따릅니다.

화면은 어두운 바탕에 주황 하나를 쓰고, 거리를 가장 크게 보여줍니다. 상태 안내는 한 곳에만 둡니다.

## 원칙

- **거리 하나를 크게.** 러닝 화면의 주인공은 거리입니다. 시간·평균 페이스·심박이 그다음이고, 나머지 지표는 보조 줄이나 다음 페이지로 보냅니다.
- **상태 안내는 한 곳에.** 상태가 바뀌면 위의 상태 줄과 아래 영역(아이폰은 지도 아래 안내 줄과 컨트롤, 워치는 하단 버튼)만 바꿉니다. 지표 배치는 움직이지 않습니다.
- **주황은 한 화면에 한 가지 일에만.** `accent`는 지금 누를 버튼, 러닝 중 상태, 경로 선, 심박에만 씁니다. 한 화면에 주황 버튼은 하나만 둡니다.
- **모르면 늘리지 않는다.** 연결이 끊기면 마지막 값을 흐리게 고정합니다(`opacity-stale`). 추정해서 거리와 시간을 늘리지 않습니다.

## 문구

- 해요체 짧은 문장으로 씁니다. 예: “오늘의 러닝을 시작해 볼까요?”, “아이폰 러닝은 계속돼요.”, “일시정지한 시간은 기록에 포함하지 않아요”.
- 질문은 결정이 필요할 때만 씁니다. 예: “러닝을 종료할까요?”
- 기술 용어 대신 사용자가 보는 결과를 씁니다. ‘HealthKit’이 아니라 ‘건강 앱’, ‘세션’이 아니라 ‘워치 측정’이라고 씁니다.
- 수치 형식: 거리 `5.41 km`, 시간 `32:18`, 페이스 `5'58"`, 심박 `152 bpm`, 페이스 단위 ` /km`. 요약은 ` · `로 잇습니다(`5.41 km · 32:18 · 평균 5'58"`).
- 이모지는 쓰지 않습니다.

## 아이폰과 워치

같은 시스템이지만 화면 크기와 손이 닿는 방식이 달라서 아래처럼 나눠 씁니다.

| | 아이폰 (390×844) | 애플워치 45mm (198×242) |
|---|---|---|
| 바탕 | `bg` #0B0D10 | `bg-watch` #000000 |
| 주황 위 글자·아이콘 | `bg` | `bg-watch` |
| 묶음 바탕 | `surface`·`surface-map` 카드, 시트 | 카드 없음, 버튼 바탕은 `fill-button` |
| 거리 | `ip-distance` 104 | `distance-56` |
| 3지표 | `ip-metric` 26, 1:1:1 | `w-metric` 17, 1.1:1:0.9 |
| 상태 줄 | `.status` 14/700 + 오른쪽 워치 상태 | `.wstatus` 13/600 + 오른쪽 시각 |
| 컨트롤 | 원형 [종료 64] [일시정지·재개 84] | 44 높이 두 칸 [종료] [일시정지·재개] |
| 안내 | 지도 아래 한 줄, 예외면 안내 카드 | 하단 버튼 바로 위 11px 문구 |
| 확인창 | 바텀 시트 | 전용 화면(세 칸 유지) |
| 스크롤 | 기록 상세만 | 러닝 화면은 스크롤 없음, 추가 지표는 두 번째 페이지 |

워치 화면은 항상 **상단 상태 / 지표 / 하단 버튼**의 세 칸입니다(`WatchScreen`). 아이폰 러닝 화면도 같은 순서를 따릅니다(`IPhoneScreen`).

## 색

- 글자는 `text`, 보조 글자는 `muted`를 씁니다. `muted`는 `bg`·`surface`·`surface-map`·`bg-watch` 위에서 모두 4.5:1 이상입니다.
- `accent`는 글자로 써도 `bg` 위에서 6.25:1입니다. 주황 바탕 위 글자는 아이폰 `bg`, 워치 `bg-watch`입니다.
- 반투명 흰색은 단계별로 용도가 정해져 있습니다: `fill-tile`(0.06) 꺼진 타일·막힌 버튼·지도 도로 → `divider`(0.07) 행 구분선 → `fill-chip`(0.08) 예외 칩 → `divider-bar`(0.09) 하단 바 구분선 → `fill-button`(0.14) 워치 버튼 → `spinner-track`(0.15) → `toggle-off`(0.16) → `line`(0.22) 외곽선·시트 손잡이 → `chart-bar`(0.28) 심박 막대.
- `line`은 1.84:1로 3:1에 못 미칩니다. 외곽선 버튼은 항상 아이콘이나 글자를 함께 둡니다.
- `device-frame`·`device-edge`는 목업 전용 색이라 앱 UI에는 쓰지 않습니다.

## 타이포

- 글꼴은 Pretendard 하나를 500·600·700 세 굵기로만 씁니다.
- 숫자는 모두 `font-variant-numeric: tabular-nums`(`.num`)로 씁니다.
- 큰 수치에는 자간을 줄입니다: 104px −4, 56px −2, 28px −1, 26px −0.5(러닝 중만).
- 라벨과 단위는 수치보다 작고 `muted`입니다. 수치와 라벨이 같은 크기가 되지 않게 합니다.

## 간격 · 모서리

- 아이폰 글자·수치는 화면 좌우 `space-24`, 카드·지도·하단 버튼은 `space-20` 안에 둡니다.
- 카드 안 행 패딩은 `space-14` / `space-16`, 시트 블록 간격은 `space-22`입니다.
- 워치 화면 패딩은 `space-18` / `space-22` / `space-20`, 버튼과 지표 열 간격은 `space-6`입니다.
- 모서리: 목록 카드 `radius-20`, 지도 `radius-24`, 안내 카드 `radius-18`, 시트 `radius-32`, 아이콘 타일 `radius-12`. 버튼은 모두 완전한 알약형(높이의 절반)이고 원형 컨트롤은 50%입니다.
- 터치 영역은 최소 `size-touch` 44입니다.
- 그림자는 쓰지 않습니다. 단계는 바탕색(`bg` → `surface-map` → `surface`)으로 나눕니다.

예외 규칙:
- 권한이 완료되지 않은 경우는 측정 중단과 같은 형식으로 보여줍니다. 상단은 ‘워치 연결 필요’, 버튼은 ‘권한 확인’입니다.
- 종료 후 저장 단계는 하나씩 체크로 바뀝니다. 워치 응답이 늦으면 2번 행을 ‘워치 종료 확인 중’으로 바꿉니다.
- 워치 저장 결과의 체크는 아이폰 저장이 확인된 뒤에만 띄웁니다. 연결이 끊긴 채 종료하면 체크 대신 ‘종료 요청 전달 중’을 표시합니다.
- 워치 버튼을 누른 뒤 아이폰 반영을 확인하기 전까지는 다시 누를 수 없습니다.
