# 앱 아이콘을 R 마크로 바꾼다

> 이름은 [9/16에 Runary로 바꿨는데](2026-09-16-product-name-runary.md) **아이콘은 계속 메추리였다.**
> 배경과 논의 과정: [2026-09-22 회의 종합](../meetings/2026-09-22/synthesis.md)

## 결정

**아이콘은 R 마크다. 메추리를 뗀다.**

| | |
|---|---|
| 전 | 메추리. 크림 바탕에 검정 선 |
| 후 | **R 마크.** 크림 바탕, 왼쪽 기둥이 트랙 레인으로 갈라지고, 옆에 주황 마침표 |

**팀은 계속 팀 메추리다.** 제품 이름만 바뀐 것이므로 제품 아이콘이 메추리여야 할 이유가 약해졌다.

## 왜 바꾸나

**이름이 안 맞는다.** 아이콘은 메추리인데 제품은 Runary다.

**톤이 뒤집힌다.** 아이콘은 크림 바탕인데 앱 안은 야간 네온(`#0B0D10`)이라 여는 순간 밝은 데서 어두운 데로 떨어진다.

## 어떻게 여기까지 왔나

**회의에서 시안 P2를 골랐다.** 크림 바탕에 스텐실 R, 옆에 주황 마침표다. 후보는 [시안 페이지](https://claude.ai/artifact/WCKWnwdtg7piXY5WBr3Etj)와 [정리 문서](../ideation/phs00/2026-09-21-app-icon-candidates.md)에 있다.

**트랙 느낌을 더 내자는 의견이 붙었다.** R의 획에 트랙 선이 보이면 좋겠다는 것이었다.

**최종안은 회의 뒤 피그마에서 새로 그렸다.** 시안 페이지의 후보 중 하나가 아니다. P2의 규칙(크림 바탕, 주황은 마침표 하나)은 유지하면서 왼쪽 기둥을 레인 셋으로 가르고 아래에 번호 칸을 뒀다.

## 이미 닫힌 것

좁혀 오면서 정한 것들이다. **다시 열지 않는다.**

| | |
|---|---|
| 메추리 | 뺀다 |
| 획으로 그린 R | 뺀다. 빛 효과가 작은 크기에서 번진다 |
| 바탕 | **크림.** 어두운 쪽도 봤으나 고르지 않았다 |
| 주황 | **마침표 하나에만.** 획에 섞지 않는다 |

## 적용

[PR #68](https://github.com/everyware-ie/run-mechuri/pull/68)에서 아이콘과 스플래시를 함께 바꿨다. **아이콘만 바꾸면 홈 화면은 R인데 앱을 열면 메추리가 나온다.**

| 파일 | |
|---|---|
| `frontend/assets/images/icon.png` | 1024×1024, 알파 채널 없음. iOS 아이콘은 알파를 허용하지 않는다 |
| `frontend/assets/images/splash-icon.png` | 색을 뒤집은 것. 스플래시 배경색 `#0B0D10`을 구워 넣었다 |
| `icon-source.svg` · `splash-source.svg` | 벡터 원본. 색이나 크기를 바꿀 때 다시 그릴 필요가 없다 |

빌드 `1.0.0(25)`에 들어갔다. 배포 기록은 [빌드·개발 명령어 모음](../ops/build-and-dev-commands.md)에 있다.

## 알고 넘어가는 것

**아이콘 아래쪽 레인 번호는 홈 화면 크기에서 안 읽힌다.** 1000 격자에서 숫자 높이가 24라 60px 아이콘에서는 1.4픽셀이다. 실제로 빌드에서 꺼내 본 120px 아이콘에서 숫자라기보다 작은 질감 띠로 보였다. 원본 SVG가 레포에 있으므로 나중에 키우거나 뺄 수 있다.

**안드로이드 적응형 아이콘과 favicon은 아직 메추리다.** 이번은 iOS만 내보내므로 두었다.

**스플래시 이미지에는 배경색이 구워져 있다.** `app.json`의 스플래시 배경색을 바꾸면 이 이미지도 다시 뽑아야 한다.
