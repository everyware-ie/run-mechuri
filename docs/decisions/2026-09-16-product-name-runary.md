# 제품명을 Runary로 확정한다

> 8월부터 잠정으로 끌던 것이 닫혔다. **PRD 미결 7번이 사라진다.**
> 배경과 논의 과정: [2026-09-16 회의 종합](../meetings/2026-09-16/synthesis.md)

## 결정

**제품명은 `Runary`다. 한글 표기는 `러너리`.**

| | |
|---|---|
| 전 | **잠정** "메추리런". 대안 "런메추리" |
| 후 | **확정** `Runary` (러너리) |

후보는 여섯이었다. 오늘러닝완료, 메추리, 김감전, 러그예, "러닝은 예술이다 갈!", 그리고 Runary.

## 왜 지금 닫았나

**미룰 자리가 없어졌다.**

> **"TestFlight 단계까지는 쉽게 바꿀 수 있어 그전까지 계속 본다"** (2026-09-01)

그 단계에 들어갔다. 2026-09-15에 빌드 `1.0.0(18)`로 베타 심사를 신청했고 지금 대기 중이다. **여기서 더 끌면 "메추리런"으로 굳는다.**

## 언제 적용하나

**최대한 빠르게 바꾼다.** 심사 통과를 기다렸다 바꿀지는 그때 흐름에 맡긴다.

**이름을 바꾸면 새 빌드를 올려야 하고 심사가 다시 걸릴 수 있다.** 그 비용을 알고 내린 결정이다.

## 무엇이 바뀌나

| 어디 | |
|---|---|
| 앱 표시 이름 | `frontend/app.json`의 `name` |
| 기획 문서 | PRD·FRD·CLAUDE.md·AGENTS.md에서 제품을 부르는 말 |
| 공개 안내 | 노션 처리방침·FAQ·안내 허브. 지금 "메추리 런"으로 적혀 있다 |
| 대시보드 | "내가 만든 것" → **MY RUNARY** ([편집 화면 결정문](2026-09-16-release-and-editor-scope.md)) |
| 스레드 팀 계정 | 소개와 게시물 |

**공개 안내를 고치면 [공개 안내 문서 변경 이력](../ops/public-docs-log.md)에 남긴다.**

### 번들 ID는 바뀌지 않는다

`com.mechuri.runmechuri`는 App Store Connect에 등록된 앱과 묶여 있어 **바꾸려면 앱을 새로 만들어야 한다.** 표시 이름만 바뀌고 내부 식별자에는 "메추리"가 남는다.

**이 상태로 가는 것 자체는 문제가 없다.** 사용자에게 보이지 않는 값이다.

`[확인 필요]` **다만 이 작업을 실제로 할 때 작업자에게 한 번 더 확인하고 진행한다.** 번들 ID를 유지한 채 이름만 바꾸는 것이 맞는지, 새로 만드는 편이 나은지는 그 시점에 다시 본다. (2026-09-16 phs00)

## 팀 이름과는 다르다

**팀은 계속 팀 메추리다.** 제품 이름만 바뀌는 것이고, 노션 워크스페이스와 조직 이름은 그대로다. 메추리런은 팀메추리의 세 번째 프로덕트라는 위치도 변하지 않는다.
