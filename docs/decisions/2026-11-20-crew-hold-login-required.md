# 크루는 보류하고 합동 그리기로, 로그인은 필수

> 배경과 논의: [2026-11-20 회의 종합](../meetings/2026-11-20/synthesis.md)

## 1. 크루 기능은 보류하고 합동 그리기로

- [11/10 결정](2026-11-10-third-sprint-crew-diary.md)에서 3차 스프린트 범위로 정한 크루 가입과 크루원끼리 경로 보기를 보류
- 대신 여러 사람이 한꺼번에 그리는 기능으로 바꿔 진행
  - 셋로그 형태. 크루원을 초대해서 셋로그 형식으로 함께 그리는 방향
- 담당은 지응. 먼저 구체화
- 보류 전에 크루 시안에서 고른 것은 [크루 기획서](../specs/prd/crew.md) 맨 위에 남김. 크루를 다시 꺼낼 때 출발점

## 2. 로그인은 필수

- [지민 안건](../ideation/jminkkk/2026-11-17-meeting-agenda.md) §2 로그인 필수 여부에서 B안(필수)
- 같은 자리에서 확인한 것: 이메일은 받지 않음, 닉네임은 겹칠 수 없고 영문은 소문자만, 로그인 수단은 Apple과 카카오
- 크루원에게 보여 줄 기록의 범위(지민 안건 §1)는 크루와 함께 보류

## 3. 할 일

| 누가 | 무엇 |
|---|---|
| 지민 | 로그인·회원가입 마무리. 취업 준비로 2주 정도 일을 줄임 |
| 지응 | 다이어리 마무리, 합동 그리기 구체화 |
| 현수 | 디자인 다듬기(경로 그림 프리셋), 다이어리 QA |

[11/10 결정](2026-11-10-third-sprint-crew-diary.md)의 역할(현수 크루 화면 디자인)은 크루 보류로 위 표로 바뀜

## 무엇이 바뀌나

| 문서 | 바뀐 것 |
|---|---|
| [11/10 결정](2026-11-10-third-sprint-crew-diary.md) | 크루 보류를 개정으로 덧붙임 |
| [MVP PRD](../specs/prd/running-drawing-mvp.md) §10 로드맵, §13 성공 판정 | 3차 스프린트 메모를 크루 보류와 합동 그리기로 갱신 |
| [크루 기획서](../specs/prd/crew.md) | 맨 위에 보류 메모와 시안에서 고른 것 |
| [로그인 PRD](../specs/prd/account-login.md) §3 언제 로그인을 묻나, §9 다음 결정 | 필수로 정했다는 메모. 본문은 아직 선택 기준 |
| [로그인 FRD](../specs/frd/account-login.md) §2 로그인 입구 | 필수로 정했다는 메모. 입구 화면은 아직 안 고침 |

로그인 입구 화면은 구현하는 지민이 PRD·FRD와 함께 고침

## 정하지 않은 것

- 합동 그리기의 범위와 화면
- 로그인 필수일 때 첫 실행 화면, 이미 쓰고 있던 사용자의 처리, 심사 대응(App Review Guidelines 5.1.1)
- 서버를 어디에 띄울지
- 경로 그림 프리셋을 어디까지 다듬을지
