# 공개 링크를 열었다, 빌드 23이 심사 없이 나갔다

> 8/11에 잡은 9/22를 지켰다. **[9/16 결정](2026-09-16-release-and-editor-scope.md)의 "막히면 미룬다"는 쓸 일이 없었다.**
> 배경과 논의 과정: [2026-09-22 회의 종합](../meetings/2026-09-22/synthesis.md)

## 결정

**빌드 `1.0.0(23)`을 외부 베타 그룹에 넣어 공개 링크를 열었다. 이것이 출시다.**

| | |
|---|---|
| 누가 | 지민 (앱 관리 애플 계정 보유자) |
| 언제 | 2026-09-22 회의 중 |
| 베타 심사 | **없었다.** 추가하자마자 공개됐다 |

## 왜 심사가 없었나

애플 문서에 "처음 제출하는 빌드는 전체 심사를 받지만 같은 버전의 이후 빌드는 심사가 없을 수도 있다"는 문장이 있다. **빌드 18과 23은 둘 다 `1.0.0`이고, 18이 9/13에 이미 승인받았다.**

회의 전에는 **심사를 다시 받을 것으로 봤다.** 18이 승인받은 것은 "메추리 런"이라는 이름으로였고 23은 표시 이름이 Runary로 바뀌었기 때문이다. **그 예측이 틀렸다.**

## 쓰지 않게 된 갈림길

심사가 걸릴 경우를 대비해 셋을 준비했다. 전부 불필요해졌다.

| | 무엇을 하려 했나 |
|---|---|
| A. 기다린다 | 통과하는 날을 출시일로 삼는다 |
| B. 18로 연다 | 승인된 옛 빌드를 공개 링크에 올린다 |
| C. 오늘을 다르게 부른다 | 지인 다섯에게 내부 테스터로 먼저 준다 |

## 무엇이 바뀌나

**[9/16 결정](2026-09-16-release-and-editor-scope.md)의 "9/22는 목표로 유지하되 막히면 미루는 것을 허용한다"가 닫혔다.** 미룰 일이 없었다.

**공개 범위는 9/16에 정한 대로다.** 스레드와 지인 다섯에게 알리고, 외부 테스터는 모집하지 않는다. 링크를 닫는다는 뜻은 아니다.

## 남은 것

**아이콘이 들어간 빌드 `1.0.0(25)`는 아직 외부 그룹에 없다.** 9/22에 내부 테스터용으로 제출했다. 외부로 올릴지는 정하지 않았다. 배포 기록은 [빌드·개발 명령어 모음](../ops/build-and-dev-commands.md)에 있다.

`[확인 필요]` **빌드 25도 심사 없이 나가는지는 해봐야 안다.** 25 역시 `1.0.0`이므로 같은 규칙이 적용될 것으로 보이나, 23에서 예측이 한 번 틀렸으므로 단정하지 않는다. (2026-09-23 phs00)
