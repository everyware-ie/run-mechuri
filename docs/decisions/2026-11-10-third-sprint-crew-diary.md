# 3차 스프린트는 크루 가입, 크루원 경로 보기, 다이어리. 로그인부터 만든다

> 배경과 논의: [2026-11-10 회의 종합](../meetings/2026-11-10/synthesis.md)

## 1. 3차 스프린트

- 기간: **11/10부터 12/8(화)까지 4주**
- 각자 가져온 아이디어를 묶어 투표하고, 2표를 받은 세 가지를 만듦

| 만들 것 | 묶음 |
|---|---|
| 크루에 가입한다 (같이 모인다) | 크루 기능 (가칭) |
| 크루원끼리 서로 뛴 경로를 본다 | 크루 기능 (가칭) |
| 기록을 다이어리 형태로 보여 준다 | 개인 기록 꾸미기 |

- 크루와 경로 공유에는 서버와 계정이 필요해서 로그인과 회원가입도 같이 만듦
- [MVP PRD](../specs/prd/running-drawing-mvp.md) §10 로드맵이 "서버가 처음으로 필요해지는 자리"로 본 그룹 기능 쪽임

## 2. 누가 무엇을

| 누가 | 무엇 |
|---|---|
| 지민 | 로그인과 회원가입 구현. Apple과 Google |
| 현수 | 크루 화면 디자인(모집, 경로 조회). 기본 배경, 불빛 런 같은 디자인 보강 |
| 지응 | 다이어리 구현(디자인 포함) |

- 카카오 로그인은 사업자가 필요해서 Google로 대신함
- [9/8 역할 결정](2026-09-08-scope-and-roles.md)은 고치지 않음. 10/6 때처럼 이번 스프린트 일을 사람별로 나눈 것

## 3. "러닝" 탭은 이름을 두고 아이콘을 바꿔 본다

- 11/3에 나온 "측정 기능이라는 게 잘 안 와닿는다"는 의견에 대해, "러닝"이라는 이름은 나쁘지 않다고 봄
- 대신 아이콘을 바꿔 보는 방향. 지응이 메추리가 달리는 느낌으로 준비
- 아이콘이 나오면 [하단 탭 FRD](../specs/frd/home-running-tabs.md)의 경로 아이콘 부분을 고침

## 무엇이 바뀌나

| 문서 | 바뀐 것 |
|---|---|
| [MVP PRD](../specs/prd/running-drawing-mvp.md) §10 로드맵 | 그룹 드로잉 아래에 3차 스프린트 범위 메모 추가 |
| [MVP PRD](../specs/prd/running-drawing-mvp.md) §13 성공 판정 | 2차 스프린트가 1주 일찍 넘어간 것과 3차 스프린트 일정 추가 |
| [10/6 결정](2026-10-06-second-sprint-app-store.md) | 2차 스프린트 결과와 조기 전환을 개정으로 덧붙임 |
| [하단 탭 FRD](../specs/frd/home-running-tabs.md) | 아직 안 고침. 아이콘이 나오면 고침 |

## 구현 전에 할 것

- 크루, 다이어리, 로그인의 PRD와 FRD 작성. 레포 규칙상 PRD 없이 제품 기능을 시작하지 않고, approved FRD만 구현 근거가 됨
- 개인정보 처리방침, 이용약관, App Store 개인정보 표시 개정. 지금은 로그인 없이 기기에만 저장하는 기준임

## 정하지 않은 것

- 서버를 무엇으로 둘지
- 크루원에게 경로를 보여 줄 때 집·회사 위치를 어떻게 할지 (지민의 크루 합본 메모에서 나온 문제)
- 3차 스프린트의 목표 수치
- 1표 이하를 받은 아이디어를 언제 볼지: 크루 목표 정하기, 경로를 하나로 합치기, 목표·등급·성장, 개인 주간 기록 꾸며 공유, 보증금 챌린지
- 탭 아이콘을 언제까지 준비해서 어느 버전에 넣을지
