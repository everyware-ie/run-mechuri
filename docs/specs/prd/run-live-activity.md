# 러닝 잠금화면 현황

## 1. 해결할 문제

러닝 중 앱을 벗어나면 측정을 켜 둔 사실을 잊기 쉽다. 잠금을 풀고 Runary로 들어가지 않아도 거리와 측정 상태를 확인할 수 있어야 한다. [10/13 회의](../../meetings/2026-10-13/synthesis.md)에서 나온 요구이며, 사용자는 10/19 대화에서 잠금화면 시안을 먼저 다듬은 뒤 구현하도록 요청했다.

사용자는 최근 러닝에서 장시간 측정과 연동을 확인했다고 알렸다. 원본 기록과 진단 수치는 이번 작업에서 직접 조회하지 않았으므로, 측정 정확도·배터리·메모리의 별도 합격 근거로 바꾸지 않는다. 이번 작업은 [기존 측정](internal-run-tracking.md)의 상태를 잠금화면에 보여주는 데 집중한다.

## 2. 제공 범위

아이폰의 Live Activity로 진행 중인 러닝의 거리, 측정 시간, 평균 페이스와 현재 심박을 표시한다. 한 러닝의 상태를 앱·워치와 공유하며 잠금화면을 위해 측정이나 운동 세션을 추가로 시작하지 않는다. 일시정지와 같은 러닝으로 돌아가는 제어를 포함한다. 후속 사용자 요청에 따라 iOS 17 이상의 잠금화면 ▶는 앱 진입 없이 같은 일시정지 러닝을 바로 재개하며, 새 GPS 구간을 사용한다. 사용자의 후속 질문과 UI 피드백에 따라 iOS 17 이상에서 측정 중·일시정지 모두 같은 위치의 종료 버튼으로 확인 후 저장하는 흐름을 제공한다.

먼저 개발 빌드와 내부 TestFlight에서 검증한다. 일반 정식 앱에 측정 기능을 공개하는 결정과 배포는 기존 공개 전 개정 절차에 따른다. 이미 제출한 39번이나 기존 제출 태그를 변경하지 않는다.

Live Activity를 표시할 수 없거나 사용자가 지워도 측정은 계속된다. 실패를 이유로 러닝 시작·저장을 막거나 반복해서 권한을 요구하지 않는다. 서버와 원격 푸시는 추가하지 않는다.

## 3. 확정된 디자인

사용자가 거리 중심안을 선택하고, 심박 아이콘 유지와 하단 세 지표의 왼쪽 정렬을 확인했다. 거리는 가장 크게 보여주며 아래에 시간·평균 페이스·심박을 놓는다. 이는 잠금화면의 정보 우선순위다. 기존 앱 측정 화면의 네 지표 구성은 유지한다.

측정 중에는 `일시정지`, 일시정지 상태에는 `재개`를 보여준다. 구체적인 생김새는 [디자인 기준](../../design/run-live-activity.md)에 보관한다. 시안과 FRD를 제시한 뒤 받은 2026-10-19 구현 요청을 착수 근거로 기록한다.

## 4. 성공 기준

- 실제 아이폰에서 화면을 잠가도 같은 러닝의 상태와 지표를 확인할 수 있다.
- 일시정지·재개·종료가 앱과 워치에 함께 반영되고 중복 기록을 만들지 않는다.
- 지연된 데이터, 일시정지와 중단을 구분하며 없는 심박을 만들어 표시하지 않는다.
- 잠금화면에서 현황을 지우거나 표시 설정을 꺼도 원본 기록을 잃지 않는다.
- 작은 화면과 큰 글자에서도 값·단위·버튼이 겹치지 않는다.

## 5. 착수 확인

[FRD](../frd/run-live-activity.md)를 제시하고 아이콘 제어 시안을 확인한 뒤 사용자가 구현을 요청했다. 2026-10-19에 `approved`로 바꾸고 내부 빌드 구현과 검증을 진행한다. 잠금화면 재개는 후속 사용자 요청에 따라 앱 진입 없이 처리하며, 실기기 검증은 자동 검사와 구분해 기록한다. 워치 권한 반복 요청의 해결이나 자동 화면 복귀를 이번 기능의 완료 조건에 섞지 않는다.
