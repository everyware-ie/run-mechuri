# Runary 크루 가입과 러닝 경로 보기

- 같은 크루의 멤버가 서로 달린 기록과 경로를 볼 수 있게 함
- 자동 공유에 동의하면 가입한 뒤 완료한 러닝이 크루에 올라감
- 경로는 Runary의 중심이므로 처음부터 끝까지 그대로 보여줌
- 처음 만난 사람과도 같은 크루에 들어갈 수 있으므로 집이나 회사처럼 개인을 특정할 수 있는 위치 정보는 사용자가 골라서 가릴 수 있게 함
- 크루원이 서로의 기록을 보러 앱에 다시 들어오는지 확인함
- 11/10 회의에서 3차 스프린트 범위로 **크루 가입과 크루원 경로 보기**를 정함
- 11/14 답변에 따라 자동 공유와 두 가지 경로 보기를 초안에 반영함
- 11/16 현수가 경로는 빼거나 자르지 않고 위치를 특정할 수 있는 주변 정보만 골라 가리는 것으로 정함([공유 범위와 위치 가리기](#공유-범위와-위치-가리기))
- 가입 방식은 아래 후보를 비교한 뒤 첫 버전 범위를 정함 ([3차 스프린트 결정](https://github.com/everyware-ie/run-mechuri/blob/main/docs/decisions/2026-11-10-third-sprint-crew-diary.md))

## 크루에 들어가는 방법

| 후보 | 사용자 흐름 | 시안에서 비교할 점 |
|---|---|---|
| 회원 검색 후 초대 | 크루원이 이메일이나 닉네임으로 가입된 회원을 찾아 초대함<br>상대가 초대를 확인하고 수락함 | 검색할 수 있는 정보, 동명이인 구분, 받은 초대에 들어가는 위치 |
| 친구 목록에서 초대 (친구 추가 기능 도입 시) | 크루원이 앱에서 이미 친구로 추가한 회원을 목록에서 골라 초대함<br>상대가 크루 초대를 확인하고 수락하면 가입함 | 이름이나 이메일을 다시 검색하지 않아도 되는 점, 친구 선택 화면과 받은 초대의 위치 |
| 초대 링크 | 크루원이 링크를 전달함<br>받은 사람은 크루 정보를 확인해 가입함 | 로그인 후 같은 초대로 돌아오는 흐름과 앱을 설치한 뒤 원래 링크를 다시 여는 흐름 |
| 앱에서 크루 찾기 | 가입하려는 사람이 앱에서 크루를 찾아 상세를 보고 가입함 | 모집 화면에 보여줄 정보, 크루별 즉시 가입과 승인 요청의 필요 여부 |

- 이미 친구인 사람을 초대할 때는 목록에서 바로 고를 수 있음
- 처음 연결하는 사람에게는 친구 추가 단계가 생기므로 회원 검색이나 초대 링크와 함께 비교함
- 친구 추가 기능을 도입할지 먼저 정함
  - 도입하면 크루 초대에 연결할 시점을 논의함
- 첫 버전에 어떤 가입 방식을 제공할지는 화면을 비교한 뒤 정함
- 회원가입과 로그인은 지민님 작업과 연결함

- 크루 가입·공유 기록 조회를 첫 검증 범위로 잡음
- 응원, 알림, 주간 목표와 크루 합본은 참여 흐름이 자리 잡은 뒤 검토함 ([지민님의 크루 제안](https://github.com/everyware-ie/run-mechuri/blob/main/docs/ideation/jminkkk/2026-11-10-crew-feature.md))

## 공유 범위와 위치 가리기

- 2026-11-16 현수가 정함
- **경로 모양은 반드시 보여주며 위치를 특정할 수 있는 상세 정보는 가림**
- 가리는 대상은 경로가 아니라 경로 주변의 상세 위치 정보

- 기본 공유
  - 자동 공유에 동의하면 같은 크루의 멤버에게 러닝 날짜, 전체 거리, 달린 시간, 평균 페이스, 지도 없는 전체 경로 모양을 보여줌
  - 경로 모양은 빼거나 자르지 않고 처음부터 끝까지 보여줌
  - 경로 모양 보기에는 지도, 실제 좌표, 장소 이름을 붙이지 않음
  - 평균 심박수는 값이 있고 심박 공유에 따로 동의한 경우에만 보여줌
  - 초 단위 심박 기록은 공유하지 않음
- 지도 보기
  - 지도 공유에 따로 동의하면 같은 경로를 지도 위에 처음부터 끝까지 그림
  - 출발점과 도착점 주변은 기본으로 가리며 사용자가 설정에서 바꿀 수 있음
  - 집이나 회사처럼 직접 지정한 장소 주변도 더해서 가릴 수 있음
  - 가린 영역에서는 지도 배경, 주소, 장소 이름, 주변 상권 정보를 보여주지 않고 경로는 그대로 둠
  - 거리와 시간은 전체 러닝을 기준으로 표시함
  - 지도 공유에 동의하지 않았으면 경로 모양과 러닝 요약만 볼 수 있음 ([기록 열람 정책](running-drawing-mvp.md#9-기록-열람-정책))
- 받아들인 한계
  - 지도 위에 경로를 끝까지 그리므로 가린 영역 안의 경로 끝점과 주변 도로를 맞춰 보면 출발점을 짐작할 수 있음
  - 정확한 경로를 보여주는 것을 더 중요하게 보고 이 점을 받아들임
  - 러너 대부분이 자기 기록이 정확하게 찍히는 것을 더 중요하게 여길 것이라는 현수의 추정에 따른 판단이며 아직 검증하지 않음
  - 지도 공유를 켜기 전 미리보기에서 상세 위치는 가려지고 경로는 그대로 보인다고 안내함
- 크루원에게 가는 정보
  - 지도 공유를 켜지 않은 기록은 경로 모양을 그릴 정보만 보내고 실제 좌표는 보내지 않음
  - 지도 공유를 켠 기록은 지도에 경로를 그려야 하므로 경로 좌표가 크루원에게 전달됨
  - 서버 저장 항목과 개인정보 안내는 이 차이를 기준으로 정함
- 공유 범위 확인
  - 사용자는 자동 공유를 켜기 전에 크루원에게 어떻게 보이는지 미리 확인할 수 있음
  - 공유한 러닝에도 가릴 장소를 더할 수 있게 함
  - 설정에서 공유 항목을 바꾸거나 자동 공유를 끌 수 있음
  - 원본 기록은 본인의 기록에 그대로 남음

## 시안으로 확인할 흐름

1. 가입 전 화면은 회원 검색 후 초대, 초대 링크, 앱에서 크루 찾기로 비교함
   - 친구 추가 기능을 도입하는 안에서는 친구 목록에서 초대하는 화면도 함께 비교함
2. 사용자는 크루에 가입한 뒤 공개 항목과 멤버에게 보일 모습을 확인하고 자동 공유를 켤지 선택함
3. 자동 공유에 동의한 사용자가 러닝을 완료하면 크루 홈에 기록이 표시됨
4. 다른 크루원은 기록을 열어 러닝 요약과 경로 모양을 확인함
   - 기록을 공유한 사람이 지도 공유에 동의한 경우 지도 보기로 바꿔 같은 경로를 지도 위에서 봄
   - 가린 영역에는 지도 배경과 장소 정보가 보이지 않음

- 첫 시안에서는 가입 방식별로 같은 크루 홈에 이르는 흐름을 비교함
- 가입할 때의 자동 공유 안내, 가입 직후의 빈 크루 홈, 기록 상세의 지도와 경로 모양 전환을 확인함
- 색, 글자, 버튼은 지민님의 시각 기준을 참고함 ([디자인 시스템 PR](https://github.com/everyware-ie/run-mechuri/pull/137))
- 시안: [크루 화면 시안](../../design/crew-screens.md) (2026-11-16)

## 확인할 결과

- 팀원 두 사람이 각자 계정으로 첫 버전에서 채택한 가입 방식을 거쳐 같은 크루에 들어감
- 자동 공유에 동의한 한 사람이 경로가 있는 러닝을 완료하면 상대가 크루 홈에서 러닝 요약과 경로 모양을 볼 수 있음
  - 가입 전 기록은 크루에 자동으로 올라가지 않음
  - 크루 밖의 계정이나 탈퇴한 계정은 공유 기록을 열 수 없음
- 경로 모양이 어느 보기에서나 처음부터 끝까지 그려지는지 확인함
  - 지도 공유를 켠 기록에서 가린 영역에 지도 배경, 주소, 장소 이름이 보이지 않는지 확인함
  - 출발점과 도착점 주변이 처음부터 가려져 있는지도 확인함
  - 지도 공유를 켜지 않은 기록은 실제 좌표 없이 러닝 요약과 경로 모양만 전달되는지 확인함
  - 심박 공유를 켜지 않은 기록에는 평균 심박수가 표시되지 않음
- 공유를 취소했을 때 다른 멤버의 목록과 기존 상세 진입 경로에서 철회가 반영됨
  - 개인의 러닝 원본은 계속 자기 기록에서 볼 수 있음
- 첫 사용 뒤 다음 러닝에서도 다시 공유하거나 크루 기록을 열어보는지 팀 테스트에서 확인함

## 시안과 함께 논의할 항목

- [확인 필요] 크루를 하단 탭의 네 번째 자리에 둘지 정함
  - 현수 제안(2026-11-16): 네 번째 탭. 크루가 여러 개가 되어도 크루 홈 제목에서 바꾸면 되어 늘리기 쉬움
  - 다이어리 안에 두는 안은 크루 수만큼 다이어리 위쪽 전환이 늘어나고 승인된 다이어리 FRD를 고쳐야 함
  - 네 번째 탭으로 정하면 [하단 탭 FRD](../frd/home-running-tabs.md)도 함께 고침
- [확인 필요] 회원 검색 초대, 초대 링크, 앱에서 크루 찾기 중 첫 버전에 포함할 방식을 정함
  - 현수 안(2026-11-16): 셋 다 넣고, 빠듯하면 초대 링크부터 넣은 뒤 넓힘. 회의에서 확인
- [확인 필요] 친구 추가 기능을 도입할지 정함
  - 도입한다면 친구 목록에서 크루 초대를 제공할 시점과 초대할 수 있는 멤버 범위를 정함
- [확인 필요] 자동 공유 동의를 어디에서 받고 공유를 원하지 않는 러닝을 한 건씩 어떻게 제외할지 정함
  - 여러 크루 가입을 허용한다면 어느 크루에 공유할지도 정함
- [확인 필요] 경로가 없는 러닝은 거리와 시간만 공유할지 정함
- [확인 필요] 출발점과 도착점 주변을 얼마만큼 가릴지 정함
  - 가리기를 기본으로 켜는 것은 2026-11-16 현수가 정함
  - 공유한 러닝에 가릴 장소를 더하는 흐름도 시안에서 확인함
- [확인 필요] 건강 앱에서 가져온 심박을 크루에 공유하는 경우에 적용되는 정책과 동의 범위를 출시 전에 확인함 ([Apple 심사 가이드라인 5.1.3](https://developer.apple.com/app-store/review/guidelines/#health-and-health-research))

- 크루 인원 상한, 동시에 가입할 수 있는 크루 수, 초대 링크 만료와 탈퇴 뒤 기록 처리의 세부 기준은 가입·공개 방식을 정한 뒤 기능정의서에서 구체화함
- 공개 빌드에서는 확정한 서버 저장 항목과 접근 권한을 개인정보 안내에 반영함
