# 다이어리

2026-11-11 지응이 아래 4절의 정하지 않은 항목을 정하고 이 PRD를 승인했다.

## 1. 왜 만드나

러닝 앱은 기록을 날짜순 목록으로 보여 준다. 목록에서는 어느 날 뛰었고 어느 날 쉬었는지 한눈에 보이지 않는다. 지난 일주일, 지난달을 훑어보려면 기록을 하나씩 열어야 한다.

달력에 뛴 날을 표시하면 이 문제가 풀린다. 쉬는 날이 이어졌는지, 이번 달에 몇 번 뛰었는지가 화면 하나에 보인다. 뛴 날이 쌓이는 모습은 다음에 또 뛰고 싶게 만드는 이유도 된다.

2026-11-10 회의에서 3차 스프린트로 "기록을 다이어리 형태로 보여 준다"를 만들기로 했다. 담당은 지응이다([결정문](../../decisions/2026-11-10-third-sprint-crew-diary.md)). App Store 앱 이름도 "러너리 (Runary) - 나의 러닝 다이어리"여서 이름과 기능이 맞는다([제품명 결정](../../decisions/2026-09-16-product-name-runary.md)).

## 2. 범위

보관함, 러닝 옆에 세 번째 하단 탭 **다이어리**를 둔다. 보관함 첫 화면의 큰 카드를 달력으로 바꾸는 안도 시안으로 비교했고, 별도 탭으로 가기로 했다(2026-11-11 지응).

| 만드는 것 | 내용 |
|---|---|
| 월 달력 | 뛴 날 아래에 뛴 날 표시를 찍는다. 이전 달과 다음 달로 넘긴다. 기록은 앱이 직접 측정한 러닝만 쓴다 |
| 요약 | 그 달에 러닝한 날 수, 총 거리, 가장 길게 뛴 거리 |
| 최근 4주 | 주마다 7일의 뛴 날과 쉰 날, 주간 거리 |
| 뛴 날 표시 선택 | 메추리와 사람 중 고른다. 기본은 메추리다 |

날짜를 눌렀을 때 그날의 기록으로 이동하는 동작은 FRD에서 정한다.

## 3. 이번에 하지 않는 것

- 크루원과 뛴 날 스티커를 같이 붙이는 것. 11/10 회의에서 나온 아이디어이며 서버와 계정이 필요하다
- 목표 달성, 색깔별 레벨. 11/10 회의에서 1표 이하였다
- 주간 기록을 꾸며서 공유하는 것

## 4. 정한 것

2026-11-11 지응이 정했다.

| 질문 | 정한 것 |
|---|---|
| 달력의 기록은 어디서 오나 | 앱이 직접 측정한 기록만 쓴다. 건강 앱 기록은 달력에 넣지 않는다 |
| 같은 날 두 번 뛰었을 때 | 뛴 날 표시를 하나만 찍는다. 횟수는 표시하지 않는다 |
| 한 주의 시작 요일 | 일요일(2026-11-12 월요일에서 바꿨다). 달력과 최근 4주 모두 같다 |
| 뛴 날 표시의 크기 | 거리와 상관없이 모두 같다 |
| 러닝 탭 아이콘과 뛴 날 표시 선택 | 묶지 않는다. 러닝 탭 아이콘은 하단 탭 FRD에서 따로 정한다 |
| 선택 시트를 `완료` 없이 닫으면 | 저장하지 않는다 |
| 기본 뛴 날 표시 | 메추리 |

메추리는 앱의 메인 캐릭터가 아니라 군데군데 들어가는 포인트다(2026-11-11 지응). 앱 아이콘은 R 마크이고 메추리는 팀 이름과 이어진 모티프다. 다이어리에서는 뛴 날 표시의 기본값으로 쓰고, 사람 아이콘으로 바꿀 수 있다. 다른 화면에 메추리를 더 넣을지는 이 PRD가 정하지 않는다.

메추리 이미지를 앱에 넣는 방법은 FRD에 적었다.

## 5. 성공 기준

- 다이어리를 열면 이번 달에 뛴 날과 쉰 날을 바로 알 수 있다
- 기록이 없는 달과 첫 사용자에게도 빈 달력이 어색하지 않게 보인다
- 뛴 날 표시를 바꾸면 달력과 최근 4주가 함께 바뀌고 앱을 다시 열어도 유지된다

수치 목표는 정하지 않았다. 3차 스프린트 목표가 정해지면 맞춘다.
