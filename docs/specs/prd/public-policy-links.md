# 공개 정책 문서와 이용약관 열람

사용자가 개인정보 처리방침 열기 실패를 제보했고 서비스 이용약관을 새로 만들고 앱에 추가하도록 요청했다. 처리방침 열기 수정은 기존 홈 FRD의 승인 범위로 먼저 구현했다. 이용약관은 내용·운영 주체·시행일·게시 범위 확인 뒤 공개한다.

## 목적과 범위

사용자가 앱의 이용 조건과 데이터 처리 방침을 쉽게 확인하도록 한다. 첫 실행 안내와 홈 하단에서 개인정보 처리방침과 서비스 이용약관을 각각 열 수 있게 한다. 앱 내 시스템 브라우저에서 읽고 닫으면 기존 화면으로 돌아온다.

서비스 이용약관은 현재 무료·로그인 없는 경로 편집·영상 생성 범위에 맞춰 작성한다. 새로운 회원가입, 동의 체크 화면, 결제·구독 기능은 만들지 않는다. App Store Connect에 커스텀 EULA를 자동 등록하지 않는다.

## 성공 기준

두 문서의 공개 URL이 로그인 없이 열리고 제목·본문을 읽을 수 있다. 중복 탭·열기 실패·닫기 뒤 재열기를 처리한다. 승인 전 비공개 초안이나 미확정 주소를 앱에 연결하지 않는다.
