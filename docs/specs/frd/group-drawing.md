# 합동 그리기 FRD

> **status: `draft`.** 구현 근거가 아니다. 팀이 [회의 안건](../../ideation/JiEung2/2026-11-27-meeting-agenda.md)의 규칙을 정한 뒤 `approved`로 올린다. 근거: [합동 그리기 PRD](../prd/group-drawing.md)\
> `[확인 필요]`는 아직 정하지 않은 것이다. 시안에서 가정한 값은 그렇게 밝혔다.

여러 사람이 한 판의 4칸을 나눠 채워 하나의 9:16 영상으로 만든다. 용어는 [용어집](../../../.claude/domain/glossary.md)의 합동 그리기, 칸, 칸 배치를 따른다. 화면 문구는 "함께 그리기"를 쓴다.

이 기능은 서버와 로그인이 있어야 한다. 서버는 지민의 로그인 작업이 끝난 뒤에 정한다. 서버가 없는 빌드에서는 합동 그리기 진입을 보여 주지 않는다 `[확인 필요]`.

## 1. 진입

보관함 첫 화면 위쪽에 `함께 그리기` 카드를 둔다. 카드에는 `새로 만들기` 버튼이 있다. 지난주에 참여한 판이 있으면 카드 아래에 `지난주 같이 그린 N명` 줄을 보이고 `같은 멤버로 다시 만들기`를 누를 수 있다. 이 버튼은 후속이고 첫 버전에는 넣지 않는다 `[확인 필요]`.

초대 링크를 열어 들어오는 길은 3절에 있다.\
진입 위치를 보관함 카드로 한 것은 시안의 가정이다. 하단 탭은 이미 세 개라서 늘리지 않았다 `[확인 필요]`.

합동 그리기는 로그인한 사용자만 쓴다. 로그인 필수는 [로그인 FRD](account-login.md)를 따른다.

## 2. 만들기

한 판은 `이번 주` 하나로 정한다. 일요일부터 토요일까지다(다이어리와 같다). 기간을 고르는 화면은 없다.

만들 때 고르는 것은 칸 배치 하나다.

| 배치 | 칸 모양 |
|---|---|
| 2×2 | 2열 2행. 기본값 |
| 세로 4행 | 전체 폭의 가로 띠 4개 |
| 가로 4열 | 얇고 긴 세로 4열 |

- 배치는 만든 뒤 한 칸이라도 채워지면 바꿀 수 없다 `[확인 필요]`
- 만들 때 내 칸을 채우지 않는다. 만든 직후 4칸이 모두 비어 있다
- `만들고 초대하기`를 누르면 만들고 초대 링크 보내기 화면으로 간다
- 같은 주에 여러 판을 만들 수 있는지는 정하지 않았다 `[확인 필요]`

## 3. 초대와 참여

링크는 판에 참여한 사람 누구나 보낼 수 있다. 만든 사람에게 특별한 권한이 없다 `[확인 필요]`.

링크를 연 사람에게는 이 화면을 보인다.

- 초대한 사람 이름, 기간, 칸 현황(몇 칸이 찼는지)
- `참여하기`와 `나중에`

참여하기를 누르면 판 화면으로 간다. 4칸이 이미 다 찼으면 `이미 4칸이 다 찼어요`를 보이고 `새로 만들기`와 `닫기`만 둔다.\
앱이 설치되어 있지 않은 사람을 위한 링크 처리(App Store로 보내기)는 서버와 함께 정한다 `[확인 필요]`.

## 4. 판 화면

위에서부터 이 순서다.

| 영역 | 내용 |
|---|---|
| 제목 | `이번 주 함께 그리기`, 기간, 마감 안내 |
| 상태 줄 | 채워진 칸 수(`1 / 4칸 채움`), 칸 배치 이름, 남은 시간 |
| 칸 | 선택한 배치로 4칸 |
| 아래 | 안내 한 줄, 주황 버튼 하나 |

- 내 칸에는 `내 칸` 표시와 주황 테두리를 둔다. 주황은 한 화면에 한 가지 일에만 쓰는 [디자인 시스템](../../design/design-system/README.md) 규칙과 맞는지 현수가 확인한다 `[확인 필요]`
- 칸은 채워져 있으면 경로, 칸에 보일 이름, 거리와 시간을 보이고, 비어 있으면 `+`와 `비어 있어요`를 보인다
- 배치에 따라 칸 안의 구성이 달라진다. 2×2는 가운데 정렬, 세로 4행은 왼쪽 경로와 오른쪽 글자, 가로 4열은 경로를 작게 하고 거리와 시간을 두 줄로 줄인다
- 아래 버튼은 칸이 다 차기 전에는 `초대 링크 보내기`, 다 차면 `영상 만들기`다
- 다 차면 `이제 기록을 바꿀 수 없어요`를 보이고 `내 칸 빼기`를 보조 버튼으로 둔다

## 5. 칸 채우기

빈 칸의 `+`를 누르면 시트가 열린다. 어느 칸이든 누르면 그 칸이 내 칸이다. 한 사람은 한 판에서 한 칸만 채운다 `[확인 필요]`.

| 항목 | 규칙 |
|---|---|
| 기록 | 이번 주(일~토)에 시작한 기록 하나. 앱에서 측정한 기록과 건강 앱 기록 모두. 경로가 없는 기록은 목록에서 뺀다([기록 선택 FRD §2-2](run-record-selection.md)). 출처는 `Runary`, `건강 앱` 칩으로 구분한다 |
| 칸에 보일 이름 | 올릴 때마다 입력한다. 닉네임으로 미리 채워 두고 고칠 수 있게 한다. 최대 10자다 `[확인 필요]` |
| 배경 | 기본 이미지 6장과 갤러리 사진 중 하나. 갤러리 영상은 허용하지 않는다 |
| 보일 부분 | 갤러리 사진을 골랐을 때만 정한다. 6절에 있다 |

시트 아래에는 `4칸이 다 차면 기록과 배경을 바꿀 수 없어요`를 보이고 `이 기록 올리기`로 올린다.\
갤러리 사진은 서버에 올라가고 같은 판에 참여한 사람의 폰에서 보인다. 시트에 그렇게 적는다.

올리는 동안은 진행 시트를 보이고 닫지 말라고 안내한다. `올리기 취소`를 둔다. 실패하면 `올리지 못했어요`와 `다시 올리기`, `나중에`를 보인다. 실패해도 내 폰의 기록은 그대로다.

## 6. 칸보다 큰 사진의 보일 부분

사진은 칸 비율에 맞춰 늘이거나 줄이지 않는다. 칸 크기만큼만 보이고 어느 부분이 보일지만 고른다.

- 사진 위에서 보일 부분의 중심 한 점을 누른다. 점 하나만 정하므로 배치가 달라도 같은 선택을 쓴다
- 화면은 사진 전체와 2×2 칸에서 보이는 범위(테두리), 세 배치별 미리보기를 함께 보인다
- 칸은 중심을 가운데로 자르되 사진 밖으로 나가지 않게 가장자리에서 멈춘다
- 가로 4열은 사진의 1/4 폭만 보여서 얇은 띠가 된다. 보기에 괜찮은지 현수가 확인한다 `[확인 필요]`

## 7. 칸 바꾸기와 빼기

- 4칸이 다 차기 전에는 `기록 바꾸기`로 내 칸의 기록, 이름, 배경을 바꿀 수 있다. 5절의 시트를 같은 모양으로 쓴다
- 다 차면 바꿀 수 없다
- `내 칸 빼기`는 언제든 할 수 있다. 시트에서 `돌아가기`와 `빼기`를 고른다. 빼면 올린 기록과 사진이 이 판에서 지워지고 내 폰의 원래 기록은 그대로다
- 뺀 뒤 그 칸에 다시 올릴 수 있는지, 다 찬 판에서 빠진 칸을 다른 사람이 채울 수 있는지는 정하지 않았다 `[확인 필요]`
- 올린 사본은 원본 기록을 지워도 남는다. 사본을 지우려면 `내 칸 빼기`를 한다 `[확인 필요]`
- 계정을 탈퇴하면 내 칸은 지워진다 `[확인 필요]`

## 8. 마감

판은 만든 주의 토요일 자정에 마감된다. 시각 기준은 서버 시각인지 기기 시각인지, 시간대를 무엇으로 하는지 정하지 않았다 `[확인 필요]`.

마감된 판은 더 올릴 수 없다. 빈 칸이 있어도 영상은 만들 수 있고 빈 칸은 비워 둔다 `[확인 필요]`. 화면은 `마감 · 2 / 4칸`과 `마감돼서 더 올릴 수 없어요`를 보이고 `영상 만들기`, `내 칸 빼기`를 둔다.

서버에 올린 사진과 좌표는 마감 뒤 일정 기간이 지나면 지운다. 기간은 정하지 않았다 `[확인 필요]`. 판 화면에 이 사실을 안내한다.

## 9. 영상 만들기

각자 자기 폰에서 영상을 만든다. 서버는 영상을 만들지 않는다.

| 항목 | 값 |
|---|---|
| 비율과 크기 | 9:16, 1080×1920. 기존 경로 그림과 같다([경로 렌더링 FRD](route-rendering.md)) |
| 칸 | 4칸이 하나의 영상에 들어간다. 칸 사이에는 얇은 구분선을 둔다 |
| 재생 | 네 경로가 같은 시간에 함께 그려진다. 순차 재생은 후속이다 |
| 칸 배치 | 판을 만들 때 고른 배치가 기본이다. 결과물 화면에서 바꿔 볼 수 있고, 바꿔도 내 영상에만 적용된다 `[확인 필요]` |
| 칸 안 구성 | 경로, 칸에 보일 이름, 거리와 시간 |
| 공유 | `스토리로 공유`, `보관함에 저장`. 방법은 [내보내기·공유·저장 FRD](export-and-share.md)를 따른다 |

길이와 프레임은 기존 영상의 값(30fps, 12초)을 기본으로 보되, 칸 4개를 합성하는 비용을 구현 전에 확인한다 `[확인 필요]`.

## 10. 신고, 숨기기, 문의

사용자가 올린 사진과 이름을 다른 사용자가 보게 되므로 App Store 심사 가이드라인 1.2(걸러내기, 신고, 차단, 연락처 공개)에 맞추는 것을 전제로 한다. 어느 수준까지 갖출지는 팀이 정한다 `[확인 필요]`.

다른 사람의 칸을 `⋯`로 열면 시트에 이 셋을 둔다.

- `신고하기`: 사유(부적절한 사진이나 이름, 괴롭힘이나 혐오, 개인 정보, 그 밖의 이유)를 고르고 보낸다. 신고를 받아 처리하는 사람과 기간은 정하지 않았다
- `이 사람의 칸 숨기기`: 숨기면 내 화면과 내 영상에서 그 칸이 보이지 않는다
- `문의하기`: 공개 연락처를 보인다. 연락처는 정하지 않았다

## 11. 확인할 항목

- 4칸이 다 찼을 때 `영상 만들기`가 열리는지, 다 차기 전에는 기록과 이름과 배경을 바꿀 수 있고 다 찬 뒤에는 바꿀 수 없는지
- 마감이 지난 판에서 올리기와 바꾸기가 막히고 영상 만들기는 되는지
- 이번 주(일~토) 밖의 기록과 경로가 없는 기록이 목록에서 빠지는지
- 갤러리 사진의 보일 부분을 바꾸면 세 배치의 미리보기가 같이 바뀌는지
- 올리기 중에 네트워크가 끊겼다가 다시 올렸을 때 중복되지 않는지
- 내 칸을 빼면 서버에서 지워지고 내 폰의 원래 기록은 남는지
- 계정을 탈퇴하면 내 칸이 지워지는지
- 숨긴 사람의 칸이 내 화면과 영상에서 빠지는지
- 칸 4개를 합성한 영상을 만드는 시간이 기존 영상과 견줘 받아들일 만한지
- 큰 글씨 설정에서 칸 안의 이름과 숫자가 겹치지 않는지, 가로 4열에서 글자가 잘리지 않는지
