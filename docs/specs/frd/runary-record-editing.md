# Runary 자체 측정 기록으로 만들기

2026-10-19 사용자가 이 문서를 확인하고 `이 범위로 구현 진행`을 선택했다.

## 1. 요청과 범위

2026-10-19 사용자는 Runary 자체 측정으로 5km 이상 달린 기록이 있으며 실제 기기에서 수집을 확인했다고 알렸다. 이 기록도 그릴 기록 목록에서 선택할 수 있도록 요청했다. 사용자 실사용 확인을 근거로 편집 연결을 추가하며, 모든 수집 조건의 정확도 검증이 끝났다는 뜻으로 확대하지 않는다.

자체 측정이 켜진 개발·내부 빌드에 제공한다. 일반 제출 빌드의 측정 제외 범위와 공개 배포 여부는 바꾸지 않는다. 새 측정 기능이나 건강 앱 쓰기 권한을 추가하지 않는다.

## 2. 목록과 선택

`새로 만들기 → 러닝 기록`의 실제 기록 목록에 건강 앱 기록과 Runary 완료 기록을 날짜 최신순으로 함께 보여준다. 각 행에 출처를 표시하고 기존 날짜·거리·시간·평균 페이스·평균 심박 구성을 재사용한다. 샘플 체험은 기존 별도 진입을 유지한다.

Runary 기록은 완료·저장된 기록만 선택할 수 있다. 진행·일시정지·중단 복구·저장 실패 상태는 먼저 측정을 마쳐야 하므로 목록에서 제외한다. 그릴 좌표가 없는 완료 기록은 기존 정책처럼 목록에서 걸러내고 건수를 안내한다. 적어도 한 구간에 서로 다른 유효 좌표가 두 개 있어야 한다. 손상된 기록은 다른 기록과 건강 앱 조회를 막지 않고 재시도 안내로 구분한다.

자체 기록 조회는 건강 앱 권한이나 조회 성공을 조건으로 삼지 않는다. 한 출처가 로딩 중이거나 실패해도 다른 출처에서 읽은 기록과 샘플 체험을 사용할 수 있다. 조회는 화면 진입·새로고침·설정 복귀에서 수행하며 목록 폴링은 추가하지 않는다.

## 3. 편집 데이터

선택한 기록의 실제 경로와 측정 요약을 기존 트랙·편집 상태로 복사한다. 거리와 시간은 저장된 측정값을 사용하고, 건강 앱 읽기로 얻은 평균 심박이 있으면 함께 전달한다. 없는 심박이나 페이스를 0으로 채우지 않는다. 출처가 섞이지 않도록 Runary 식별자를 구분한다.

일시정지·중단·GPS 누락으로 나뉜 구간은 보존한다. 미리보기, 다듬기와 완성 영상에서 구간 사이를 직선으로 잇거나 거리·페이스에 더하지 않는다. 선택한 뒤에는 기존 배경 선택·경로 편집·영상 생성·사진 저장·보관함·다시 편집 흐름을 그대로 사용한다.

원본 측정 기록은 변경하거나 삭제하지 않는다. 초안과 결과물에는 복사한 경로가 남아 원본을 나중에 삭제해도 다시 편집할 수 있다. 선택 중 원본이 없어지거나 읽기에 실패하면 해당 행에서 재시도할 수 있고 다른 기록을 계속 고를 수 있다. 중복 탭과 다른 출처의 연속 선택은 한 번만 처리한다.

## 4. 확인 기준

- 실제 5km 이상 완료 기록이 목록에 나타나고 선택하면 경로와 지표가 편집에 전달된다.
- 건강 앱 실패·권한 미허용 때도 자체 기록과 샘플을 선택할 수 있다.
- 진행 중 기록과 경로 없는 완료 기록이 편집 대상으로 섞이지 않는다.
- 여러 구간의 경로가 미리보기와 영상에서 끊어진 채 유지되고 원본은 보존된다.
- 영상 생성·기기 저장·보관함에서 다시 편집까지 확인한다. 확인하지 못한 단계는 별도로 기록한다.
