# 샘플 기록 체험 FRD

2026-10-12 FRD를 사용자에게 제시한 뒤 샘플 후보와 정식 앱 포함 여부를 설명했다. 사용자는 하트를 선택하고 로컬에서 먼저 확인하도록 요청했다. HealthKit 실제 기록 읽기에 샘플 체험 예외를 추가하며, TestFlight 업로드는 사용자 로컬 확인 뒤 진행한다.

## 1. 진입

첫 실행 안내와 홈에서 `샘플 기록으로 만들어 보기`를 제공한다. 실제 러닝 기록으로 만드는 기존 진입은 유지한다. 기록 선택에서도 불러오기·오류·빈 상태와 관계없이 샘플 체험에 진입할 수 있게 한다.

샘플 버튼을 누르면 건강 권한 요청·HealthKit 조회 없이 샘플 기록과 트랙을 생성 상태에 설정하고 기존 배경 선택 화면으로 이동한다. 첫 실행의 샘플 선택 뒤에는 안내를 반복하지 않으며 뒤로 이동하면 홈으로 돌아갈 수 있다. 샘플 준비에 실패하면 현재 화면에서 다시 시도할 수 있다. 중복 탭은 같은 동작을 겹쳐 실행하지 않는다.

이미 선택한 실제 기록의 좌표를 불러오는 동안에는 샘플 시작을 잠근다. 목록 자체의 로딩·오류·빈 상태에서는 사용할 수 있으며, 두 기록의 생성 상태가 서로 덮어쓰지 않게 한다.

## 2. 샘플 데이터

앱에 포함한 하트 모양 가상 기록 한 건을 사용한다. 사용자가 비교한 하트 좌표와 같은 생성식을 사용하며 2026-10-01·약 5km·30분·6분/km로 맞춘다. 실제 사용자의 경로와 건강 데이터는 복사하지 않는다. 합성 좌표의 기준점은 위도·경도 0이며 실제 달릴 수 있는 코스로 안내하지 않는다.

샘플임을 판별할 수 있는 안정적인 식별자를 사용한다. 실제 러닝 기록 목록에 자동 삽입하지 않는다. 결과물에 저장한 기록과 트랙에도 샘플 식별을 유지한다.

## 3. 편집과 결과물

배경 선택부터 [결과물 편집 FRD](result-editing.md)와 [내보내기·공유·저장 FRD](export-and-share.md)의 실제 기능을 사용한다. 건강 권한을 허용하지 않아도 기본 배경으로 영상 생성까지 진행할 수 있다. 사진 접근이나 사진 앱 저장 등 사용자가 선택한 기능의 권한은 기존 규칙대로 필요한 순간에 요청한다.

편집 화면에 `샘플 기록`을 표시한다. 보관함에서도 샘플로 만든 결과물임을 알 수 있게 한다. 앱 재실행 뒤 초안 복구·결과물 다시 편집·같은 기록으로 새로 만들기에도 샘플 트랙을 사용한다. 해당 식별자를 HealthKit으로 조회하지 않는다.

완성 MP4는 기존 저장·공유 기능으로 실제 전달한다. 공유 대상 앱을 실행하거나 외부 게시를 테스트할 때는 사용자 승인 범위를 따른다. 샘플 표시를 위해 편집·영상 출력 규격을 바꾸지 않는다.

## 4. 건강 데이터와 외부 요청

샘플 진입·편집에서 건강 데이터를 읽거나 쓰지 않는다. 실제 기록을 선택하면 기존 HealthKit 읽기 흐름을 사용한다.

샘플 경로의 장소 이름은 외부 역지오코딩으로 조회하지 않는다. 장소를 표시한다면 `샘플 코스` 같은 고정 문구를 사용한다. Expo 업데이트와 사용자가 선택한 공유 등 기존 네트워크 기능의 동작을 이 규칙으로 없앴다고 설명하지 않는다.

## 5. 일반 제출 빌드

`production` 프로필을 사용한다. `RUNARY_INTERNAL_TRACKING`은 활성화하지 않고, 아이폰 측정 진입·워치 진단·워치 앱·측정용 위치 백그라운드 설정이 포함되지 않는지 최종 설정과 바이너리에서 확인한다. 샘플 체험은 일반 사용자에게도 제공하며 별도 심사자 전용 숨김 기능으로 만들지 않는다.

버전은 기존 `1.0.0`을 기준으로 준비하되 제출 버전 표기와 맞는지 확인한다. 빌드 번호는 새 업로드에서 증가시킨다. 최종 번호는 배포 기록에 남긴다.

## 6. 검증

- 건강 권한 미응답·거부·기록 없음 상태에서 첫 화면과 홈의 샘플 진입이 가능하다.
- 기록 선택의 로딩·오류·빈 상태에서도 샘플 진입이 막히지 않는다.
- 기본 배경으로 편집한 내용이 실제 MP4에 반영되고 사진 앱 저장 경로가 동작한다.
- 샘플 초안과 결과물은 앱 재실행 뒤 복구·재편집되고 건강 앱 조회 없이 같은 기록으로 새로 만들기가 된다.
- 실제 건강 기록의 불러오기·편집은 기존대로 동작한다.
- 샘플의 외부 장소 조회가 없고 일반 빌드에 측정·워치 진단이 노출되지 않는다.
- 타입·린트·문서 검사와 해당 회귀 검사를 통과한다. 실기기나 외부 공유에서 확인하지 못한 항목은 완료로 기록하지 않는다.
