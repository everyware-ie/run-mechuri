# 정책 문서 링크 FRD

이용약관 공개 및 앱 연결의 착수 확인안이다. 개인정보 처리방침의 열기 실패 수정은 기존 [홈 FRD](home-and-library.md) §1-2 개인정보 처리방침에 반영했다.

## 1. 제공 위치

첫 실행 안내와 홈 하단에서 `서비스 이용약관`과 `개인정보 처리방침`을 나란히 제공한다. 좁은 화면에서는 자연스럽게 다음 줄로 배치한다. 각 링크의 터치 높이는 44pt 이상이다.

로그인이나 건강 권한이 없어도 접근할 수 있다. 별도의 동의 체크·가입 절차를 추가하거나 건강 권한 요청과 묶지 않는다.

## 2. 문서 열기

공개 노션의 확정 URL을 앱 내 시스템 브라우저로 연다. 문서 본문을 앱에 복제하지 않으며 닫으면 이전 앱 화면으로 돌아온다. 중복 열기를 막고 실패 시 해당 문서 이름을 포함한 안내와 재시도를 제공한다.

공개되지 않은 초안 URL·빈 주소·다른 서비스의 약관을 임의로 연결하지 않는다. 각 문서가 로그인 없이 읽히는 것을 확인한 뒤 정상 링크로 취급한다.

## 3. 공개 전 확인

사용자가 약관 내용을 확인하고 실제 계약상 운영 주체 이름과 시행일을 확정한다. 이후 공개 노션 게시와 앱 연결을 진행한다. 팀 이름만으로 법적 운영 주체를 단정하거나 개발자 계정 명의를 자동 복사하지 않는다.

약관 링크 제공만으로 모든 이용자의 계약 동의가 입증됐다고 설명하지 않는다. 중요한 계약 조건에 대한 별도 안내·동의 절차가 필요한지는 운영자의 공개 검토에서 확인한다.

## 4. 검증

실기기에서 각 문서의 제목·본문과 닫기 복귀·재열기를 확인한다. 중복 탭·실패 재시도 회귀와 타입·린트·문서 검사를 수행한다. 시행일·운영 주체 미확정 또는 공개 상태 미확인은 완료로 기록하지 않는다.
