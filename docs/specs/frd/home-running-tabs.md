# 보관함과 러닝 하단 탭

2026-11-03 사용자가 2~4절 범위를 확인하고 구현 진행을 승인했다. 이 문서를 구현 근거로 사용한다.

## 1. 문제와 선택

현재 러닝 진입 카드는 결과물 목록의 맨 아래에 있다. 결과물이 늘어날수록 측정을 시작하려고 긴 목록을 내려야 한다.

2026-11-03 사용자는 세 가지 진입 시안 중 보관함과 러닝을 나눈 하단 탭 구성을 선택했다. 이어 러닝 탭 아이콘은 두 번째인 경로 모양을 골랐다. 편집 화면의 경로 도구와 같은 아이콘을 사용해 일관성을 유지한다는 이유를 밝혔다.

## 2. 화면 구성

측정 기능이 포함된 빌드에 보관함과 러닝 탭을 제공한다. 두 탭은 결과물 목록의 스크롤과 분리해 화면 아래에 고정한다. 측정 기능이 없는 기존 빌드의 진입 제한은 유지한다.

| 탭 | 연결할 화면 | 표시 |
|---|---|---|
| 보관함 | 현재 홈의 결과물 목록 | 네 칸 격자 아이콘과 `보관함` |
| 러닝 | 러닝 준비 또는 진행 중인 같은 러닝 | 편집 화면과 같은 경로 아이콘과 `러닝` |

보관함은 이어서 만들기, 최근 결과물과 기존 목록을 유지한다. 현재 `새로 만들기` 버튼은 시안처럼 `영상 만들기`로 표시하고 같은 기록 선택 화면으로 연결한다. 샘플도 이 흐름에서 선택한다.

목록 끝의 기존 러닝 진입 카드는 탭으로 대체한다. 앱 권한 확인과 개인정보 처리방침 링크는 계속 접근할 수 있게 남긴다. 목록 마지막 항목과 링크가 고정 탭에 가려지지 않도록 아래 여백과 기기 안전 영역을 확보한다. 각 탭의 터치 높이는 44pt 이상이다.

실제 경로 아이콘은 편집 화면의 `point.bottomleft.forward.to.point.topright.scurvepath`를 함께 사용한다. 선택한 탭은 주황색으로 표시하고, 선택하지 않은 탭은 보조 색으로 표시한다. 아이콘 아래의 문구도 함께 제공한다.

## 3. 러닝 진입과 전환

러닝 탭을 누르면 준비 화면으로 이동한다. 측정은 기존처럼 준비 화면의 시작 버튼을 눌렀을 때 시작한다. 탭을 누르거나 보관함을 여는 것만으로 운동 기록을 만들지 않는다. 시작 전 위치 미리보기와 권한 요청 시점은 기존 측정 FRD를 따른다.

진행 중이거나 일시정지한 러닝이 있으면 그 기록으로 돌아간다. 새 기록을 만들지 않으며, 보관함에 있을 때도 러닝 탭에 진행 상태를 표시한다. 측정 중에는 `측정 중`, 일시정지 중에는 `일시정지`로 안내하고 아이콘 옆에 작은 표시를 둔다.

준비 화면에서는 하단 탭을 유지한다. 실제 측정 화면에서는 기존 종료·일시정지·재개 버튼에 공간을 배분하도록 하단 탭을 숨긴다. 측정 화면의 뒤로가기는 보관함으로 연결하며, 이 이동이 측정을 종료하거나 일시정지하지 않는다.

탭을 여러 번 왕복해도 화면이 계속 쌓이지 않아야 한다. 보관함의 스크롤 위치와 편집 초안, 측정 기록을 유지한다. 워치나 잠금화면에서 변경한 상태는 다시 러닝으로 들어갈 때 최신 네이티브 상태로 확인한다.

## 4. 다른 화면과의 관계

첫 실행 안내와 기록 선택, 배경 선택, 편집, 결과물 상세와 공유에서는 하단 탭을 표시하지 않는다. 기존의 집중해서 만드는 흐름을 유지한다.

첫 실행 안내에서 러닝을 선택한 경우에도 안내를 마친 것으로 보관한다. 이후 보관함으로 돌아올 때 안내가 다시 나타나지 않게 하며, 측정 기능이 포함된 빌드의 첫 설명도 실제 직접 측정 기능과 맞춘다.

워치·잠금화면에서 같은 러닝을 여는 주소와 복구 동선은 유지한다. 탭 전환은 측정 엔진, 워치 운동 세션, 심박 전달과 건강 저장의 시작·중단 조건을 바꾸지 않는다.

## 5. 확인할 항목

- 결과물이 없을 때와 많이 쌓였을 때 모두 목록을 내리지 않고 러닝을 열 수 있는지 확인한다.
- 보관함과 준비 화면을 반복 전환해도 초안·스크롤 위치를 유지하고 화면이 중복으로 쌓이지 않는지 확인한다.
- 진행 중·일시정지 상태에서 같은 기록으로 돌아가고, 보관함 이동 중에도 측정이 계속되는지 확인한다.
- 편집에서 돌아오거나 워치·실시간 현황으로 진입했을 때 화면과 선택 상태가 맞는지 확인한다.
- 좁은 화면과 안전 영역에서 탭·마지막 목록 항목이 가려지지 않는지 확인한다.
- 측정이 없는 빌드는 기존 홈과 접근 제한을 유지하는지 확인한다.
