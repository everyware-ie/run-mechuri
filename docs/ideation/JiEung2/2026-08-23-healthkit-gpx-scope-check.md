# HealthKit·GPX 구분 정리

*2026-08-23 · JiEung2 개인 정리 원문 · [phs00 2주차 업무 분배 제안](../phs00/2026-08-19-w2-work-split-proposal.md) "결정 회의 전" 담당 항목*

> 성격: 새 리서치가 아니라 **이미 PRD·결정문·FRD에 흩어져 있는 판단을 한자리에 모아 확인하는 정리 노트.** 실제로 열려 있는 것과 이미 닫힌 것을 가른다.

## 결론 요약

**정책 판단(HealthKit 우선)은 이미 끝나 있다.** 남은 건 둘뿐이다.

1. GPX를 **"여유 시"로 열어둘지, "완전 제외"로 굳힐지** — 회의에서 확인 필요
2. **팀 3명 기기에서 HealthKit 워크아웃에 좌표가 실제로 저장돼 있는지** — 아직 아무도 확인 안 함, 이게 진짜 남은 작업

## 1. HealthKit과 GPX는 위계가 아니라 병렬 경로

헷갈리기 쉬운 지점부터 정리한다. **"HealthKit을 쓰면 GPX 데이터를 가져다 쓰는 것"이 아니다.**

| | 경로 |
|---|---|
| **HealthKit** | 앱이 애플 API(`HKWorkoutRoute`)를 직접 호출 → 좌표 배열을 바로 받음. 파일이 끼지 않는다 |
| **GPX** | 사용자가 (다른 앱으로) GPX 파일을 추출 → 우리 앱에 업로드 → 우리가 파싱 |

둘은 같은 데이터(좌표열)를 얻는 **서로 독립적인 두 개의 입력 경로**다. 하나가 다른 하나를 경유하지 않는다.

## 2. 이미 확정된 정책

[PRD §6](../../specs/prd/running-drawing-mvp.md), [08-18 결정문 §2](../../decisions/2026-08-18-native-ios-and-mvp-scope.md), [러닝 기록 선택 FRD §1](../../specs/frd/run-record-selection.md)에 이미 반영돼 있다 (2026-08-23 갱신).

- **MVP 기본은 HealthKit 읽기 하나다.** GPX 임포트는 **여유 시**로 내린다
- 이유: 애플 기본 건강 앱은 **개별 워크아웃 GPX 내보내기 기능 자체가 없다.** 서드파티 앱을 한 번 거쳐야 하고, 그마저 나이키런클럽 같은 앱은 공식 반출 경로가 아예 없다(JiEung2 2026-08-16 데이터 확보 조사). **사용자에게 GPX 추출·임포트를 기대하기 어렵다는 판단이 이미 근거로 깔려 있다** — 지금 갖고 있는 문제의식과 같은 방향이다
- 목록은 "HealthKit 워크아웃 목록"이 아니라 **"내 러닝 기록 목록"**으로 설계돼 있다. 출처는 기록의 속성 하나일 뿐이라, 나중에 GPX가 붙어도(혹은 영영 안 붙어도) 화면 구조가 안 흔들린다

**즉 "무조건 HealthKit으로 간다"는 이미 정해진 방향과 같다.** 새로 결정할 게 아니라 확인하고 넘어갈 항목이다.

## 3. `[확인 필요]` GPX를 완전히 제외할지, 여지를 남길지

지금 문서들은 GPX를 **"완전 제외"가 아니라 "여유 시"**로 적어뒀다. 이건 실수가 아니라 이유가 있다.

[PRD §10 로드맵 — 그룹 드로잉](../../specs/prd/running-drawing-mvp.md#10-로드맵)이 "GPX 임포트가 들어가면 계정 없이 트랙을 주고받아 합쳐 그리는 최소 형태가 가능해진다"고 GPX에 기대는 후속 기능을 하나 걸어뒀다. 그래서 phs00이 문을 완전히 닫지 않고 "여유 시"로 남겨둔 것으로 보인다.

**회의에서 확인할 것**: MVP 5주 안에는 GPX를 안 만들 거라는 실질(=사실상 제외)은 이미 같은데, **문서상 표현을 "완전 제외"로 굳힐지 "여유 시"로 열어둘지**는 팀 확인이 필요하다. 실무 영향은 크지 않지만(어차피 이번 5주 안에는 안 만든다), 로드맵 문서의 정확성 문제다.

## 4. 진짜 남은 작업: 실기기 확인

**여기가 이 작업 항목에서 유일하게 아직 아무도 안 한 일이다.** [FRD §7](../../specs/frd/run-record-selection.md#7-확인-필요-모아보기)이 "이 문서에서 가장 중요하다"고 표시한 항목과 같다.

> 워크아웃이 있어도 좌표가 함께 저장돼 있지 않을 수 있다. 그런 기록은 목록엔 뜨는데 그릴 수 없다. **흔하면 GPX가 "여유 시"에서 "필수"로 격상된다.**

**확인 방법**: 아이폰 건강 앱 → 탐색(Browse) → 활동(Activity) → 실외 달리기 워크아웃 하나 열기 → **경로 지도가 뜨는지** 확인.

| 확인 대상 | 결과 |
|---|---|
| JiEung2 | `[확인 필요]` |
| jminkkk | `[확인 필요]` |
| phs00 | `[확인 필요]` |

**하나라도 좌표가 없으면**: FRD §2-2의 "고를 수는 있는데 그릴 수 없다" 처리가 실제로 자주 발동한다는 뜻이라, GPX를 앞당겨야 할지 다시 논의해야 한다.
