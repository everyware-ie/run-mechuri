## 기록 원칙

- 사실에는 원문 URL과 확인일을 남긴다.
- 개인 가설과 팀 결정을 구분한다. 팀 결정은 회의 종합·decision 문서가 근거다.
- 한 노트는 한 가지 재사용 목적만 다룬다. 주제가 달라지면 새 날짜 파일을 만든다.
- 새 생각·정정은 기존 raw 원문을 고치지 않고 후속 노트에 기록한다.
