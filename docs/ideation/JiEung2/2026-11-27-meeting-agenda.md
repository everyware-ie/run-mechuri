## 1. 합동 그리기가 무엇인지 (공유)

한 판을 4칸으로 나눠서, 칸마다 다른 사람이 자기 러닝을 올려 하나의 9:16 영상으로 만든다. 크루는 만들지 않는다

- 한 판은 이번 주(일요일부터 토요일) 단위이고 토요일 자정에 마감된다
- 만든 사람이 칸 배치를 고른다. 2×2, 세로 4행, 가로 4열 중 하나다
- 만든 뒤 초대 링크를 보낸다. 초대받은 사람이 링크로 들어와 빈 칸의 `+`를 눌러 기록을 올린다
- 올릴 때 이번 주 기록 하나, 칸에 보일 이름, 칸 배경을 고른다. 기록은 앱 측정과 건강 앱에서 가져온 기록 모두 가능하다
- 4칸이 다 차기 전에는 내 칸의 기록을 바꿀 수 있고, 다 차면 바꿀 수 없다
- 각자 폰에서 영상을 만들어 인스타 스토리로 올린다. 서버는 기록, 이름, 배경을 저장하고 전달만 한다

지응이 정한 것과 시안을 그리며 제안한 것은 [노트 §2, §3](2026-11-27-group-drawing-note.md)에 나눠 적었다.

## 2. 사진을 서버에 올리는 것과 심사 (10분)

칸 배경으로 갤러리 사진을 쓰려면 사진을 서버에 올려야 다른 사람 폰에서 같은 영상을 만들 수 있다. 지응이 이렇게 가기로 했다.\
그러면 한 사람이 올린 사진을 다른 사람이 보게 된다. App Store 심사 가이드라인 1.2는 사용자가 만든 콘텐츠를 다른 사용자에게 보여 주는 앱에 네 가지를 요구한다. 부적절한 내용을 거르는 장치, 신고하고 제때 처리받는 수단, 괴롭히는 사용자를 막는 차단, 사용자가 연락할 수 있는 공개 연락처다.\
크루 시안에서 크루 찾기와 사진 기반 안을 첫 버전에서 뺀 이유도 같은 가이드라인이다. 합동 그리기는 초대받은 사람끼리만 보는 비공개 판이라는 점이 완화 요인일 수 있지만, 심사에서 어떻게 판단할지는 확정하지 못했다 `[확인 필요]`.

정할 것

- 1.2에 맞춰 신고, 차단, 연락처를 첫 버전에 넣을지. 넣는다면 신고를 받아 처리하는 사람과 절차
- 갤러리 사진 배경을 첫 버전에 넣을지, 기본 배경 6장만으로 시작하고 사진은 1.2 대응을 갖춘 뒤에 열지
- 서버에 올린 사진과 좌표를 마감 뒤 며칠 뒤에 지울지
- 개인정보 처리방침에 사진과 경로를 서버에 보관한다는 내용이 들어가야 한다. 지금 처리방침은 자체 서버를 운영하지 않는다고 적혀 있다. 로그인 작업에서 이미 고쳐지고 있다면 같이 본다 `[확인 필요]`

## 3. 규칙으로 정할 것 (15분)

시안에는 아래 가정을 넣어 그렸다. 팀이 다르게 정하면 시안을 고친다.

| 질문 | 시안의 가정 |
|---|---|
| 크루 없이 방장 없는 구조로 가도 되나 | 만든 사람에게 특별한 권한이 없다. 각자 자기 칸만 관리한다. 초대 링크는 참여한 사람 누구나 보낼 수 있다 |
| 한 칸이라도 채워지면 칸 배치를 바꿀 수 없나 | 바꿀 수 없다. 이미 올린 사진의 보일 부분이 배치마다 다르게 잘리기 때문이다 |
| 마감 뒤 빈 칸이 있어도 영상을 만들 수 있나 | 만들 수 있다. 빈 칸은 비워 둔다 |
| 칸 위치를 내가 고르나 | 아무 `+`나 누르면 그 칸이 내 칸이다. 한 사람은 한 칸만 채운다 |
| 기록을 올린 뒤 원본을 지우면 | 올린 사본은 남는다. 지우려면 내 칸 빼기를 따로 한다. 계정을 탈퇴하면 내 칸은 지워진다 |
| 한 사람이 같은 주에 합동 그리기를 여러 개 만들거나 참여할 수 있나 | 허용한다. 한 기록을 여러 곳에 올리는 것도 허용한다 `[확인 필요]` |
| 4칸이 다 찬 뒤 내 칸 빼기 | 허용한다. 빼면 그 칸은 비게 된다. 비게 된 칸에 다시 올릴 수 있는지는 정하지 않았다 |
| 갤러리 영상을 배경으로 허용하나 | 허용하지 않는다. 용량이 커서 다음 단계로 미룬다 |
| 영상 재생은 | 네 경로가 같은 시간에 함께 그려진다. 순차 재생은 후속이다 |
| 이름 | 기능 이름은 합동 그리기, 화면 문구는 "함께 그리기"로 했다. 하나로 맞출지 |

## 4. 서버와 시안 (5분)

- 서버는 지민의 로그인 작업이 끝난 뒤에 한다. 지민 Mac에서만 돌고 아직 배포하지 않았다([지민 안건](../jminkkk/2026-11-24-meeting-agenda.md) §1). 서버를 어디에 띄울지는 11/20 회의에서 다루지 않았다
- 서버가 정해지면 필요한 것은 판 저장, 초대 링크 처리, 칸 기록과 사진 저장, 마감 뒤 삭제다
- 4칸의 배경과 경로를 한 영상에 합성하는 비용을 구현 전에 확인해야 한다. 기존 12초 영상도 속도 개선 작업이 있었다
- 현수가 봐 줄 것: 가로 4열에서 사진이 얇은 띠로 잘리는 것이 괜찮은지, 칸의 주황 테두리가 "주황은 한 화면에 한 가지 일에만" 규칙과 부딪히지 않는지
