# 크루 기능: 친구와 함께 계속 뛰게 만들기

*2026-11-10 · jminkkk · 개인 제안이며 팀 결정이 아님*

지금은 결과물을 올리고 나면 다음 러닝 전까지 앱을 열 이유가 없다. 친구와 묶이면 다시 열 이유가 생긴다.

## 기능

| 기능 | 무엇 | 서버 |
|---|---|---|
| 크루 | 친구끼리 크루를 만들고 카톡 초대 링크로 들어온다 | 필요 |
| 크루원 러닝 | 크루원이 뛴 거리·시간을 본다. 뛰면 알림이 온다 | 필요 |
| 응원 | 크루원의 러닝에 응원을 누른다. 받은 사람에게 알림이 간다 | 필요 |
| 주간 목표 | 크루가 이번 주에 함께 채울 거리와 진행률 | 필요 |
| 내 주간 합본 | 내가 이번 주에 뛴 기록 여러 개를 한 결과물에 모은다 | 불필요 |
| 크루 합본 | 내 주간 합본과 같은 레이아웃에 크루원 기록을 넣는다. **가설**: 매력이 있는지 먼저 확인한다 | 필요 |

## 필요한 것

서버, 계정, 초대 딥링크, 푸시, 처리방침 개정, 앱 안 계정 삭제([심사 지침 5.1.1(v)](https://developer.apple.com/app-store/review/guidelines/#5.1.1))

## 정할 것

크루 합본의 매력, 크루 인원, 러닝을 자동으로 올릴지, 누가 만들지
