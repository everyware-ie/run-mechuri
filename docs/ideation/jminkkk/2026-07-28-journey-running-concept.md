## 한 줄 컨셉

> 네가 실제로 뛴 **지역·경로가 곧 여정의 진척**이 된다 — 현실 지리 위에서 한국 루트(제주 올레·국토종주·한강·지리산 둘레길…)를 완주해 나가는 러닝 앱. 혼자서도 완결되고, 친구가 있으면 위치 공유로 더 재밌어진다.

## 코어 + 부가 레이어

- **🔵 코어 (최우선·양보 불가): 실제 지역 기반 여정형.** 실제 뛴 지역이 진척이 되는 현실 지리 앵커. 혼자서도 완결된다.
- **🟢 부가 기능 (1순위 후보): 위치 공유.** 코어 위에 얹는 옵션(필수 아님). 친구와 진척·구간 도착을 공유. *나머지 부가 기능(수집·인증·릴레이 등) 발산은 다음 세션.*

---

## 어떻게 여기까지 왔나

1. 4개 축(습관화 / 기록·성장 / 소셜 / 게임화) 중 **기록·성장 × 습관화**를 골랐다.
2. 실사용 신호로 방향이 꺾였다 — 문제는 "성장이 안 느껴진다"가 아니라 **재미·리텐션**이었다. → 축이 **습관화 × 재미**로 이동.
3. "재미"를 **다른 테마와 결합(매핑)** 하는 아이디어로 발전 — 지루한 숫자를 매력적인 세계 위에 얹기.
4. 여러 테마 중 **여정형**을 골랐고, **실제 지역 기반**을 코어로 확정.
5. 리텐션 엔진 후보를 발산 → **보증금은 폐기**(사행성 톤), **위치 공유를 부가 기능**으로 채택.

## 누구의 문제인가

- 타겟: **혼자 뛰는 폰-온리 입문~중급 러너.**
- 근거(개인 경험): 나는 직접 뛰고 **나이키 런 클럽(NRC)만** 쓴다. 페이스·거리로 성장은 느껴지지만, **매일 앱을 열게 만드는 장치가 없다.** → 기록 해석보다 **리텐션·재미**가 결핍.

## 컨셉 상세 (개인 가설)

**코어 — 실제 지역 기반 여정**
- 누적 거리·경로로 한국 실제 루트를 가상 완주. 도착 지점마다 랜드마크·엽서·구간 해금.
- 차별의 핵심 = **현실 지역성**(내가 실제 뛴 곳이 진척) + **혼자서도 완결**.

**부가 — 위치 공유 (옵트인)**
- 친구와 여정 진척·구간 도착을 공유해 함께 뛰는 재미. Zenly(2023 종료)가 남긴 "친한 친구 위치 공유" 공백을 러닝에 붙이는 각도.
- 처음부터 **"실시간 좌표"가 아니라 "구간 도착·진척 공유"** 수준으로 순화 전제(안전 리스크 완화).

- **GPS·개인정보 규제** — 러닝 앱 공통 벽(Strava가 한국서 못 넘은 지점). 로컬 팀엔 방어막이 될 수도. `[미결]`
- **The Conqueror 대비 차별점** — 여정형 자체는 해외에서 검증됨. 우리 차별 = ① 한국 루트·실제 지역성 ② 위치 공유 부가 ③ 한국 러너 대상. 충분한지 `[미결]`
- **리텐션 엔진** — 보증금을 뺀 뒤, "현실 지역 정복 재미 + 친구 공유"만으로 재방문이 충분한지 검증 필요. `[미결]`

## 검증 질문 (다음 회의 안건)

1. 실제 지역 매핑 방식: 실거리 1:1 vs 상징적. 스트리트뷰·랜드마크 해금 범위.
2. 위치 공유 순화 수준: "구간 도착·진척"까지만 vs 실시간 좌표 옵션 제공 여부.
3. 부가 기능 우선순위: 위치 공유 외 무엇을(수집·인증·릴레이 등) 언제 붙일지.
4. 수익모델: 구독 / 루트 콘텐츠 판매 / 지역 제휴.
