## 1. 정식 등재, 어디까지 왔나 (15분)

### 이번 주에 한 것

- **하트 샘플**: 건강 앱에 러닝 기록이 없어도 하트 모양 샘플로 편집과 영상 만들기를 해 볼 수 있다. 심사하는 사람 폰에는 러닝 기록이 없어서 넣었다 (10/12, [결정](../../decisions/2026-10-12-heart-sample-experience.md))
- **개인정보 처리방침**: 앱 안에서 바로 열리게 고치고, 공개 방침과 FAQ를 정리했다
- **빌드 37**: 측정 기능을 뺀 일반 빌드를 TestFlight에 올렸다 (10/12)
- **최종 검토 (10/13)**: 앱에 보관한 영상이 아이폰 백업에 들어가던 것 등 3건을 고쳤다. 이건 37번에 안 들어가서 **제출용 새 빌드가 필요하다** ([최종 검토](../../ops/app-store-final-review-2026-10-13.md))

### App Store Connect 상태 (10/13 저녁)

자료는 준비됐지만 등록은 아직이다. 지금 상태로는 제출할 수 없다.

| 항목 | 상태 |
|---|---|
| 제출할 빌드 | 아직 안 골랐다 (새 빌드 필요) |
| 언어 | 영어 하나만 있다. 한국어를 추가해야 한다 |
| 설명·키워드·부제 | 비어 있다 |
| 스크린샷 | 0장 |
| 지원·개인정보 URL | 등록 안 됨 |
| 심사 연락처·심사 메모 | 등록 안 됨 |
| 앱 개인정보 설문, 연령 등급 | 확인 못 했다 |

### 스토어 자료에서 고칠 것 (PR #109)

- "어디에도 보내지 않아요" → 장소 이름 조회와 인스타 공유가 있어서 정확하지 않다. "러닝 기록과 영상을 우리 서버에 올리지 않아요" 정도로
- "모두 내가 실제로 달린 데이터" → 하트 샘플이 생겼으니 예외를 넣어야 한다
- 첫 이미지의 "사진으로 남겨요" → 실제로는 영상을 만든다

## 2. 제출까지 남은 일 나누기 (15분)

| 할 일 | 누가 |
|---|---|
| 제출용 새 빌드 만들고 폰에서 확인 (샘플 영상, 사진 앱 저장, 다시 열었을 때 복구, 아이패드) | |
| 스토어 문구 고치고 App Store Connect에 등록 (한국어, 설명, 키워드, 스크린샷) | |
| 지원·개인정보 URL, 심사 연락처, 심사 메모 (샘플로 들어가는 법 설명) | |
| 앱 개인정보 설문. 업데이트 모듈 때문에 "수집 없음"을 고르면 안 된다 | |
| 연령 등급, 배포 국가, 계약 확인 | |
| 심사 제출 | |

### 정할 것

- 위 일을 누가 맡을지. App Store Connect는 계정 주인이 지민이라 지민이 하는 게 빠를 수 있다
- 실제 제출일
- 버전 표기. App Store Connect는 `1.0`, 앱은 `1.0.0`이다. 하나로 맞춘다

## 3. 러닝 측정 근황 (10분)

10/6에 정한 대로 바꿨다. 내부 빌드 36에 들어 있다 (10/9).

- 심박은 건강 앱에서 읽어 온다. 애플 운동을 같이 켜도 안 꺼진다
- 워치는 자체 운동을 시작하지 않고, 아이폰 지표를 보여 주고 시작·정지만 한다
- 워치에서 읽은 심박을 아이폰으로 바로 보내서, 건강 앱 동기화가 늦어도 들어오게 했다

### 아직 남은 것

- 메모리 때문에 앱이 꺼지던 문제 (10/6 출근길)는 아직 손대지 않았다
- GPS가 끊긴 구간을 나이키 런·스트라바가 어떻게 처리하는지 조사
- 11/3 재제출까지 3주 남았다
