## 2. 스레드 통계와 팔로워 50명 (20분)

이제 수치가 레포에 쌓인다. 안건을 쓸 때마다 갱신한다. ([스레드 통계](../../marketing/threads/stats.md))

### 수치를 어떻게 모으나 (공유)

- Meta 개발자 사이트에 "Runary 스레드 통계" 앱을 만들었다. 팀 구글 계정으로 만든 페이스북 계정에 있다
- 팀 스레드 계정(@team.mechuri)을 이 앱의 테스터로 연결했다. 개발 모드라 심사가 필요 없고 비용도 없다
- 스크립트 한 줄로 수치를 받아 레포에 쌓는다. 토큰은 현수 맥에만 있다 ([사용법](../../marketing/threads/README.md))
- 앱 화면 캡처는 노션 회의록에 있다

**2. 10/12 주에 조회가 확 뛰었다**
주별 조회가 13 → 58,715로 늘었다. 질문형 글을 올리기 시작한 주다.

**3. 조회가 팔로우로 이어지지 않는다**
조회는 수만인데 팔로워는 9명, 링크 클릭은 0이다. 질문 글에 답한 사람이 우리 계정이나 Runary를 알게 되는 장치가 없다.

### 정할 것

- 질문형 글을 계속 밀지
- 질문 글에서 팔로우나 Runary로 잇는 방법. 예: 답글에 결과물 영상 달기, 질문과 결과물을 한 글에 같이, 프로필에 앱 링크
- 누가, 일주일에 몇 개 올릴지

## 3. 러닝 측정 근황 (10분)

내부 빌드 41에 들어갔다 (10/19, [PR #114](https://github.com/everyware-ie/run-mechuri/pull/114)).

- **잠금화면**: 러닝 중 거리와 시간이 보이고, 일시정지·재개·종료를 바로 누를 수 있다
- **바로 시작**: 버튼 한 번이면 시작한다. GPS를 기다리지 않는다
- **시작 전 위치**: 현재 위치를 미리 보여 준다
- **잰 기록으로 그림 만들기**: 측정한 기록을 건강 앱 기록과 같이 날짜순으로 골라 영상을 만든다
- **보관함 영상 재생**: 결과물 상세에서 영상을 틀고 넘겨 볼 수 있다

현수가 10/14 실제 러닝(5.41km, 38분)으로 측정부터 영상 저장까지 끝까지 확인했다.

### 아직 남은 것

- 워치 권한 (10/13): 같은 권한을 또 묻는 건 고쳤다(빌드 36). 아이폰과 워치에서 처음 한 번씩 따로 묻는 건 남아 있다. 워치OS가 워치에서 따로 허용받게 돼 있어서, 처음 설정할 때 미리 받아 두는 쪽으로 줄일 수 있다
- 메모리 때문에 앱이 꺼지던 문제 (10/6). 38분 러닝에서는 안 꺼졌지만 따로 고치진 않았다
- GPS가 끊긴 구간 처리 조사
- 11/3 재제출까지 2주
