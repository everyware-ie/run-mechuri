## 0. 지금 어디 있나 (5분, 공유)

**앱은 준비됐다.** 9/20에 빌드 `1.0.0(23)`을 올렸다.

| | |
|---|---|
| 이름 | **Runary**로 바뀌었다. 표시 이름, 화면 문구, 노션 안내까지 |
| 처리방침 | **앱 안에 링크가 생겼다.** 첫 실행 안내와 홈 목록 아래 |
| 편집 | 경로 선택 박스 동기화, 러닝 데이터 크기 슬라이더, 항목별 터치 영역 |
| 러닝 데이터 가독성 | **원인 둘을 찾아 고쳤다** (아래) |

### 가독성이 왜 안 좋았는지 밝혀졌다

9/16에 "최우선"으로 올린 그 항목이다. 원인이 둘이었다.

**결과물을 굽는 Swift가 항상 흰색 발광으로 그리고 있었다.** 미리보기는 프리셋에 따라 옅은 검정 그림자를 쓰는데 최종 mp4만 전부 흰빛이 돌았다. **그래서 편집 화면보다 결과물이 더 번져 보였다.**

**글씨체도 달랐다.** 미리보기는 실제 폰트를 쓰는데 Swift 쪽은 시스템 폰트로 근사하고 있었다.

`[확인 필요]` **빌드 23을 받아보고 결과물이 나아졌는지.** 이게 W5 실사용이 막혀 있던 이유였으므로, 나아졌다면 이제 올릴 수 있다.

## 1. 오늘 열 수 있나 (20분)

### 상태부터

2026-09-20 애플 조회 결과다.

| 빌드 | 무엇 | 상태 |
|---|---|---|
| **1.0.0(18)** | 9/13, 이름이 "메추리 런"이던 때 | **BETA_APPROVED** (외부 심사 통과) |
| **1.0.0(23)** | 9/20, 지금 것 | 내부는 `IN_BETA_TESTING`, **외부는 `READY_FOR_BETA_SUBMISSION`** |

**승인은 옛 빌드가 받았고, 지금 빌드는 외부 그룹에 아직 안 들어갔다.**

### 무엇을 해야 하나

**앱을 다시 빌드해 올릴 필요는 없다.** 빌드 23은 9/20에 애플에 올라갔고 내부 테스터는 이미 쓰고 있다.

**남은 것은 외부 베타 심사에 제출하는 일이다.** 지금 상태인 `READY_FOR_BETA_SUBMISSION`이 정확히 "제출할 준비가 됐다, 아직 안 냈다"는 뜻이다. TestFlight에서 **빌드 23을 외부 그룹에 추가하면** 그 절차가 시작된다.

### 심사를 다시 받는다고 보는 편이 맞다

애플 문서에는 "처음 제출하는 빌드는 전체 심사를 받지만 같은 버전의 이후 빌드는 심사가 없을 수도 있다"는 문장이 있다. 빌드 18과 23은 둘 다 `1.0.0`이다.

**그래도 이번에는 기대하지 않는 편이 낫다.** 18이 승인받은 것은 **"메추리 런"이라는 이름으로**였고, 23은 **표시 이름이 Runary로 바뀌었다.** 처리방침 링크도 새로 들어갔다. **이름이 바뀌면 다시 보는 쪽에 가깝다.**

보통 하루, 늦으면 닷새다. **오늘 열리지 않을 가능성을 전제로 아래를 정한다.**

### 그래서 고를 것

[9/16 결정](../../decisions/2026-09-16-release-and-editor-scope.md)은 **"9/22는 목표로 유지하되 막히면 미루는 것을 허용한다"**였다. 그 상황이다.

| | 무엇을 하나 | 잃는 것 |
|---|---|---|
| **A. 기다린다** | 오늘 제출하고 통과하는 날을 출시일로 | 날짜. 보통 하루, 늦으면 닷새 |
| **B. 18로 연다** | 이미 승인된 빌드를 공개 링크에 올린다 | **이름이 "메추리 런"이다.** 9/13 이후 고친 것이 전부 빠진다. 가독성도 안 고쳐진 상태다 |
| **C. 오늘을 다르게 부른다** | 지인 다섯에게 내부 테스터로 먼저 준다 | 공개 링크가 아니므로 PRD의 출시 정의와 다르다 |

**B는 권하기 어렵다.** 제품명을 Runary로 확정한 것이 바로 지난주이고, 가독성 때문에 실사용이 막혀 있었는데 그게 안 고쳐진 빌드를 내놓는 것이 된다.

### 누가 하나

**앱 관리 애플 계정은 지민 것이다.** [인계 기록](../../ops/build-and-dev-commands.md)에 "외부 베타 공개 설정을 다른 팀원에게 요청하거나 다음에 진행하기로 했다"고 남아 있다.

**오늘 이 자리에서 누가 언제 할지 정한다.** 정해두지 않으면 또 하루가 지나간다.

## 2. 아이콘을 고른다 (15분)

이름은 바꿨는데 **아이콘은 아직 메추리다.** 그리고 아이콘은 크림 바탕인데 앱 안은 야간 네온이라 **열자마자 톤이 뒤집힌다.**

**시안: https://claude.ai/artifact/WCKWnwdtg7piXY5WBr3Etj**

정리 문서는 [여기](2026-09-21-app-icon-candidates.md)에 있다.

### 이미 닫힌 것

메추리 제외, 획으로 그린 R 제외, 선은 굵기 4·길이 104~408·간격 보통, 스텐실 틈 16. **다시 열지 않는다.**

### 남은 11개

| | |
|---|---|
| **마크 다섯** | 마침표 있는 셋(P1·P2·P3), 없는 둘(B4-1·B4-2) |
| **워드마크 여섯** | `RUNARY`/`Runary` × 선 위/아래 × 선 색 |

### 정할 것

1. **마크로 갈까 워드마크로 갈까**
2. **주황을 마침표로 찍을까 말까**
3. **바탕을 어둡게 할까 크림으로 할까**
4. **글꼴** — Space Grotesk(앱이 숫자에 쓰는 것) 또는 Pretendard(앱 UI 글꼴)

**3번이 취향이 아니라 판단이다.** 크림은 지금 아이콘과 이어지지만 앱 안과는 계속 끊긴다. 어두운 쪽은 앱과 이어지지만 홈 화면에서 밝은 아이콘들 사이에 묻힐 수 있다.

**4번은 워드마크를 고를 때만 걸린다.** 스텐실 R은 손으로 그린 도형이라 글꼴과 무관하다.

**아이콘 교체가 출시를 막지는 않는다.** 다음 빌드에 넣으면 된다.

## 3. 열고 나서 무엇을 볼까 (10분)

### 무엇을 검증하려던 것이었나

PRD §5가 이번 라운드의 검증 항목으로 잡은 것이다.

> 직접 측정하지 않더라도 **공유를 목적으로 예쁜 드로잉 결과물을 얻고 싶어하는 니즈**가 있는지

**결과물을 보고 "나도 해보고 싶다"가 나오는지가 답이다.** 앱을 쥐여주지 않아도 나온다.

### 어디까지 뿌리기로 했나

[9/16 결정](../../decisions/2026-09-16-release-and-editor-scope.md)이다.

| | |
|---|---|
| 공개 링크 | **연다.** 이것이 출시다 |
| 어디에 | **스레드**와 **지인 다섯** (준익·수미·준민·규영·준호) |
| 외부 테스터 | **모집하지 않는다.** 링크를 닫는다는 뜻은 아니다 |

### 정할 것

- **우리가 먼저 올릴 것인가.** 9/12에 "결과물을 각자 스토리에 올려보자"는 제안이 나왔고 아직 아무도 안 했다. **가독성이 고쳐졌으면 이제 할 수 있다**
- **스레드에 무엇을 올릴 것인가.** 세 번째 글 자리가 비어 있다
- **반응을 어디에 모을 것인가.** 흘러가면 또 못 본다
