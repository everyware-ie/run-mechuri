## 2. 트렌드를 얹는 방식: 유행어가 아닌 게임 규칙으로

"러닝크루", "AI", "웨어러블"이라는 단어를 붙이는 것만으로는 차별점이 되지 않는다. 아래처럼 실제 경로가 바꾸는 세계와 연결돼야 한다.

```text
개인 상태/목표 → 오늘의 공간 퀘스트 선택 → 실제 동네에서 달림 → 지도 세계 즉시 변화
→ 크루의 다음 약속/역할 생성 → 결과물 공유와 친구 초대
```

## 3. 컨셉 후보

### A. 크루 시즌 패스 — 매주 실제 동네에서 열리는 작은 원정

2~5인 크루가 7일짜리 `마이크로 시즌`을 시작한다. 전력망/신호탑 같은 실제 지도 게임판 위에 이번 주의 목적이 생긴다.

예시 시즌:

- "우리 동네 첫 점등": 서로 다른 3개 길을 이어 공원 신호탑에 불 켜기
- "야간 원정": 해가 지기 전/후 각 1회 러닝으로 등대 유지하기
- "새 학기 캠퍼스 탐사": 크루가 캠퍼스 주변의 5개 연결 구간 완성하기

**트렌드 연결:** 러닝크루의 성장과 로컬 이벤트 흐름을, 별도 오프라인 행사 운영 없이 앱 안의 작고 반복 가능한 약속으로 번역한다.

**바이럴 가설:** 시즌 중 "연결에 한 명이 더 필요하다"는 빈자리가 보이면 친구 초대가 추상적 가입 권유가 아니라 공동 목표의 해결책이 된다.

### B. 컨디션 퀘스트 — AI가 게임 난이도와 역할만 고른다

기록/웨어러블 데이터를 바탕으로 AI 또는 규칙 엔진이 오늘의 의도를 `유지·성장·탐험·회복` 중 하나로 추천한다. AI가 건강 조언의 정답을 말하는 것이 아니라, 안전한 범위의 게임 퀘스트를 고른다.

| 의도 | 위치 기반 퀘스트 예시 |
|---|---|
| 유지 | 기존 전력선 1개를 재점등해 팀 네트워크 유지 |
| 성장 | 평소보다 조금 먼 다음 거점까지 연결 |
| 탐험 | 아직 안개가 남은 안전한 인근 도로 1개 발견 |
| 회복 | 짧은 걷기/가벼운 러닝으로 캠프 보급품 전달 |

**핵심:** 회복도 "오늘 못 뛰었다"가 아니라 팀에 필요한 역할이 되므로, 꾸준함과 건강한 중단/복귀를 동시에 보상할 수 있다.

**주의:** 의료적 판단이나 부상 진단은 제공하지 않는다. 추천 근거와 끄기/변경 기능이 필요하다.

### C. 마이크로 런트립 패스포트 — 여행 대신 평소 동네를 수집한다

실제 지도의 공원·하천·언덕·골목 등 장소 성격을 짧은 테마 패스로 엮는다. "서울 전체 정복" 같은 거대한 목표가 아니라, 3~5km 안에서 끝나는 작은 여행이다.

- 계절별/시간대별 테마: 비 온 뒤 물길, 벚꽃 길, 야경, 언덕, 책방/커피 근처
- 경로를 달리면 지도 스탬프와 짧은 장소 카드 획득
- 크루가 서로 다른 패스를 완성하면 공동 원정 지도가 완성

**트렌드 연결:** 런트립/로컬 탐험의 감각을 비용 큰 여행 콘텐츠 없이 일상 러닝에 가져온다.

**MVP:** 장소의 감성 데이터를 대규모로 만들지 말고, 테스트 지역 1곳의 수동 큐레이션 패스 5개로 검증한다.

### D. 크루 전력전: 이벤트 당일에만 열리는 실제 지도 레이드

평소에는 전력망을 가꾸고, 특정 주말 2시간에는 크루끼리 정해진 지역의 거점을 활성화하는 이벤트를 연다. 실제로 만나서 뛰는 팀과 떨어져 있는 팀 모두 참여할 수 있게 비동기 기여도 허용한다.

- 이벤트 전: 크루가 연결망과 역할을 준비
- 이벤트 중: 제한된 거점이 열리고 실제 경로가 실시간으로 점등
- 이벤트 후: 팀의 경로가 하나의 빛나는 리플레이/연대기로 저장

**트렌드 연결:** 실제 이벤트·클럽 모임의 상승세를 게임의 절정으로 사용한다.

**주의:** 첫 MVP부터 실시간 대규모 이벤트 운영을 하지 않는다. 팀 2개, 거점 3개, 1시간짜리 내부 테스트가 우선이다.

### E. 로컬 보상은 마지막 단계에만 — "달리고, 이야기하고, 만난다"

완주한 크루에 카페 쿠폰 같은 외부 보상을 붙이는 것은 바이럴/재참여에 도움이 될 수 있다. 실제로 Strava와 adidas도 GPS 활동을 리워드 프로그램과 연결하는 사례를 발표했다.

다만 MVP의 핵심 보상은 외부 쿠폰이 아니라 `점등된 동네`, `완성한 연결망`, `크루의 원정 기록`이어야 한다. 파트너 보상은 지역 크루/행사가 검증된 뒤 확장한다.

## 4. 추천 조합

### 1차 MVP: A(크루 시즌 패스) + 전력망

가장 작고 명확한 질문을 검증한다.

> "친구의 실제 러닝 경로가 내 길과 연결되어 동네 거점에 불이 켜지면, 다음 주에도 다시 달리고 친구를 초대하고 싶은가?"

- 위치 기반 게임의 즉시성 유지
- 크루/로컬 이벤트 트렌드 반영
- 대형 콘텐츠 제작·실시간 대전·브랜드 제휴 없이도 구현 가능

### 2차 확장: B(컨디션 퀘스트) + C(마이크로 런트립)

전력망만으로 반복 동기가 부족할 때, 오늘의 개인 상황에 맞는 길과 역할을 제안한다. 이 단계에서만 AI/웨어러블 데이터를 보조적으로 쓴다.

## 5. 검증 질문

1. 사용자에게 가장 설레는 것은 "우리 길이 연결됨", "새 장소 발견", "상대 팀보다 먼저 점등" 중 무엇인가?
2. 2~5인 크루가 실제로 7일짜리 마이크로 시즌 약속을 유지할 수 있는가?
3. 기기 데이터가 없는 사용자에게도 컨디션 퀘스트를 공정하게 제공할 수 있는가?
4. 학교/지역 진영전은 크루 기반 경험이 검증된 후에야 추가해야 하는가?
5. 로컬 파트너 보상이 없어도 지도 위 결과물만으로 공유/초대 의지가 생기는가?
