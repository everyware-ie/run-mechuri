# 2026-09-21 앱 아이콘 시안 (회의 준비)

제품명이 `Runary`로 확정됐는데([2026-09-16 결정](../../decisions/2026-09-16-product-name-runary.md)) **아이콘은 아직 메추리다.** 이름을 바꾸는 김에 아이콘도 같이 보려고 시안을 뽑았다.

**회의에서 고르면 된다.** 여기는 어디까지 좁혔고 무엇이 남았는지를 적어 둔 것이다.

## 시안 보는 곳

**https://claude.ai/artifact/WCKWnwdtg7piXY5WBr3Etj**

`[확인 필요]` **지금은 비공개라 팀원이 못 연다.** 회의 전에 페이지의 공유 메뉴에서 열어야 한다. (2026-09-21 phs00)

화면 위쪽의 **홈 화면 크기** 단추를 누르면 전부 60px로 줄어든다. **아이콘은 결국 그 크기에서 갈리므로** 큰 그림만 보고 정하지 않는 편이 좋다. 맨 아래에는 남은 시안을 전부 올린 홈 화면 목업이 있다.

## 왜 바꾸나

| | |
|---|---|
| **이름이 안 맞는다** | 아이콘은 메추리인데 제품은 Runary다 |
| **톤이 뒤집힌다** | 아이콘은 크림 바탕에 검정 선인데 앱 안은 야간 네온(`#0B0D10`)이다. **열자마자 밝은 데서 어두운 데로 떨어진다** |

**팀은 계속 팀 메추리다.** 제품 이름만 바뀐 것이므로 제품 아이콘이 메추리여야 할 이유는 약해졌다.

## 닫힌 것

좁혀 오면서 정한 것들이다. **회의에서 다시 열지 않는다.**

| | |
|---|---|
| **메추리** | 뺀다 |
| **획으로 그린 R** | 뺀다. 빛 효과가 작은 크기에서 번진다 |
| **선** | 굵기 4 · 길이 `x=104~408` · 글자와의 간격 보통 |
| **스텐실 틈** | **16.** 10은 작게 줄이면 틈이 메워진다 |

색은 앱의 실제 토큰을 그대로 썼다. 바탕 `#0B0D10`, 강조 `#FF5A2B`, 선 `#FFF3EC`, 크림 `#F2EBE1`. 글자는 앱이 숫자에 쓰는 Space Grotesk다.

## 남은 것 (11개)

### 마크 다섯

| | |
|---|---|
| **P1** | 스텐실 R + **주황 마침표**. 어두운 바탕 |
| **P2** | 같은 것, 크림 바탕 |
| **P3** | `RUNARY.` 워드마크. 마침표만 주황 |
| **B4-1** | 스텐실 R만. 마침표 없음. 어두운 바탕 |
| **B4-2** | 같은 것, 크림 바탕 |

**P1·P2와 P3는 한 세트다.** 마크와 이름이 같은 규칙(주황은 마침표 하나)을 쓰므로, 아이콘은 P1이나 P2로 가고 스레드·스토어에는 P3를 쓸 수 있다.

### 워드마크와 선 여섯

`RUNARY` 또는 `Runary`에 주황 직선 하나. 선을 **위에 두느냐 아래에 두느냐**가 갈린다.

| | |
|---|---|
| 선이 **위** | 선이 먼저 걸려 머리띠처럼 읽힌다 |
| 선이 **아래** | 이름이 먼저 읽히고 선이 바닥을 받친다 |

D-5와 D-6은 선을 강조색 대신 **경로 색(흰색)**으로 바꾼 것이다.

## 회의에서 정할 것

1. **마크로 갈까 워드마크로 갈까**
2. **주황을 마침표로 찍을까 말까** (P 계열 / B4 계열)
3. **바탕을 어둡게 할까 크림으로 할까**
4. 워드마크로 간다면 **선 자리와 글자 형태**

**3번이 생각보다 크다.** 크림을 고르면 지금 아이콘과 이어지지만 앱 안의 야간 네온과는 계속 끊긴다. 어두운 쪽을 고르면 앱과 이어지는 대신 홈 화면에서 밝은 아이콘들 사이에 묻힐 수 있다.

`[확인 필요]` **번들 ID `com.mechuri.runmechuri`는 그대로 간다.** App Store Connect에 등록된 앱과 묶여 있어 바꾸려면 앱을 새로 만들어야 한다. 아이콘 교체와는 별개이고, **그 작업을 실제로 할 때 작업자에게 한 번 더 확인하고 진행한다**([제품명 결정문](../../decisions/2026-09-16-product-name-runary.md)).

## 만드는 방법에 대해

시안은 **512 격자 위에 좌표로 그린 것**이라 고른 뒤 값만 바꿔 다시 뽑을 수 있다. 배경 이미지를 만든 `scripts/generate-backgrounds.py`와 같은 방식으로 스크립트를 두면 레포에 남고, 나중에 색이나 굵기를 바꿀 때도 다시 그릴 필요가 없다.

**아직 레포에 코드로 넣지는 않았다.** 아이콘은 결정 사항이라 회의 뒤에 넣는 것이 맞다고 봤다.
