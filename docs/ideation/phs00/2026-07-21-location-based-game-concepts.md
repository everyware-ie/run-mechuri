## 1. 출발점: 땅따먹기가 강하게 느껴지는 이유

땅따먹기형 러닝 게임의 몰입은 "경쟁 점수"보다 아래의 즉각적인 공간 인과관계에서 나온다.

```text
실제 동네에서 달린 경로 → 지도 위 동일한 장소가 즉시 변함 → 다음 러닝에서 갈 이유가 생김
```

- 내가 아는 공원·골목·캠퍼스가 게임판이 된다.
- 내 이동 경로가 추상 XP가 아니라 눈으로 확인 가능한 면적/선/상태가 된다.
- 같은 장소를 다시 달리거나, 아직 가지 않은 장소로 갈 이유가 생긴다.
- 상대와의 경쟁도 추상 순위가 아니라 "저 공원/길/거점이 바뀌었다"는 사건으로 보인다.

따라서 줄다리기처럼 전체 점수만 움직이는 구조는 이 감각이 약하다. 아래 후보들은 실제 위치를 게임의 **배경**이 아니라 게임 규칙의 **입력과 결과**로 사용한다.

## 2. 리서치 메모: 이미 존재하는 위치 기반 문법

- [Fitopoly](https://fitopoly.app/)는 실제 이동으로 육각 타일을 점령하고, 팀 영토·연결 패턴·루프 보너스를 제공한다.
- [RIVL](https://playrivl.com/)과 [Motera](https://www.motera.app/)는 GPS 루프로 둘러싼 실제 면적을 소유·방어·탈환하는 방식이다.
- [RNERS](https://www.rners.net/)는 GPS 육각 그리드의 타일 점령과 방어를 제공한다.
- [GeoRacer](https://georacer.dk/)는 팀이 실제 체크포인트를 순서대로 통과하는 실시간 경주를 제공한다.
- [TrailGlyph](https://trail-glyph.glamdring.work/)는 실제 도로를 따라 GPS 아트를 완성하는 경로 설계 도구다.

**의미:** 격자 타일 점령, 폐곡선 면적 점령, 단순 체크포인트 경주, GPS 그림 자체는 새롭지 않다. 차별화는 실제 경로가 만드는 결과를 `면적 소유` 외에 무엇으로 바꾸는지에 있다.

## 3. 공간 몰입을 유지하는 설계 조건

1. **즉시성**: 러닝을 저장하면 지도 상태가 바로 바뀌어야 한다.
2. **장소성**: 실제 도로·공원·캠퍼스의 형태가 결과물에 남아야 한다. 임의 육각 그리드만 보이면 장소 감각이 약해진다.
3. **반복 이유**: 이미 간 길도 방어·연결·성장·변화의 이유가 있어야 한다.
4. **탐험 이유**: 아직 안 간 길도 발견·연결·완성의 이유가 있어야 한다.
5. **초보 포용**: 장거리/고속 기록이 아니라 짧은 러닝, 복귀, 반복도 의미 있게 반영돼야 한다.
6. **안전/프라이버시**: 달리는 중 화면을 계속 보게 하거나 집 근처의 정확한 활동 패턴을 공개하지 않는다.

## 4. 컨셉 후보

### A. 러닝 전력망 — 실제 도로를 연결해 도시를 밝힌다

GPS 경로를 도로 단위로 맵 매칭한다. 처음 달린 도로는 팀 색의 `전력선`이 되고, 서로 연결된 길들이 커지면 실제 공원·학교·랜드마크 같은 거점에 전기가 공급된다.

```text
길을 달림 → 도로 구간 점등 → 구간을 연결 → 거점에 전력 공급 → 팀 도시가 밝아짐
```

- 새 길: 새로운 전력선 확보
- 자주 달리는 길: 전력선 유지/강화
- 팀원들의 길이 이어짐: 더 긴 회로와 거점 해금
- 적 팀: 같은 거점으로 이어지는 더 강한 전력망을 만들어 경쟁
- 보상: 실제 동네 지도 위에서 팀의 빛나는 네트워크와 야간 도시 변화

**땅따먹기와의 차이:** 면적을 많이 먹는 사람보다 `연결을 완성하는 사람`이 중요하다. 1km의 빈 구간을 이어 거점에 불을 켜는 짧은 러닝도 영웅적인 행동이 된다.

**MVP 가설:** 실제 지도 전체가 아니라, 제한된 테스트 지역의 도로/거점 10~20개와 2개 팀으로 시작한다. GPS→도로 매칭 정확도와 거점 연결의 이해 가능성을 먼저 검증한다.

### B. 안개 지도와 탐사 도감 — 내가 달린 동네가 발견된다

시작 시 지도는 안개에 가려져 있다. 실제로 달린 도로만 안개가 걷히며, 동네의 공원·전망·물길·오르막 같은 탐사 카드가 나타난다. 팀은 구성원이 발견한 길을 합쳐 특정 구역의 탐사도를 완성한다.

- 새 길: 안개 해제/탐사 카드
- 반복 길: 그 길의 친밀도·계절 기록·안전한 추천 경로 강화
- 팀 완성: "우리 학교 주변 80% 탐사" 같은 공동 도감
- 경쟁: 같은 기간 어느 크루가 더 다양한 길/거점을 발견했는지

**몰입 포인트:** 사용자가 실제 동네를 새롭게 보고, 지도 자체가 개인/팀의 기억으로 변한다.

**주의:** 새 길만 보상하면 늘 새로운 코스를 찾아야 하는 피로가 생긴다. 반복 경로에도 `나만의 길` 성장 보상을 반드시 둔다.

### C. 길 위의 회로 — 실제로 그린 루프가 세계의 장치가 된다

사용자가 실제 도로에서 만든 폐곡선 또는 연결 경로가 `마법진/방벽/수로/철도 회로`가 된다. 루프 안에 있는 가상 거점이 활성화되고, 팀원들이 이어 달리면 더 큰 회로가 완성된다.

- 작은 루프: 개인 방어막/자원 생성
- 팀 루프: 공동 거점 활성화
- 겹치는 루프: 회로 강화 또는 상대 회로 교란
- 일정 기간의 회로 유지: 지역의 세계관 장면 변화

**땅따먹기와의 차이:** 루프의 면적이 곧바로 영토가 아니라, 경로의 형태와 연결성이 장치의 기능을 결정한다. "어디를 얼마나 크게 둘렀나"보다 "누구와 어떤 회로를 만들었나"가 전략이 된다.

**주의:** 폐곡선을 강제하면 러닝 경로가 부자연스러워진다. 한 번의 러닝이 아니라 팀의 여러 경로가 나중에 이어져 회로가 되는 비동기 방식을 우선 검토한다.

### D. 실외 GPS 아트 시즌 — 우리 팀의 실제 동네 벽화

팀이 특정 기간에 실제 도로를 달려 하나의 큰 그림/문양/상징을 완성한다. 러닝 기록이 지도 위의 선으로 남고, 필요한 선을 팀원들이 나누어 채운다.

- 개인: 오늘 맡은 선 하나를 완성
- 협동: 조각들이 모여 팀의 상징/마스코트/시즌 벽화 완성
- 경쟁: 다른 팀보다 더 빨리 또는 더 완성도 높게 시즌 작품 완성
- 보상: 실제 동네의 도로 모양을 포함한 공유 카드

**리서치 주의:** GPS 아트 경로 생성/공유 도구는 이미 존재한다. 차별점은 그림을 개인의 인증샷이 아니라 **팀 역할 분담과 시즌 게임**으로 만든다는 점이다.

**주의:** 그림을 정확히 따라야 한다는 부담과 안전한 경로 보장이 과제다. 자유 GPS 그림보다, 실제 보행/러닝 가능한 길을 바탕으로 한 간단한 패턴으로 시작한다.

### E. 신호탑 릴레이 — 실제 거점을 이어 도시의 신호를 복구한다

공원·캠퍼스·운동장 등 실제 거점에 가상 신호탑을 둔다. 팀이 각 거점까지 달려 신호를 충전하고, 서로 다른 팀원이 시간 안에 다음 거점으로 바통을 이어야 도시 전체의 통신망이 살아난다.

- 짧은 러닝도 가까운 신호탑 충전에 기여
- 장거리 러닝은 멀리 떨어진 탑을 연결
- 팀의 비동기 순서가 릴레이/협동 전략이 됨
- 같은 거점은 다른 팀과 점유가 아니라 "이번 시즌 누가 더 안정적인 신호를 유지하는가"로 경쟁

**차이:** 실제 장소 방문과 팀의 시간적 연결이 핵심이다. 점령보다 `관계/순서/연결`이 게임 결과를 만든다.

**주의:** 특정 장소로 유저를 유도하는 만큼 야간 접근성·사유지·안전 경고·지역별 거점 데이터 관리가 필수다.

### F. 살아 있는 길 — 자주 달린 길이 팀의 생태계가 된다

실제 경로를 달리면 길 주변에 가상의 식물·물길·동물 서식지가 자란다. 팀의 반복 러닝은 길을 유지하고, 새로운 길은 생태계를 확장한다. 두 팀은 같은 공원/구역의 생태 지수를 두고 선의의 경쟁을 한다.

- 거리: 성장 자원
- 반복: 생태계 유지·계절 변화
- 새 길: 서식지 확장
- 팀 협동: 서로 떨어진 서식지를 연결해 숲/강/철새 길 완성

**장점:** 영토 탈취의 공격성을 줄이고, 달린 길을 가꾸는 정서적 보상을 만든다.

## 5. 현재 추천과 보류

### 가장 유망: A. 러닝 전력망

땅따먹기의 "내가 뛴 실제 장소가 변한다"는 장점을 유지하면서, 면적 경쟁을 `연결`과 `거점 활성화`로 바꾼다. 크루 협동·학교/지역 대항·개인 기여를 모두 자연스럽게 넣을 수 있다.

- 초보: 짧은 빈 구간을 이어 팀 회로를 완성
- 꾸준한 러너: 기존 전력선을 안정적으로 유지
- 탐험 러너: 새 거점으로 확장
- 팀: 어떤 거점부터 연결할지 전략 선택

### 함께 검토할 조합

- **A + E**: 도로 전력망을 연결해 실제 거점 신호탑을 켠다.
- **B + F**: 탐사한 길이 팀의 살아 있는 동네 생태계가 된다.
- **C + D**: 팀의 실제 루트가 회로이자 시즌 GPS 아트가 된다.

### 아직 보류할 것

- 영구적인 지역 점령/탈취: 기존 서비스가 많고, 약팀의 이탈·개인 위치 노출·치팅 문제가 큼.
- 실시간 러닝 중 상호 공격: 안전상 화면 주시를 유도할 수 있음.
- 실제 정치 성향과 연결된 진영: 러닝 동기보다 갈등/운영 위험이 커질 수 있음.
