### 생성 속도

- 사진 배경 기준 약 45초 → 약 30초 (화면 켠 상태)
- 폰이 뜨겁거나 메모리가 부족하면 전처럼 한 장씩 그려서 안 빨라질 수 있다
- 화면 잠금 상태는 아직 안 재 봤다

[성능 노트](../../product/features/export-parallel-rendering.md)

### 영상 배경

- 갤러리 영상을 배경으로 쓸 수 있다. 결과 영상에서도 배경이 움직인다

### 편집 화면 개편 (인스타 스토리 방식)

| 단계 | 내용 |
|---|---|
| 1단계 | 전체 화면 미리보기와 오른쪽 도구 버튼. 문구를 화면에 바로 쓰고 여러 개 넣기, 핀치·슬라이더로 크기 조절, 아래로 끌어서 숨기기·삭제, 되돌리기 |
| 2단계 | 선 색·두께, 글꼴, 글자 색(흰색·검정) |
| 3단계 | 손그림(펜·형광펜·네온), 내 스타일 저장 |
| 자유 색상 | 기본 6색 말고도 원하는 색을 직접 고르기 |

[결정문](../../decisions/2026-10-04-story-style-editor.md)
