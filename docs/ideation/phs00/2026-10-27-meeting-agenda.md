## 2. 11/3 재제출까지 1주 (20분)

MVP는 지난 스프린트(9/22 출시)로 마무리. **이번 스프린트 목표는 측정까지 공개하는 것.**
[10/6에 정한 일정](../../decisions/2026-10-06-second-sprint-app-store.md)은 "11/3 ~ 11/10 측정 기능 포함해서 다시 제출". 지금 측정·워치는 내부 빌드에만 들어 있음

### 남은 일

| 구분 | 할 일 | 상태 |
|---|---|---|
| 측정 | 종료·일시정지·반환점의 짧은 이동이 거리에서 빠짐 (§3) | 미완료 |
| 워치 | 손목 들었을 때 측정 화면으로 돌아오기 | 확인 못 함 |
| 워치 | 평균 심박이 화면마다 다르게 보임 | 확인 못 함 |
| 건강 앱 저장 | 여러 경로 구간 표시, 저장 실패 뒤 다시 저장 | 확인 못 함 |
| 공개 준비 | 공개 범위 PRD·FRD에 반영, 일반 빌드에 측정 넣기 | 미완료 |
| 공개 준비 | 개인정보 처리방침(위치 기록 보관, 건강 앱 저장), 스토어 권한 설명, 심사 메모, 측정 화면 스크린샷 | 미완료 |

근거: [측정 출시 전 검토](../../product/features/tracking-release-readiness.md), [워치 연동 구현 노트](../../product/features/watch-workout-integration.md)

### 남은 일 자세히

1~4는 수정하거나 실기기로 확인할 일, 5~6은 공개를 위한 결정과 문서 작업

**1. 짧은 이동이 거리에서 빠짐** (측정, 미완료)
- 원인: iOS는 3m 이상 움직여야 새 위치를 보내 줌. 앱은 2~5m보다 짧은 이동을 제자리 흔들림으로 보고 버림
- 빠지는 곳: 종료·일시정지를 누르면 위치 수집이 바로 멈춰서 마지막 3~5m가 빠짐. 반환점에서 급하게 돌면 끝부분이 잘림
- 크기: 5km에 10m 안팎(0.2%)으로 추정. 실측 아님
- 고칠 방법 후보: 종료·일시정지 때 위치 한 번 더 받기 / 3m 기준 낮추기 (배터리 확인 필요) / 제자리 판정 기준 조정

**2. 손목 들었을 때 측정 화면으로 돌아오기** (워치, 확인 못 함)
- 실제 워치에서 확인한 적 없음. 10/26엔 워치 개발 연결이 계속 끊겨서 최신 앱으로 못 봄
- 손목 들 때 앱이 보이는지는 운동 세션 상태와 워치 설정에 따라 달라짐. 빌드 44로 실제 워치에서 확인 필요

**3. 평균 심박이 화면마다 다름** (워치, 확인 못 함)
- 10/26 72초 테스트: Runary 평균 81bpm, 피트니스 앱 평균 84bpm
- 두 앱의 평균 계산 방식이 같은지는 아직 확인 안 함

**4. 건강 앱 저장** (확인 못 함)
- 지금까진 제자리 테스트(거리 0)로 저장되는 것만 확인
- 실제로 달린 경로가 건강 앱에 들어가는지
- 일시정지로 경로가 여러 조각일 때 피트니스에서 어떻게 보이는지
- 저장 실패 후 다시 저장해도 중복이 안 생기는지 (자동 검사만 함)

**5. 공개 범위 정하기와 일반 빌드에 측정 넣기** (미완료)
- 현재: 측정·워치·잠금화면은 내부 빌드에만 있음. 일반 빌드는 진입이 막혀 있고 위치 백그라운드·워치 앱·잠금화면도 빠져 있음
- 공개 범위: 아이폰 측정만 / 워치까지 / 건강 앱 저장까지
- 문서: PRD가 아직 지난 스프린트 MVP 기준이라 자체 측정이 "제외"로 남아 있음. 이번 스프린트 범위(측정 포함)로 PRD·결정문·FRD 정리
- 앱: 일반 빌드 설정 변경, "팀 테스트" 표시나 진단 화면 같은 내부용 화면 정리
- 심사: 위치 백그라운드, 건강 앱 쓰기, 워치 앱이 처음 들어가서 용도 설명 필요

**6. 개인정보 처리방침과 스토어 자료** (미완료)
- 처리방침: 지금은 "일반 배포 앱은 건강 데이터에 기록을 쓰지 않고, 자체 GPS 측정이나 워치 측정도 없다"고 되어 있어서 수정 필요
- 추가할 내용: 러닝 중 위치를 기기에 저장, 건강 앱에 운동·경로·심박 저장, 워치 연동
- 스토어: 권한 설명 문구(위치, 건강 쓰기, 동작), 심사 메모(측정 테스트 방법), 측정 화면 스크린샷, 설명문, 앱 개인정보 설문

### 정할 것

- 11/3에 낼 수 있을지. 어렵다면 무엇을 빼고 낼지 (예: 워치는 빼고 아이폰 측정만 먼저)
- 1차 심사 결과가 아직 안 나옴. 측정 버전을 언제, 어떤 버전으로 낼지
- 누가 무엇을 맡을지
