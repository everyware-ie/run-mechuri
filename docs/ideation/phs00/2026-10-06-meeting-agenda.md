## 2. 러닝 측정 기능 공유 (15분)

앱에서 직접 GPS로 러닝을 재는 기능이다.
9/29에 다음 스프린트 후보로 얘기했던 걸 팀 내부 테스트용으로 먼저 만들었다. 나이키처럼 건강 앱에 경로가 안 남는 기록도 이걸로 재면 그릴 수 있게 된다. ([PRD](../../specs/prd/internal-run-tracking.md) · [FRD](../../specs/frd/internal-run-tracking.md))

### 되는 것

| 기능 | 내용 |
|---|---|
| 측정 | 시작·일시정지·재개·종료. 시간, 거리, 페이스, 케이던스 |
| 지도 | 현재 위치와 지나온 경로 |
| 워치 (선택) | 워치로 심박 측정. 워치 없어도 측정은 된다 |
| 보관 | 폰 안에만 저장. 앱을 지우면 사라진다 |
| 복구 | 앱이 꺼져도 마지막 저장 시점부터 이어서 잴 수 있다 |

아직 측정한 기록으로 결과물을 만들 수는 없다.

### 써 보는 법

1. TestFlight에서 빌드 34로 업데이트 (내부 테스터만)
2. 홈 아래 `러닝 시작` 카드로 들어가기
3. 평소처럼 뛰면서 켜 두기. 다른 러닝 앱 같이 켜도 된다
4. 끝나면 기록 화면에서 `진단 요약 복사` → 카톡에 붙여 넣기

워치를 쓸 때는 다른 워치 운동을 같이 켜지 않는다. 워치는 운동을 하나만 돌릴 수 있다.

### 오늘 아침 첫 야외 테스트 (현수 출근길)

| 항목 | 결과 |
|---|---|
| 거리·시간 | 1.08km, 10분 42초 |
| GPS | 좌표 281개 중 278개 사용. 평균 오차 14m, 가장 긴 공백 5초 |
| 화면 잠금 중 | 254개를 잠긴 상태에서 받았다. 잠가도 잘 들어온다 |
| 배터리 | 95% → 95% (12분) |
| 끝부분 | 도착 직전 구간이 빠졌다 |
| 심박 | 안 들어왔다 |

**끝부분이 빠진 이유**
8:54에 iOS가 메모리를 확보하려고 Runary를 강제로 껐다. 그때 Runary가 폰에서 메모리를 가장 많이 쓰는 앱이었다(약 700MB). 다시 열었을 때 마지막 저장 시점까지만 복구돼서 그 뒤가 비었다.
→ 러닝 중에 쓰는 메모리를 줄여야 한다.

**심박이 안 들어온 이유**
워치 앱은 깔려 있었고 워치 연결도 켜져 있었다. 그런데 지금은 워치에서 "워치 측정 시작"을 한 번 더 눌러야 심박이 시작된다. 현수도 이 단계를 몰랐다.
이 확인 단계는 워치가 운동을 하나만 돌릴 수 있어서 넣었다. Runary가 워치에서 운동을 시작하면 이미 켜 둔 애플 운동이 꺼진다([Apple 문서](https://developer.apple.com/documentation/healthkit/hkworkoutsession)). 나이키 런(아이폰)은 워치 운동을 따로 돌리지 않고 애플 운동이 잰 심박을 읽어 오는 것으로 보여서, 둘을 같이 켜도 괜찮았다.

**심박 받는 방법을 고르게 하는 안**

| 방법 | 언제 | 동작 |
|---|---|---|
| Runary 워치로 재기 | Runary만 켤 때 | 워치에서 직접 잰다. 워치에서 누르는 단계는 없앤다 |
| 다른 운동 앱에서 가져오기 | 애플 운동 등을 같이 켤 때 | 건강 앱에 저장된 심박을 읽어 온다. 폰이 잠겨 있으면 늦게 뜨거나 안 뜰 수 있고, 끝난 뒤 기록에 채운다 |
| 안 씀 | 워치가 없을 때 | 심박 없이 잰다 |

**현수 의견**
지하에 들어가거나 와이파이가 붙었다 끊기는 상황에서도 끊기지 않고 이어서 재야 한다.

- 인터넷이나 와이파이는 측정에 쓰지 않는다. 끊겨도 측정은 계속되고 지도 배경만 안 뜰 수 있다
- 지하처럼 GPS가 안 잡히는 구간은 지금 거리를 더하지 않고 "누락 가능성"으로만 표시한다

자세한 내용은 [내부 측정 QA](../../ops/internal-run-tracking-qa.md) §11에 있다.

### 더 확인할 것

야외 기록이 아직 하나뿐이다.

- 거리가 평소 쓰는 앱이랑 비슷한지
- 다른 앱을 쓰다 와도 계속 기록되는지
- 지하나 GPS가 약한 곳을 지나도 이어서 재는지
- 워치 앱이 깔리고 심박이 들어오는지

### 주의

- 빌드 34는 공개 링크에 넣으면 안 된다. 위치 추적과 워치 앱이 들어간 내부용 빌드다

### 정할 것

- 누가 언제 뛰어 볼지 (일요일 러닝 때 같이 재면 편하다)
- 심박 받는 방법 세 가지를 모두 넣을지 (가져오기는 PRD·FRD를 먼저 고쳐야 한다)
- GPS가 끊긴 구간(지하 등)의 거리를 걸음 수로 추정해서 채울지, 비워 둘지
