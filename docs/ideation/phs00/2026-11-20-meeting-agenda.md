## 2. 크루 시안에서 정할 것 (20분)

[#140](https://github.com/everyware-ie/run-mechuri/pull/140) · [웹 시안](https://claude.ai/artifact/NsdzMysnDufu5XyfdcnZ9E) · [크루 기획서 초안](https://github.com/everyware-ie/run-mechuri/blob/phs00/docs/crew-design/docs/specs/prd/crew.md)

현수 안으로 적어 둔 것. 회의에서 확인

| | 현수 안 | 다른 안 |
|---|---|---|
| C1 크루 자리 | 하단 네 번째 탭 | 다이어리 안에서 전환(다이어리 FRD를 고쳐야 함) |
| C2 참여 방식 | 초대 링크, 회원 찾아 초대. 빠듯하면 초대 링크부터 | 친구 목록에서 초대(친구 기능이 먼저 필요) |
| C4·C5 크루 홈 | 소개 아래 한 줄 요약과 기록 목록. 10건씩 이어 불러옴 | 넓은 카드, 작은 썸네일, 멤버별 요약 등 |
| 공유 | 가입하면 자동 공유, 보여 줄 항목만 고름. 경로 모양은 항상, 지도는 고름. 지도는 장소 이름 숨기기 가능 | |
| 평균 심박 | 켜 둔 채로 안내. 출시 전 법률 확인 | |
| 크루장 | 누구나 만들고 만든 사람이 크루장. 멤버 내보내기, 크루장 넘기기 | |
| 첫 버전에서 뺌 | 크루 찾기, 사진 결과물 공유(App Store 가이드라인 1.2) | |

### 노션 위쪽 의견과 겹치는 것

| 노션 의견 | 지금 시안 |
|---|---|
| 건강 앱에서 가져온 기록도 공유 대상인지 | 경로 없는 러닝(F2-4)만 그림. 지민 안건 §1 크루원에게 보여 줄 기록의 범위와 같은 질문 |
| 공유 취소 대신 삭제. 원본을 지우면 공유한 기록은 어떻게 할지 | 공유 취소만 있음. 원본 삭제는 정하지 않음 |
| 자동 공유 대신 러닝을 마친 뒤 고르기 | 가입하면 자동 공유 |
| 심박은 기본으로 끄고 안내해서 켜게 | 켜 둔 채로 안내 |
| 공유 관리를 기록 상세 말고 다른 목록에서 | 내 기록 상세에서 한 건씩 |

### 정할 것

- 위 현수 안을 그대로 갈지, 겹치는 의견을 어떻게 정리할지
- C1을 네 번째 탭으로 정하면 하단 탭 FRD를 고침(#136으로 세 탭이 된 뒤)
- 크루 구현 담당. 11/10에는 디자인까지만 정함

## 4. QA (10분)

### 지인 사용 피드백 ([#141](https://github.com/everyware-ie/run-mechuri/pull/141))

- **결과물을 정지 이미지로도 받고 싶음.** [내보내기·공유·저장 FRD](../../specs/frd/export-and-share.md) §4-1 클립만 저장한다가 정지 이미지를 따로 주지 않기로 정해 둬서 FRD부터 고쳐야 함. 현수 안: 영상 마지막 완성 화면을 이미지로 저장하거나 스토리로 공유
- **측정을 마친 화면의 지도에 가게 정보와 위치가 보임.** 크루의 장소 이름 숨기기는 크루원이 보는 지도에만 적용됨. 본인 화면은 따로 정해야 함. 지도의 관심 장소 표시는 끌 수 있음

### 11/10에 나온 것

| QA | 지금 |
|---|---|
| 준비 화면 지도를 더 확대 | 고친 PR 없음 |
| 거리가 길게 나옴 | 정하지 않음 |
| 앱을 지웠다 깔면 기록이 사라짐 | 로그인 PRD가 서버 백업으로 풀기로 함. 백업·복원은 #143 범위 밖이라 다음 작업 |

### 정할 것

- 지인 피드백 두 건을 넣을지, 언제 넣을지
- 준비 지도 확대는 누가
