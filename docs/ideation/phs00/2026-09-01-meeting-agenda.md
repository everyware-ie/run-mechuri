## 1. `main`에 구현이 없다 (10분) — 가장 급하다

**이게 오늘 가장 먼저 풀어야 할 문제다.**

PR #32~36이 서로에게 순차적으로 머지됐고, **그 스택 전체를 `main`으로 보내는 PR이 없다.** `main`에는 Expo 스캐폴딩(#31)과 배경 이미지뿐이다.

```
main
 └─ chore/expo-project-setup        (#31 → main, 머지됨)
     └─ feature/healthkit-bridge     (#32, 머지됨)
         └─ feature/route-renderer   (#33, 머지됨)
             └─ feature/core-loop-screens  (#34, #36 머지됨)  ← 실제 구현이 여기 다 있다
                 └─ feature/result-editing (#35, 머지됨)
```

**왜 문제인가**

| | |
|---|---|
| 빌드를 낼 수 없다 | TestFlight에 올릴 기준이 `main`이라면 지금은 스캐폴딩만 나간다 |
| 검토가 안 됐다 | 7,700줄이 한 번도 `main` 기준으로 리뷰되지 않았다 |
| 되돌릴 수 없다 | 스택이 길어질수록 나중에 `main`으로 합칠 때 충돌이 커진다 |

**정할 것**: 오늘 `main`으로 통합 PR을 낼 것인가. 낸다면 한 번에 낼지 나눠 낼지.

## 5. 스레드 첫 글 결과 (10분)

**8/29에 올렸다.** "혹시 내가 뛴 러닝 기록(경로)이 예쁘게 그려진다면 어떨 것 같나요?"

### 5-1. 외부 반응은 한 명이다

숫자를 그대로 읽으면 조회 796, 좋아요 1, 답글 2다. **그런데 우리 것을 빼면 이렇게 된다.**

| | 표시된 수 | 우리 것 | **외부** |
|---|---|---|---|
| 조회 | 796 | | 796 |
| 좋아요 | 1 | phs00 본인 | **0** |
| 답글 | 2 | team.mechuri 답변 1 | **1** |

**796명이 보고 한 명이 답글을 남겼다.** 0.13%다. 좋아요는 외부에서 하나도 없었다.

### 5-2. 무엇을 알 수 있나

**노출은 됐다.** 팔로워 0인 계정인데 796회가 나왔으니 러닝 토픽 태그는 제 몫을 했다. 문제는 노출이 아니라 그다음이다.

**질문이 약했을 수 있다.** "어떨 것 같나요"는 답하기 애매하다. 좋다고 하기도 나쁘다고 하기도 어중간해서 그냥 지나치게 된다. 다음 글은 **둘 중 하나를 고르게 하거나 자기 경험을 말하게 하는** 편이 낫다.

**한 번으로 판단할 수는 없다.** 첫 글이고 팔로워가 없다. 다만 **"반응이 적었다"가 아니라 "외부 반응이 하나였다"로 정확히 적어둔다.** 나중에 두 번째 글과 비교할 기준이 되기 때문이다.

### 5-3. 그 한 명이 한 말이 경쟁 제품 지적이었다

> 가민 코로스 둘다 기능이 있어

**유일한 외부 반응이 "그거 이미 있어"였다.** 우연일 수 있지만 그냥 넘길 수 없다.

**결이 다를 가능성은 크다.**

| | 그쪽 | 우리 |
|---|---|---|
| 대상 | 그 시계를 쓰는 사람 | **애플 건강 데이터가 있으면 누구나** |
| 결과물 | 기록 화면 안의 지도 | **인스타에 올릴 세로 클립** |
| 목적 | 기록 확인 | **남에게 보여주기** |

`[확인 필요]` **실제로 어떤 형태인지 셋이 각자 보고 오자.** PRD §3 타겟과 §5 차별점에 영향이 있다. 겹치는 부분이 크면 "왜 우리 것을 쓰나"에 답할 말이 필요하다.

## 6. 확인하고 넘어갈 것 (10분)

### 6-1. 목업이 FRD 범위를 넘어섰다

인계 노트의 6단계 계획에 **"설정 화면"**이 있는데 **FRD 어디에도 없다.** FRD 7개가 `approved`인 상태에서 구현이 앞서가면 스펙과 코드가 조용히 갈라진다.

통합 PR 전에 한 번 맞춰보는 게 좋겠다. FRD를 고칠지, 범위를 줄일지.

### 6-2. Expo Go 제약

**Expo Go로는 커스텀 네이티브 모듈이 안 돈다.** 브릿지 셋을 쓰려면 development build나 prebuild가 필요하다. 이미 겪었을 텐데 어떻게 풀었는지 공유받자.

### 6-3. 08-18 미해결 4건

백엔드 인력 배치(닫힘), 재방문 유인, "예쁘다"의 기준, PRD 단독 결정 승인. **세 건이 두 번의 회의를 그냥 지나갔다.**
